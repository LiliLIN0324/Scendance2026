## 必须检查的行为

| 情况 | 观察内容 |
|---|---|
| 旧底图 | 可找到选择图片与显隐入口；坏文件/取消不覆盖旧图；隐藏时墙体、基础和物件身份/位置均不变 |
| v2图纸 | 选择当前项目的平面图与对应依据；照片/无对应/旧记录缺尺度基准时有明确提示；有效图纸可在主画布对照 |
| 坐标 | 图像像素、后端左上角原点、编辑器中心原点三者正确转换；二维三维方向一致，无镜像/倒置/第二次中心偏移 |
| 退化输入 | NaN/Infinity、重复点、共线与近共线拒绝；(10,20),(610,20),(610,20.0001)不能因绝对det非零而接受，避免1像素误差被放大成数万米 |
| 固定尺度 | 更改场地尺寸后不静默以新宽深重算旧图比例；需要重核时标明，不自动把尺寸改成confirmed |
| 设计调整 | 同一项目、原图及世界坐标框架内微调墙线或门窗时保留固定参照；仅修改被比对的设计不应迫使用户每改一面墙就重选对应点 |
| 显隐与透明度 | 只改变显示，不清除图片、不更换场景、不新增几何，也不把隐藏误当删除或完成现场复核 |
| 保存与重开 | 图片来源与已确认对齐依据在同项目回读；实际文件依赖与布局备份覆盖分开报告，不声称Blob已被备份 |
| 作用域 | 换项目/移除图纸后，迟到的文件解码、来源加载或对齐结果不能把旧图画进新项目 |
| 历史兼容 | 旧registration只有sourceId与points，缺确认时的世界尺寸时不得推断为当前已对齐；不丢弃原输入 |
| 展示边界 | 未显式选择的私有来源不自动进入公开分享或客户评审；三维截图按当前实际视图说明包含的资料 |

对存储错误和时序的受控测试与真实浏览器正向验证分开记录。需要云端授权的来源用明确的测试替身检查，不用未发生的真实云/模型结果作证明。
