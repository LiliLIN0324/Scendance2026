# 幕景 Agent 离线基线

在仓库根目录运行：

```powershell
node frontend/scripts/evaluate-agent-baseline.cjs
```

脚本复用仓库现有的人工标注测试：30 人与每桌 2 人、签到待定、口述库存、冲突与缺失、双人桌及缺口、原场景与锁定物件。输出 JSON 将需求理解、工具执行和结果复核分开，包含各项断言耗时和整体耗时；未覆盖的层为空数组。缺失或跳过的断言不会算通过，任一测试组失败时整体状态为 `incomplete`。

这是固定模拟与临时数据库的回归基线，不连接真实模型、不读取密钥、不使用用户项目；通过比例不是 Agent 成功率，也不代表真实库存或现场安全。单次测试耗时包含运行环境影响，不能当作模型延迟。

真实模型测试要使用隔离试用和虚构输入，分别记录模型版本、实际调用次数、工具回执、最终候选与场景回读；不要将真实 Key 或客户资料放进用例或报告。该基线脚本本身没有真实模型批量调用能力，也不会自动重试付费请求。现有单轮需求评测另见 `frontend/evals/brief/README.md`。
