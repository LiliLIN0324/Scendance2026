# 前端版本记录

当前版本 v4.12.0。活动方案全流程与深收口见仓库根目录 `CHANGELOG.md`。以下保留前端历史记录。

## v4.12.0 · 户外主链与品牌收口 · 2026-11-13

这一版前端跟户外主链一起收口：对话面板能给出真实场地候选并等你确认，未登录会明确引导而不是静默失败；本机开发的地点搜索走双源代理并常驻不再被会话带走；品牌选中态改读规范 token，前端版本记录与两个 package.json 同步到 v4.12.0。

**你能直接用到的**
- 户外对话给出真实候选卡片：「在杭州IN77做设计」之后直接列出湖滨银泰 in77 与 A 区、C 区、C3 区、C1 区的地址与坐标，点选就把场地锚定下来。
- 未登录时明确告诉你：匿名访客发户外消息会被前置闸门拦下并给出登录引导，登录之后原话可以接着说，不再像按钮失灵一样没有下文。
- 候选不止一条：模型把「我理解为『杭州IN77』，设为场地？」和候选列表一起给出，另外留了「都不是，换个说法」的出口，猜错了不用重开对话。
- 本机开发也能搜地点：本机走 3199 代理的高德与天地图双源，合并去重后按相关度排序，新开业的商业体也能被搜到，不必先部署到线上才能验证。
- 本地代理常驻：Next dev 与地图代理作为独立进程运行，代理不会因为一次对话结束被带走，你重新打开页面还能继续搜地点和铺物料。

**改好了什么**
- outdoor_v1 完成预算提到 4096：户外这类要同时给分区、动线与物料的长提案不再被中途截断，模型输出能被完整解析成结构化结果交给画布。
- 登录闸门位置明确：未登录判定放在发请求之前的前置闸门里，失败会被转成登录提示，而不是把异常直接抛到界面上变成一句看不懂的报错。
- 候选检索按需发起：进入场地确认环节才开始检索，页面初始化时不会抢跑地图请求，没开始对话时不会有一堆无谓的网络调用。
- 品牌选中态改读 token：交付面板选中项文字改读 `--green-deep` 的 `#35624A`，新增 `PLANNING_SURFACE.selectedText`，组件里不再硬编码色值。
- 版本号三处对齐：前端 `package.json` 升到 4.12.0，与根目录 `package.json` 以及两份 CHANGELOG 的最新版本段保持一致，机器校验可一次通过。

**边界与未做**
- 四轮验收还差两轮：分区与物料提案这一输出量最大的模型回合没有实测数据，因为场地边界始终没能锚定，4096 预算在该回合的表现仍缺直接证据。
- 真实轮廓取不到就转手画：公开地图源不可用时明确提示并进入手画闭合，不用臆造轮廓充数，因此 2D 视图的底图在外部故障期间可能是空的。
- 标注预览仍在开关后面：Agent 读取规划标注只做预览，启用前探测数据库保护版本，缺失时不建任务也不调模型，默认保持关闭状态。
- 三维视图依赖硬件加速：内置浏览器拿不到 WebGL 时会降级并给出提示，要看完整底图与三维效果请在本机浏览器打开同一个本地地址。
- 历史版本段按规范下移：前端此前的旧格式记录移到文末附录区，附录之前只保留合法版本段，方便机器校验与人工检索。
- 中间版本没有补记：前端 CHANGELOG 在 v1.0.0 之后未随发布更新，本次按当前口径补记 v4.12.0，其间的版本以远端 tag 与发布记录为准。
- 仓库还有别的会话的未提交改动：本次只提交前端品牌 token 与版本记录相关文件，其余改动原样保留，没有代为回退也没有混入这次提交。
- 本地与线上返回同构数据：线上走同源地点检索接口，本机走本机代理但结构一致，前端不需要为环境写两套解析分支，界面表现也一致。
- 候选顺序有确定规则：按名字完全命中、前缀命中、包含命中再到地址命中依次打分，同分保持原序，列表里的先后不是随机抖动出来的。
- 地图源故障按失败处理：超时或被拦截时记录原因，不用回退数据掩盖，也不因为外部故障放宽坐标与名称的校验口径。

## v0.4.1 — 2026-10-02

把 `assets/library/online.json` 的 234 件模型接入 `frontend/` 的物料库面板，沿用 v0.4.0 的视觉框架（浅色面层 + 深青 `#0e7c78`），不新增深色顶栏。

- 清理死代码：用脚本从 CSS 抽类名、逐个反查 TS/TSX 与复合选择器，删掉 `清单` tab 与「真实 GLB 加载验证」区块移除后再无引用的 `sc-count` / `sc-sample-section` / `sc-library-footer` / `sc-success` / `sc-object-list` / `sc-object-dot`，以及无引用的 `cr-references`（含 hover 规则里的对应选择器）。
- 统一 tab 标题：需求面板的「先说说，你的想法。」原来走创意面板自己的 23px / 字重 550 / 绿色 `#34483e`，跟场地面板的「场地设置」不是一套；现在两者都改用工作台的 `.sc-section-heading`（16px / 500 / -0.4px），并让该标题显式取 `--sc-ink`，不再依赖父级继承色。随之删掉 `cr-heading` 的 3 条规则。
- 删减文案：物料库面板不再保留「线上模型库 / 点击下载并放入场地」标题（tab 已表明内容，工具栏顶部由 y=248 提到 y=181）；需求面板去掉 `FROM BRIEF TO SPACE` 与「一份需求，展开成一整个现场。」；「布置思路」由三篇静态文章改为**一张可刷新的卡片**，点右上角按钮按顺序轮换 3 条思路。
- 面板 tab 重构为 `物料库 | 需求 | 场地`：需求面板（`CreativeBriefPanel`）从物料库拆出独立成 tab——物料库与需求是两件事，此前 1681px 的需求表单压在模型库上面，模型库要往下滚很久才露出来；`清单` tab 删除（选中物件的属性由右侧属性栏承担）。
- 物料库面板收敛为线上模型库：标题改为「线上模型库」，分类栏改成**一行横向滚动**，搜索收成它右侧常驻的窄框（只露出放大镜，聚焦时展开 96px），每步 24 张分段展开。工具栏顶部位置从 y=1955 提到 y=248。
- **行为变更**：内置的 8 件活动物料（`EVENT_CATALOG`）与「真实 GLB 加载验证」区块从物料库面板移除，面板不再区分来源。`EVENT_CATALOG` 仍用于拖拽解析（`room-organizer.tsx`）与抽屉里的 `FurnitureCatalogPanel`，未做删除。
- 新增 `lib/online-models.ts`：懒加载仓库内的 `assets/library/online.json`（约 110 KB，动态 `import`，不进入首屏包）。同时接受裸数组与 `{ modelCount, models }` 包装对象；归一化时丢弃无法落位的行、按 `slug` 去重、把尺寸夹到工作台数字输入可接受的范围（0.02–50 m）、把不可用的缩略图降级为占位。
- 新增 `panels/online-model-library.tsx`：13 个分类芯片（中文标签，按数量降序）、中英文搜索（匹配名称 / 中文子类 / slug）。点击后先 `ensureGlbAsset` 下载并校验，再以 `source: 'public_library'` 落位并自动选中。
- 材质属性栏的来源标签改为优先按 `source` 判定：线上模型没有 `assetId`（`schema.ts` 要求它是 UUID），只按 `glbUrl` + `assetId` 组合判断会把它误标成「本地 GLB 验证样例」。
- 物料属性面板同步适配线上模型：摘要图改用它自己在 CDN 上的渲染图（由 `glbUrl` 推导同目录的 `thumb.webp`，失败则回退矢量图标；此前是白色矢量占位图，在浅色面板上几乎看不见）；GLB 模型的色板与取色器本来就是整段 `disabled`，改为一句话说明；不再把模型 slug 写进「物料备注」，备注留给用户（模型身份由 `glbUrl` 承担）。
- 线上模型的缩略图与 GLB 直连 CDN（`cdn.3dassets.dev`），首次点击需要可访问外网的网络；下载沿用现有 30 秒超时，超时或失败会在面板内提示且不落位（避免把一个看不见的对象放进场地）。
- 线上模型只支持点击添加，不参与拖拽：拖拽负载用「类型 + 名称」在静态目录中反查，线上目录不在其中，做成可拖拽会拖不出东西。
- 修正 v0.4.0 配色迁移遗漏的 6 处植物绿（`#aabe96` / `#e7eddf` / `#e9eedf` / `#c4d5a8` / `#d7e6c5`）：按钮、卡片与标签的 hover 底色和描边、标签激活描边、品牌 logo 中间竖条、页头 focus ring 全部改回深青族。
- 修正登录页与工作台页头停留在 v0.3.0 的版本号。
- 已知约束：线上模型是「有 `glbUrl` 但没有 `assetId`」的形态，`backend-adapter.ts` 对该形态会抛 `LOCAL_ASSET_NOT_UPLOADED` 以阻止云端保存。本地草稿保存不受影响；接入云端后需要单独决定线上模型的存档方式。
- 验证（Node 24.15.0）：`vitest run --maxWorkers=4` **1411/1411**（新增 35 条，含直读真实目录的集成测试与来源标签断言）；`tsc --noEmit` 0 错误。
- 浏览器实测：234 件模型 / 13 个分类计数正确，24/24 缩略图自 CDN 加载成功，CDN 上的 GLB 通过仓库自带 `validateGlbBuffer` 校验（`0x46546c67` / GLB 2.0 / 长度自洽），分类栏单行横向滚动、搜索框收起宽度 0、聚焦后 96px，点击后场地物料数 +1。
