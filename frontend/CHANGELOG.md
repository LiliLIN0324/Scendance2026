# 前端版本记录

前端独立递增：修复使用 v0.4.1、v0.4.2，下一批功能使用 v0.5.0。后端版本不随前端升级。

## v0.4.1 — 2026-10-02

把 `assets/library/online.json` 的 234 件模型接入 `frontend/` 的物料库面板，沿用 v0.4.0 的视觉框架（浅色面层 + 深青 `#0e7c78`），不新增深色顶栏。

- 物料库面板收敛为线上模型库：分类栏改成**一行横向滚动**，搜索收成它右侧常驻的窄框（只露出放大镜，聚焦时展开 96px），每步 24 张分段展开。
- **行为变更**：内置的 8 件活动物料（`EVENT_CATALOG`）与「真实 GLB 加载验证」区块从物料库面板移除，面板不再区分来源。`EVENT_CATALOG` 仍用于拖拽解析（`room-organizer.tsx`）与抽屉里的 `FurnitureCatalogPanel`，未做删除。
- 新增 `lib/online-models.ts`：懒加载仓库内的 `assets/library/online.json`（约 110 KB，动态 `import`，不进入首屏包）。同时接受裸数组与 `{ modelCount, models }` 包装对象；归一化时丢弃无法落位的行、按 `slug` 去重、把尺寸夹到工作台数字输入可接受的范围（0.02–50 m）、把不可用的缩略图降级为占位。
- 新增 `panels/online-model-library.tsx`：13 个分类芯片（中文标签，按数量降序）、中英文搜索（匹配名称 / 中文子类 / slug）。点击后先 `ensureGlbAsset` 下载并校验，再以 `source: 'public_library'` 落位并自动选中。
- 材质属性栏的来源标签改为优先按 `source` 判定：线上模型没有 `assetId`（`schema.ts` 要求它是 UUID），只按 `glbUrl` + `assetId` 组合判断会把它误标成「本地 GLB 验证样例」。
- 线上模型的缩略图与 GLB 直连 CDN（`cdn.3dassets.dev`），首次点击需要可访问外网的网络；下载沿用现有 30 秒超时，超时或失败会在面板内提示且不落位（避免把一个看不见的对象放进场地）。
- 线上模型只支持点击添加，不参与拖拽：拖拽负载用「类型 + 名称」在静态目录中反查，线上目录不在其中，做成可拖拽会拖不出东西。
- 修正 v0.4.0 配色迁移遗漏的 6 处植物绿（`#aabe96` / `#e7eddf` / `#e9eedf` / `#c4d5a8` / `#d7e6c5`）：按钮、卡片与标签的 hover 底色和描边、标签激活描边、品牌 logo 中间竖条、页头 focus ring 全部改回深青族。
- 修正登录页与工作台页头停留在 v0.3.0 的版本号。
- 已知约束：线上模型是「有 `glbUrl` 但没有 `assetId`」的形态，`backend-adapter.ts` 对该形态会抛 `LOCAL_ASSET_NOT_UPLOADED` 以阻止云端保存。本地草稿保存不受影响；接入云端后需要单独决定线上模型的存档方式。
- 验证（Node 24.15.0）：`vitest run --maxWorkers=4` **1411/1411**（新增 35 条，含直读真实目录的集成测试与来源标签断言）；`tsc --noEmit` 0 错误。
- 浏览器实测：234 件模型 / 13 个分类计数正确，24/24 缩略图自 CDN 加载成功，CDN 上的 GLB 通过仓库自带 `validateGlbBuffer` 校验（`0x46546c67` / GLB 2.0 / 长度自洽），分类栏单行横向滚动、搜索框收起宽度 0、聚焦后 96px，点击后场地物料数 +1。

## v0.4.0 — 2026-10-02

功能版本。在 v0.3.0 基础上合入模型物料库，并统一品牌、配色与导航。

- 合并 `feat/model-library`：新增 `scene/` 模型场景模板与模型库工具（独立静态页 + GLB 缩略图目录 + `tools/catalog` 生成脚本）。
- 品牌统一：全仓「场域」改为「幕景」，含 `frontend/` 实现文案与测试断言同步，避免断言失配。
- 主色统一为深青 `#0e7c78`（原站紫色仅作研究参考），工作台面层色与语义色保留。
- 首页与工作台双向导航：首页「进入场景」跳工作台；工作台品牌 logo 跳回官网。
- 前端阴影类型收口：`use-three-scene.ts` 的 `THREE.PCFSoftShadowMap` 改为 `THREE.PCFShadowMap`（r186 已移除前者，渲染结果不变）。
- 合并队友 `c720dc7`：GPT 提案交接文档（纯文档，+142/−3）。
- 仓库根目录侧改动详见根 `CHANGELOG.md`：静态首页替换、渲染器阴影枚举同步、Windows 开发服务器 `serve.py`。
- 验证（Node 24.15.0）：`vitest run --maxWorkers=4` 1376/1376；`tsc --noEmit` 0 错误；后端 54/54。

## v0.3.0 — 2026-10-02

- 统一页面配色，保留三维优先；增加现有三种灯光预设的实时切换与场景保存。
- 现场照片可放大、删除、连续选图，校验与跨项目隔离；介绍页往返保留，刷新需重选。
- 新增可编辑现场条件、风格、配色与氛围；助手使用完整需求、确认决定与近期对话，不截断必需条件。
- 补齐登录加载/错误/重试验证，以及 v0.3 最新后端交接 MD。

- 图片入口明确为“现场照片（选填）”，用于真实场地资料；当前不识别照片、不自动还原场地。

- AI 提案在三维画布呈现临时差异；放弃、过期或草稿改变后清理，预览不保存、不进入撤销历史。
- 对可靠识别的缺少物料、规格差异作保守提示；未经确认不替换物料。
- 保留 v0.2.0 的介绍页、图文需求入口、助手、氛围，以及移除 JSON 按钮的产品界面。

## v0.2.0 — 2026-10-02

- 新增介绍/登录页面，与编辑器共享会话，可进入本地体验。
- 在现有物料区提供参考图片、文字需求和 Generate 入口；不新增独立栏目或灵感快捷按钮。
- 隐藏物料区底部“导入 JSON / 导出 JSON”，保留本地自动保存。
- 新增右下角助手及提案确认，建议不会自动写入场景；场景变化后拒绝旧提案。
- 三维场景使用真实氛围灯光与阴影，兼容既有 neutral/warm/cool 字段。
- 明确图片目前只在本机预览；扩展物料、完整创意生成和通用问答等待后端支持。
- 后端交接：[FRONTEND_V0.2_BACKEND_REQUIREMENTS](../docs/FRONTEND_V0.2_BACKEND_REQUIREMENTS.md)。
