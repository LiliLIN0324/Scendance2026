# Frontend model provenance

`public/assets/models/*.glb` and `public/assets/catalogue.json` are byte-for-byte copies of the repository's existing model files. Full origin URLs, CC0 1.0 licence records and SHA-256 values remain in [the original asset record](../ASSET-SOURCES.md) and the bundled catalogue.

The working GLB example uses `table.glb` (3DAssets.dev, source ID 25917). It is a pre-existing public-library model, not a new model generated by this app. No model-service call or purchase occurred in this task.

The upstream people model and its attribution remain in `components/room-organizer/assets/`. NPC and residential features are hidden from this event editor; retained internal code allows incremental adaptation without replacing the tested history/renderer implementation.
