# 统一 Agent 入口

日期：2026-10-03。基线：`159f53f`。工作分支：`codex/unified-agent`。

## 行为

- 右下角唯一 Agent 入口：场景策划（DeepSeek）与 3D 生成（腾讯 HY-3D-3.0）。移除左侧需求标签、物料库内生成表单及云项目内重复生成任务标签；个人云素材浏览、授权预览和加入画布保留。
- 策划页默认使用“发送后直接应用”，取消勾选可先预览。聊天始终使用 `modify`，包括空场景中的单件添加；只有空 v1 场景的完整需求表单使用 `layout` 模板。未填写需求时不会把默认活动类型与人数当作聊天要求。
- 应用仍走真实 `proposals/apply`，检查租约、场景哈希、修订号、过期和项目归属，通过 `acceptedLocally` 后写入画布并保留一次撤销。生成期间场景或需求变化时不应用旧结果；直接应用后仍显示布局警告。
- v2 场景保留结构、来源、尺寸和表面信息；文字策划不发送或识别图片。既有图纸/照片识别、尺寸核对与确认流程位于“活动需求与场地资料”中。
- 3D 页沿用服务端生成、查询、授权模型与加入场地接口。标签切换/收起保留面板实例和输入，状态查询不再次提交生成。旧两个入口的未确认请求编号均可恢复，依次核对，不静默覆盖或创建新编号；损坏或不可写存储阻止新提交。
- 生成模型仍需使用真实资产、设定尺寸、加入场地并云端保存，服务器确认场景含资产后才标记任务已保存。
