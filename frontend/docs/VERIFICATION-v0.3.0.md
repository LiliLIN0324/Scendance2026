# v0.3.0 验收记录

日期：2026-10-02。范围：frontend 与授权交接文档；后端与共享协议未修改。

## 自动检查

- Node 24；`vitest run --maxWorkers=4`：100 个文件、1376 项测试全部通过。
- TypeScript 与 ESLint 通过；Next.js 15 静态生产构建成功，无构建警告。
- 测试包含实际 HTTP／后端处理器／本地 PostgreSQL 测试库；Auth/Storage 使用显式测试实现，不能当真实云端验收。
- 浏览器 UI 的生成、确认、放弃、过期、草稿改变保护、失败恢复、旧项目迟到响应、助手连续上下文，使用明确的服务 mock 验证；没有实际付费 AI 调用。
- 照片校验涵盖格式、5 MiB、4096px、数量上限、连续异步选取、失败回滚、跨项目取消和资源释放。
- 助手 3000 字符预算：必需需求/确认替代/当前请求/最近提案说明完整保留；超限拒绝请求，仅整条省略旧对话并提示。
- 登录加载、防重复提交、错误密码、断网、本地体验、重试、共享会话使用测试实现验证。

## 实际浏览器检查

使用静态产物 `http://localhost:3018`，独立于用户的 `127.0.0.1` 草稿。

- 介绍页 → 本地工作台 → 返回介绍页 → 再进入：需求、现场条件、照片、助手消息仍在；刷新后内存中的输入/照片/对话清空。
- 当前无真实云配置：登录入口禁用且解释原因；Generate 显示未连接 AI，原画布保持，不展示伪造提案。
- 使用仓库 JPEG 截图作为**文件上传测试夹具**：选择、缩略图、点击放大、Esc关闭、焦点恢复通过。它不是用户实际场地照片，也不证明识图能力。
- 灯光：暖光与冷调切换可在三维画布观察；沿用实际 `backendLighting → Scene.lighting`。场景本地保存，云保存待真实环境验收。
- 1280×800 桌面、390×844 手机宽度：无页面横向溢出；助手展开后焦点进入输入框。额外在 372px 窄宽度检查了介绍页往返和照片。
- 物料区按用户要求恢复独立物料列表；桌椅组合、数量提示与额外清单联动已撤回。
- 桌面默认 3D，2D作为切换；米白/植物绿主配色一致；JSON 导入/导出按钮已移除。
- 浏览器 error 日志为空。

## 未经真实环境验收

真实 Supabase 登录、云项目双账号交接、真实模型生成与图片上传/视觉理解尚未完成。本版照片仅本机 blob 预览。完整创意规划、帐篷等扩展资产、通用问答、项目需求与会话持久化仍需后端支持。现场文字是用户输入，不是图像自动识别或精确测绘结果。
