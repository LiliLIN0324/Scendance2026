# 可编辑场景预设

入口：工作台左侧「场景预设」→「载入工作台」。

- 体育馆 · 黑客松：307 个物件（207 件家具 + 100 人）。
- 青序 · 香氛快闪：42 个物件（16 件完整陈设 + 24 位来访者 + 2 位店员）。
- 支持选择、移动、旋转、缩放、复制、删除、锁定、备注、撤销/重做，以及现有本地自动保存和刷新恢复。
- 场馆、墙面和地面使用原始模型，保持固定；屋顶/顶部灯架隐藏。快闪陈设按完整物件组合，台面、桌腿、饰条和产品随物件共同编辑。
- 载入前确认替换、记录恢复点并保留撤销。下载失败、加载过程中有新编辑或离开预设面板时，不覆盖当前画布。
- 预设模式的编辑物件上限为 500；普通场景继续使用 50。云端协议、数据库和生成服务保持原有契约。

## 数据和保存范围

预设使用前端 `RoomLayout.scenePreset` 指定固定场馆；每个物件用 `glbUrl + glbNode` 选取原模型中的陈设节点，并保存米制尺寸、位置、旋转和离地高度。多个物件共享一次模型下载，但渲染实例分别拥有材质和几何资源，编辑/删除不会污染其他实例。

这两个完整模型尚未注册为云端资产；场馆结构、离地高度及物件数量也超出现有云端场景协议。适配器明确阻止云保存和 AI 修改，不将其删减成普通场景后发送。界面显示「预设 · 本地保存」。云项目仍可通过原入口打开。

体育馆来自照片概念模型，内部 70 × 76 米工作范围只用于容纳周边布景，不展示为实测尺寸或使用面积。快闪的 12 × 8 米同样属于概念尺寸，人数不代表核定容量。

## 来源与构建

来源为 `codex/gym-scene-template` 提交 `f2ec7ebd58094e51b868528b1ff499bcd8ea9b0d`，原始 GLB、来源文件和 manifest 位于 `scene/templates/`。

`npm run dev` / `npm run build` 自动调用打包脚本，重组节点并将模型和缩略图输出到 `frontend/public/scene-presets/`，生产产物位于 `frontend/out/scene-presets/`。原始几何与贴图二进制保持不变，不需第三方模型接口。
