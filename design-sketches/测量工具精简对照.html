本轮改动要点

  • 入口钮 + 竖向下拉：一个入口钮显示当前模式，点开竖向菜单选择；距离 = 尺子，面积 = 框选矩形，路径 = 折线，选中行带对勾。
  • 删掉常驻长说明：不再把三种手势堆在一行，只在当前模式下给一句短引导（右卡点入口钮切换查看）。
  • 完成钮文案缩短：完成测量（N 点） → 完成（N 点）；点数不足保持禁用，距离两点自动提交、无需完成钮。

这三个模式分别量什么

模式点数算出的结果典型用途手势
距离2 点 两点之间的直线段长 设施间距、净距、边界段长 点两点，或拖一条线；够两点自动成线
面积3–64 点，闭合环 围合区域的占地面积 场地、分区、展位占地核算 拖矩形（Shift 正方形），或逐点描边、点回起点闭合
路径2–64 点，折线 沿走向的折线累计总长 步道、排队动线、巡游路线长度 按住手绘，或逐点加路点、双击结束

成熟案例怎么做

Google 地球 / 地图

尺子图标进入测量；逐点加点，底部小卡实时显示累计读数；双击末点或勾选 Done 完成；面积用多边形闭合。

可借鉴：读数就近显示在轻量卡片上，完成动作很轻（双击 / 勾选），不长篇说明手势。

Figma / Miro

按住 Alt / Option 悬停对象，即时出红线和横竖读数；不进面板、不留下测量结果。

差异：它们是临时间距提示；我们的测量要留存成可回看的标注，所以保留完成钮把结果固定下来。

平面规划工具（Visuary 类）

左轨尺子图标进入测量；距离线和房间面积直接标在图形旁，读数贴着图形走；酷家乐 / 模袋云同类做法为量尺图标 + 点吸附，右键或 Esc 退出。

可借鉴：图标入口 + 读数上画布；我们把距离 / 面积 / 路径收进同一张卡，三选一切换。
