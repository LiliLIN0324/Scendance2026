维度正式站 · 现在草图 01为什么
一级工具 T + 矩形▾，其余 4 个藏在菜单里 改5 个常驻：T / 矩形 / 圆形 / 三角形 / 线段 只有 5 个，不值得多一次点击；点开菜单还会挡住画布。
颜色 工具条一排，菜单里又重复一排 改只保留选项行一排 同一个控件出现两次，会让人以为上面那排是“菜单颜色”、下面那排是“当前颜色”。
操作说明 菜单里写“2 点 / 3 点”，底部再写“按住拖，放点两个点” 改工具条下方一行，以当前工具名开头 “2 点”是实现细节；三角形 3 点、底部却说两个点，会自相矛盾。说明只该留一处。
选中态 细边框 + 文字，远看分不出哪个在用 改浅绿实底 + 1.5px 绿边 + 绿图标 画布工具靠“正在用哪个”判断手势；双属性比只换字色稳。
触达 约 32px 高，手机上偏小 改46px 外框 / 40px 视觉 手机为主场景，≥40 才不容易点错；五个并排仍放得下。
层级 一级 → 二级菜单 改无二级菜单；选项跟随当前工具 菜单只做“选工具”，选项只做“改样式”，两件事分开。

这一步只动什么

只改工具行和选项行：五个工具常驻、颜色/线宽并成一行、说明改成“工具名 + 手势”，选中态换成浅绿实底。不动画布、不动数据、不动其他面板。

  • 再点一次当前工具 / Esc 退出；画完一个是否自动回选择；
  • 360px 窄屏与真机触控验收。
