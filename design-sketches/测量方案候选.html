测量工具 · 三个方案候选

三张卡片都可点顶部模式切换；读数、提示与完成钮跟随当前模式。参考案例标注在每张卡下方。

方案 A · 主钮下拉

对标 Figma 形状下拉 / Excalidraw 工具栏菜单

测量 0

取舍：面板最省空间，变体收纳干净，选中态明确；代价是要多一次点击才能看到全部选项。

方案 B · 图标直排工具条

对标 Visuary 左轨量尺 / Miro 顶部工具条

测量 0

取舍：一眼见全部模式，点一次即切，最像工具条直觉；代价是横向占宽，图标标签弱化、需 hover 提示。

方案 C · 读数优先轻量卡

对标 Google 地图底部测距小卡

测量 0

取舍：读数就近、动作最轻，最像成熟测距产品；但我们要留存成可回看标注，完成钮仍需保留收口。
