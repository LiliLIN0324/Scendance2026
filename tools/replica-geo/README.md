# replica-geo · 案例配准与重描流程

把 OnePlan 参考图钉到真实影像上，重描成米制 ENU 几何，再写回产品 spec 与核对报告。
本目录取代 `.tmp` 里一次性脚本的做法；`.tmp` 仍保留历史过程产物，不再作为入口。

## 流程

1. `register.py` — 取 Esri z19 瓦片拼图，SIFT + RANSAC 求固定尺度刚性变换。
   用于影像与截图同源、季节差异小的情况。
2. `align_search.py` — SIFT 失败时的兜底：Canny 边缘做角度/尺度粗搜，ECC 精修。
3. `trace_overlays.py` — 按颜色分割原图上的分区/摊位/流线，输出像素级色块框。
4. `build_case.py` — 用配准矩阵把色块框换成真 ENU 坐标，生成 `spec.json`（分区/设施/路线/节点）。
5. `apply_case.py` — 单一写入器：写 `replica-specs-*.ts` 的对应块 + 替换报告段落 + 更新 `CASES`。
   只改目标 slug，其余案例不动；重复执行结果一致。
6. `qa_case.cjs` — 结构校验：43 段、43 地图、脚本语法、目标案设施数。

## 约定

- 尺度一次定死（本案 0.1036 m/px），坐标只做一次换算，不在渲染层二次缩放。
- 坐标写成真 ENU，`rotationDeg: 0`；参考图相对正北的角度只作为证据记录。
- 锚点必须标明来源：页面已记录 / 本次解算 / 现场确认，三者不混写。
- 报告数字一律从 `spec.json` 生成，不手抄。

## 本案（start-on-the-street）结果

- 配准：SIFT 2410 内点，0.1036 m/px，RMSE 0.052 m；参考图相对正北 -73°。
- 重描：7 区 / 83 件（60 摊 + 4 餐车 + 12 桌 + 3 车 + 3 舞台 + 1 剑士）/ 2 线 / 2 点。
- 锚点沿用页面已记录坐标；Google 与 Esri 影像可能有米级偏移，报告已写明。

## 已知边界

- 报告里本案仍走通用 canvas 渲染，没有像 Scotiabank 那样接产品贴纸渲染器。
- 抽查点是同一次 SIFT 变换的内点，只证明几何一致，不是独立 NCC 复核。
- 未做真实浏览器目检（file:// 限制）；滚轮/拖拽/全屏行为待验。
