## 3. P1 · 品牌基建（1–2 天）

### 3.1 一页品牌快照

- **链接不复制**：slogan 表指向 `docs/06`，色板/字阶指向 `docs/05`，logo 指向 `assets/brand/README.md`。
- 补缺规则：door 最小尺寸；错误用法示例（不加描边、不换色、不拆门洞、白眼不可单独使用）；安全区（字标高 ×1）沿用。
- **动效场景映射**：`assets/brand/logo-2026/motion/` 12 个动效逐个写一句「用在哪」（如 door-loading → 工作台启动态、door-enter → 演示视频开场），写进 `assets/brand/README.md`。

### 3.2 运行时去位图依赖

- `brand-mark.tsx` 从 `<image href="door.png">` 改用矢量（`door-128.svg` 等价版）；PNG 只保留 favicon / 小程序 icon 派生源职责。
- 派生关系（源 → 产物）写进 `assets/brand/README.md`。

### 3.3 独立仓同步

- 打「品牌包」同步 `scendance-capture`：door SVG 全档 + 字标规则（幕景 PingFang 600 + 绿点 + SCENDANCE）+ 色板 token 表 + 小程序 icon / 启动页替换。

**P1 验收**：任何端（Web / 小程序 / 导出物）的品牌呈现都能从 `assets/brand/` 一处溯源。
