## 0. 用户场景与拍板

用户对 Agent 说「**我想设计一个虚拟场地**」（没有真实地点、不想关联地图）——这类需求不该被推进「搜索目标地点 → 写入锚点 → 铺真地图」的地理主线，而应该**纸面起稿**：白纸 + 米制网格 + 自画边界 + 自由分区摆设。

用户拍板（2026-11-17）：

1. 纸面模式升为一等公民：进「地图类型」默认组 + 快速弹层（**本卡 §1 已落码部分，当日完成**）。
2. 「如果用户就是需要没有场地的话，那么我们就用这个（纸面）」——虚拟场地 = 纸面模式的主形态。
3. 深色档 Carto 境外线路问题**暂不修**（本机 dev 灰块可接受，线上 CF 正常；日后可议「高德瓦片+反色滤镜」方案，不在本卡范围）。

## 3. 边界与不做

- **不动** outdoor_v1 线上契约 schema（锚点 optional 是既有事实，只放宽校验/提示词）。
- 不做真地图与纸面混合渲染（半透明叠印之类）。
- 不把虚拟场地与 Aholo 扫描/重建资产关联（那是室内线的事）。
- 虚拟场地**必须有边界**：契约必填不豁免，起步矩形兜底、用户可重画。
- 深色档境外线路问题不在本卡（拍板暂不修，见 §0）。
