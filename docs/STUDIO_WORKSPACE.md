# 工作室管理

工作室统一管理成员，项目内展示继承的参与人员。工作室只有在没有任何项目时才能删除。

## 面板

- `/projects/`：固定工作室切换入口和项目、成员、设置导航；选择按账号保存在当前浏览器，已失去访问权的工作室不会继续被选中。
- 项目：只读取当前工作室的完整项目列表，项目详情显示所属工作室、版本及全部参与人员。新建项目明确标注归属。
- 成员：负责人添加或移除编辑成员；移除前说明会撤销全部项目访问权与编辑租约。项目不设置独立成员权限。
- 设置：仅负责人可以重命名和删除。重命名保持工作室 ID、项目归属和成员不变。只有项目与成员加载成功且项目为空时启用删除；输入完整工作室名称后再次确认。
- 编辑器云项目面板：工作室选择同时控制项目列表和新项目保存位置；当前打开项目单独显示其真实所属工作室。

## 数据与兼容

接口定义见 `docs/contracts/SUPABASE_BUSINESS.md`。新增迁移 `20261003094500_studio_management.sql`，不修改历史迁移。

数据库在删除前验证 owner、锁定工作室行并检查是否存在项目，已有项目外键保护并发创建；不迁移、不级联删除项目，也不删除账号。注册时的个人工作室只在首次确认邮箱时自动创建，后续账号更新不再重建主动删除的最后一个工作室。

前端样式使用独立 `sc-studio-manager` 前缀，避免与既有画布 `.sc-workspace` 冲突。既有项目租约、保存与交接逻辑保持原有协议。
