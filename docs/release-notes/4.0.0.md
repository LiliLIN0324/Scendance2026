# 4.0.0 智能建造升级 — 给丽丽的变更说明

> 这一版不再是「能摆家具」，而是「会判断布局好不好」。核心变化三件事，全部可在草案卡上直接看到。

## 一句话总结

之前出方案只给一个分数；现在会**主动告诉你哪里不能走、哪里挤、哪里堵了门**，并按「容量 / 动线 / 人体」三个维度分别打分。

## 用户能直接感受到的变化

### 1. 草案卡从「一个总分」变成「三档 × 三维子分」
- 松 / 适中 / 密三版各自显示：**容量 X 分 · 动线 Y 分 · 人体 Z 分**（0–100）
- 不再是一个裸数字，你能看出「这版座位多但通道挤」这种 trade-off

### 2. 三版方案真不一样了
- 松版：少摆一桌一椅，留出更宽通道
- 密版：通道自动收紧 0.3 m，更挤但坐更多人
- 之前三版经常同分（都是 12），现在密度、通道、座位数都拉开差距

### 3. 草案卡底部列出「硬伤清单」（violation）
每条都用大白话说人话，例如：
- 「椅距太近，坐下会蹭到隔壁」
- 「主通道只有 1.3 m，轮椅过不去」
- 「休息区被桌椅围死，人走不过去」
- 「休息区入口被长椅堵了一半」
- 「签到区走到不了圆桌区」
- 「4 件家具互相压住」

绿色左边框 = 硬伤（会扣分），灰字 = 提醒。
