## 3. 四柱边界

### A · 3D / 场地

- **用户任务一句**：从空白或底图得到可编辑、米制、室内外分明的单层场地，再进入布置。
- **本期 in**：空白场地；图片底图投影（仅参照）；人工 L×W（1–500 m）；室内/户外；工具列导航/量测；单位米 + wall≠furniture。
- **明确 out**：DXF-first（下一 MVP）；DWG/PDF 原生；照片自动测建筑；多层/吊挂；消防承重认证；假墙渲染。
- **验收 PASS（各 3）**：
  1. 空白进场 → 预填卡可见 → 可不上传直接出方案。
  2. PNG/JPG/WebP 松手铺底图，**无**「读到 xx m」识别话术；未填 L×W 主按钮不可点。
  3. 仅户外露雨天提议；DXF/DWG/PDF 本期画布不变、不渲染结构。

### B · 布置修改

- **用户任务一句**：在真实 3D 场景里选移旋缩、库放置、撤销，并让 Agent 提案可视化后再确认写入。
- **本期 in**：选/变换/复制删除锁；物料抽屉放置；属性米制；撤销重做同栈；Agent propose→预览→确认；重叠/超出琥珀标。
- **明确 out**：实时多人同编；写实渲染；任意 CSG；自动满场排座；物理碰撞仿真；静默覆盖选择。
- **验收 PASS（各 3）**：
  1. 库放置后可变换；撤销一步回到放置前。
  2. Agent「挪舞台」→ 绿框新位 + 虚线原位 → 确认/撤回；确认前不写场景。
  3. 锁定件工具与 Agent 均不可改；提案报出跳过项。

### C · 交付（客户评审 ≠ 执行资料）

- **用户任务一句**：评审阶段给客户只读看方案；执行阶段给工作室导出本机搭建资料——两套勿混称。
- **本期 in**：评审 → `/view/` 或离线 HTML（无编辑控件）；分享可撤销；执行 → 工作单/安排/点验/CSV·JSON·GLB·交接 HTML（以现网为准）；左轨切换不丢场景。
- **明确 out**：电子签/收付款/开票；甲方意见回流闭环；未验收的「云端执行双人协作」宣称；客户页泄漏 Agent/库。
- **验收 PASS（各 3）**：
  1. 评审主路径一键到只读链接或等价 HTML；客户页无编辑 UI。
  2. 撤销分享后访问拒绝。
  3. 执行导出至少一类内部文件且件数与场景一致。

### D · Agent（晴光）

- **用户任务一句**：用对话完成 intake、出可编辑初稿、解释冲突、为交付预填字段——始终建议→预览→确认。
- **本期 in**：晴光命名 + 3D 毛绒头像；chat-first 右栏；预填卡；做好了/发现问题；白名单 tool loop；破坏性确认；氛围提议只开工具列同一控件。
- **明确 out**：HY3 新生成（RETIRED）；跨项目长期记忆；静默 navigate 离画布；编造库存价格消防；扁平/Bingo 形象。
- **验收 PASS（各 3）**：
  1. 首屏预填可改后出方案；进行中可停，已摆保留；失败琥珀可重试。
  2. 状态「做好了/发现问题」可见；无狗/扁平头像。
  3. 无静默 apply；工具循环不擅自跳 `/projects` 或外链。
