### 2. 字体排版 ✅

**字体家族**：西文与数字用 **Inter**，Arial 只做降级（v2.3 裁决，2026-10-28 定稿）；中文用思源黑体。工作台通过 `next/font/google` 构建时自托管 Inter（`--font-inter`），运行时不依赖 Google CDN。降级序列：

```css
font-family: "Inter", Arial, "Noto Sans SC", "Source Han Sans SC", "Source Han Sans CN",
  "PingFang SC", "Microsoft YaHei", sans-serif;
font-variant-numeric: tabular-nums;
```

**标题层级（Headings）**

| 级别 | 字号/行高 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| H1 | 24 / 34 | 600 | ink | 页面主标题、空状态大标题 |
| H2 | 20 / 28 | 600 | ink | 分区标题、模态标题 |
| H3 | 16 / 24 | 600 | ink | 面板标题（Agent）、卡片标题 |

**正文与辅助（Body & Controls）**

| 级别 | 字号/行高 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| 正文 P1 | 14 / 22 | 400 | ink | 消息、正文、输入文字 |
| 控件 C1 | 14 / 22 | 500 | ink / ink-soft | 按钮、tab、菜单项 |
| 辅助 P2 | 12 / 20 | 400 | muted | 说明、占位、meta |
| 标注 CAP | 11 / 16 | 500 | muted · 字距 `.08em` | 区块标签（如「物料库」）、徽标；中文不加字距时可用 500 字重区分 |

规则：全产品只允许这 7 档；强调用字重 600；中文禁用斜体；英文标签大写必须配字距 `.08em`。

**同区三档（v2.5 新增 · 硬规则）**：任何同一视线区域——一个面板、一个弹层、一条工具栏、一个卡片组——**同时可见的字号不得超过 3 档**。执行细则：

1. 相邻近档不同区并用：`CAP 11` 与 `P2 12` 不得出现在同一区域；区域内需要更小的标注时，整区把 `--fs-cap` 重钉为 `--fs-p2`（如 Agent 面板的做法），使该区只剩「标题 / 正文 / 元信息」三档。
2. 品牌字标（Brand Lockup）按 §三.3 自成体系，其 10px/15px 不计入所在区域的档数。
3. 禁止面板自建私有字号系统：一律引用全局七档 token；局部只能重钉既有 token 的取值，不得发明新数值。
4. 字重是第二层级轴：同档内用 400 / 500 / 600 区分主次，不靠加大字号。

**响应式字号**：工作台桌面优先；≤640px 进入阅读态时 H1 20、H2 18、H3 15，正文不变。

**中英文混排**：中文与西文/数字之间加一个空格（如「使用 Figma 设计」「共 12 件物料」）；标点用全角。

### 3. 网格布局与间距 ✅

**断点**：`≤640` 移动阅读态 · `641–1024` 窄桌面（右栏折叠）· `1025–1440` 标准工作台 · `>1440` 大屏（画布上限 1280 居中）。

**工作台栅格**：左轨 64px + 画布弹性（约 55–70%）+ Agent 300px，区块间 16px 硬边界、全高发丝线分隔；底部 MATERIALS 通栏 40px。

**间距步进（4px 基准）**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`
Token：`--sp-1`…`--sp-8`。组件内边距用 8/12/16，区块间距用 16/24，分区间距用 32/48。

### 4. 图标与阴影 ✅

**图标（lucide-react 1.48）**：UI 图标唯一来源。网页端不小于 16px——16（行内下限：文字旁、列表内）、20（按钮、输入、面板头）、24（左轨、画布工具条、缺省图与空态）；32 是唯一上限档，只给整页空态与引导卡的主图标，不进工具条、表格与按钮；12 只允许出现在徽标内的非交互小标记，不进按钮、菜单与可点区域；不用 14 / 18 / 22 这类中间值。统一 stroke 1.75（24 网格下比默认 2 更轻更稳）、圆头圆角；单色继承 `currentColor`，禁用态换 `--faint` 而不降透明度；不混用填充风格。

**禁则**：emoji 当图标、混入第二个 UI 图标库、填充双色/加粗描边、图标作唯一信息载体、用品牌绿画图标、触达区 < 32px。

**圆角（Radius，原则：大方，宁大勿小）**

| Token | 值 | 用途 |
|---|---|---|
| `--r-sm` | 10px | 按钮、输入框、小控件 |
| `--r-md` | 14px | 卡片、菜单、弹窗 |
| `--r-lg` | 18px | 模态、大容器 |

圆角语言与品牌标志一致（厚实圆角，参考 ChatGPT / DeepSeek 一类干净形制）；禁止 4px 以下的「胆怯圆角」与超过高度一半的胶囊（发送键圆形除外）。

**阴影与层级（Elevation）**

| 级别 | 参数 | 用途 |
|---|---|---|
| E0 | 无阴影 | 默认一切元素，分区靠 1px `--hair` |
| E1 | `0 6px 18px rgba(20,20,22,.10)` + 1px hair 描边 | 菜单、popover、tooltip、toast |
| E2 | `0 16px 48px rgba(20,20,22,.18)` + 1px hair 描边 | 模态、抽屉，配 32% 墨色遮罩 |
| E3 | `0 1px 2px rgba(20,20,22,.06)` | 唯一例外：左轨激活卡 |

禁止彩色投影、大扩散柔影、默认给卡片投影。

## 二、UI 组件库

### 1. 基础控件 ✅

**按钮（5 种交互状态：常规/悬停/聚焦/点击/禁用）**

| 类别 | 形态 | hover | active | disabled |
|---|---|---|---|---|
| primary | 墨底白字 P1/500，高 36，`--r-sm` | `#2A2C31` | `#3D3F45` | bg plane · 字 faint |
| secondary | 白底 1px hair，字 ink | bg plane | bg plane-deep | 同上 |
| ghost | 透明，图标 ink-soft | bg plane | bg plane-deep | 图标 faint |
| danger | 白底 1px `--err`，字 `--err` | bg `#FBF1F0` | bg `#F5E2E0` | 同 primary 禁用 |
| text | 无底文字，C1/500 | 字变 ink | 字 faint | 字 faint |

聚焦态一律 `:focus-visible` 外描边 2px `--ink-soft`、offset 2px。accent 发送钮是 32px 绿色圆形，仅此一处。

**输入框（Text Fields）**：高 36、`--r-sm`、白底 1px hair、P1 文字。状态：占位（P2 muted）→ 输入中（border `--ink-soft`）→ 错误（border `--err` + 下方 P2 红字）→ 成功（右侧 16px 绿勾）→ 禁用（plane 底 faint 字）。聚焦不用 ring 阴影。

**选择器（Selectors）**：单/复选选中用 `--green` 实心，未选用 1px hair 白底；开关开用 `--green`、关用 hair；下拉与输入框同形。选中一律品牌绿，不做绿底容器。

### 2. 导航架构 ✅

**顶栏（48px，吸顶）**：左起 字标（Icon 28 + 幕景 15/600 + 绿点 + SCENDANCE 11）→ 1px 竖线 → 项目名 14/600 → 保存态胶囊（本地草稿 / 正在保存… / 已保存到本机）。右端只放两个入口：`项目`（FolderOpen）与头像（UserRound）；中部不放 tab。

**左轨（64px）**：布置 / 评审 / 执行 三态单选，只切上下文、不弹面板；底部常驻 `设置`。

**入口分工（一个动作只留一个入口）**：

| 入口 | 打开 |
| --- | --- |
| 顶栏「项目」 | 我的项目（projects）：新建、打开、另存为云项目 |
| 顶栏头像 | 素材库（assets） |
| 左轨「设置」 | 团队与权限演示、发布管理（team / publication） |
| 左轨三阶段 | 换 workbench-mode，不弹窗 |
| 右栏 Agent | 唯一生成入口：出方案、改尺寸、导出 |
| 底部物料薄条 | 物料库，拖入画布即成物件 |

**标签页（Tabs）**：只出现在面板内，下划线式——激活项 2px `--ink` 下划线 + 600 字重；未激活 P2 muted。

**面包屑与分页**：面包屑 P2 muted、当前项 ink；分页为 ghost 数字钮 + 激活墨底圆钮。

### 3. 数据展示与反馈 ✅

**表格**：表头 CAP 级 muted、底 hair-soft；行高 40、行间 1px hair；文本左对齐、数字右对齐（tabular-nums）；hover 整行 bg plane；不用斑马纹。排序图标 16px。

**卡片**：白底 1px hair、`--r-md`、内边距 16；无默认阴影；hover 可把 1px `--hair-soft`→`--hair` 加深。

**弹窗体系**：

- 模态：居中，宽 `min(560px, 100vw-32px)`，`--r-lg`、E2、32% 墨遮罩；H2 标题 + ghost 关闭；底部右对齐 secondary+primary。
- 抽屉（Drawer）：右滑入，宽 360，白底左侧 1px hair，E2；其余同模态。
- 警告（Alert）：白底 1px hair、左侧 3px 语义色竖条、P2 文字，`--r-sm`。
- 轻提示（Toast）：白底 1px hair、`--r-md`、E1；左侧 6px 状态点 + P1 文字；顶部居中浮出，3.2s 自动退场。

**加载（Loaders）**：全屏遮罩 = 32% 墨色 + 白卡 spinner；局部 spinner 16px `--ink-soft` 旋转 800ms；骨架屏 = `--plane` 圆角块，1.2s 呼吸（opacity .5–1）。

## 三、交互、内容与无障碍

### 1. 动效与极端情况 ✅

**动效参数**：微交互（hover、淡入）120ms；弹窗/抽屉 200ms；模态 300ms；统一缓动 `cubic-bezier(0.2, 0, 0, 1)`；入场淡入 + 上移 2px；`prefers-reduced-motion` 时全部直切。

**极端情况**：单行溢出 ellipsis；多行 line-clamp 2 并保留 title 提示；加载失败 = P2 说明 + ghost「重试」按钮；404/500 = H2 标题 + P2 说明 + secondary「返回工作台」，插画区留白不画。

**空状态**：白底居中，H3 标题 + P2 说明 + primary/secondary 行动钮；不用插画，最多一个 24px 线性图标（整页空态的主图标可到 32）。

**缺省图（占位图）**：内容未到位时出现的图只有一种画法——`--plane` 底 + 1px `--hair-soft` 描边 + 居中单色 faint 线稿图标 + CAP 文案。不用插画、截图、渐变、logo 水印、彩色投影与品牌绿。比例固定、不重排，缩放只换图标档位（24 / 20 / 16，整页空态主图标可 32）：

| 场景 | 比例 | 尺寸 | 图标 | CAP 文案 |
|---|---|---|---|---|
| 物料卡预览 | 1:1 | 112 | Box · 24 | 暂无预览 |
| 预设 / 模板封面 | 1.7:1 | 187×110 | SquareStack · 24 | 暂无封面 |
| 图纸 / 分享缩略 | 16:9 | 196×110 | FileImage · 24 | 预览未载入 |
| 成员头像 | 1:1 圆 | 40 / 32 | UserRound · 20 / 16 | 不写文案 |
| 列表小方图 | 1:1 | 48 | Box · 20 | 不写文案 |

**占位三态**：加载中 = 整块 `--plane` 呼吸 1.2s，不显示图标与文案；内容缺省 = `--plane` 底 + faint 图标 + CAP；加载失败 = 只把描边换成 `--err`、图标转 `--ink-soft`，原位给 ghost「重试」，不弹 toast。比例、底色、尺寸在三态之间都不变；图到位后 120ms 淡入盖住占位，不位移不缩放。缺省图只进 2D 容器——3D 画布的空场地由渲染器自绘地面，不贴占位图。

**缺省态规格**：全屏（画布 / 整页错误）最小高 240，图标 24 + H3 + P2 + 主次两个动作；面板（右栏 / 抽屉 / 底条）最小高 150，图标 24 + H3 + P2 + 一个动作；行内（表格行 / 列表项）一行 36–40，P2 一行 + ghost 文字钮，图标可省。只读态不给编辑类主动作、也不把按钮置灰，直接给「申请编辑权」；动作名与后续 toast 同名（空态「生成初始方案」→ toast「已生成初始方案」）。异常页 404 / 500 不加错误码、不画插画，只差标题与动作。

### 2. 错误与异常 ✅

错误只说三件事：**发生了什么、你的东西还在不在、下一步点哪**。语义色只做描边、图标与状态点，不做整屏红；同一件事只在一处报，不在 toast 和弹窗里各说一遍。

**四层错误面**

| 层 | 用在哪 | 落位 | 结构 | 动作 |
|---|---|---|---|---|
| 整页 | 404 / 启动失败 / 方案已移出 | 白纸居中，最小高 240 | H2 + P2，不画插画 | 主：返回工作台 / 重新加载；次：下载本地草稿 |
| 画布 | 三维不可用（WebGL、显卡、渲染资源） | 替换画布，居中 | 图标 24 `--err` + H3 + P2 + 折叠技术细节 | 主：重新加载；次：复制诊断信息 |
| 面板 / 行内 | 某条清单、某个预览没加载出来 | 原位，最小高 150 / 一行 36–40 | 图标 24 `--err`（行内可省）+ P2 | 仅 ghost「重试」 |
| 操作 | 保存、发布、上传失败 | 顶部 toast，3.2s 自动退场 | `--err` 状态点 + P1 | 文案里写出口：「重试上传」 |

**结构模板**：图标 24 `--err`（整页主图标可 32）→ H3 标题（≤10 字，说清发生了什么）→ P2 说明（东西还在不在 + 下一步）→ 一个主动作 + 一个次动作 → 折叠「技术细节」（等宽 11px、默认收起、可复制原文）。主区不出现英文报错原文、错误码与堆栈。

**动作规则**：主按钮只能是可恢复动作——「重新加载」「重试」「返回工作台」；破坏性动作（清空、覆盖、开始新方案）永远不做主按钮，且必须先给备份出口。错误页不给错误码；404 / 500 只差标题与动作，不画插画。

**画布错误**（WebGL / 显卡）：只替换画布本身，不动画布外的 chrome，不叠加 toast；技术细节折叠里放原文 + 三条可执行建议（打开硬件加速、更新驱动、换浏览器）。

**可访问性**：异步出现的错误区用 `role="alert"`（非阻断的用 `role="status"`）；不抢键盘焦点，动作钮可 Tab 直达；错误必须同时有文字，不只靠红色。

**文案**：说人话、给出路、不道歉不推责。✅「三维画布没能启动」→「通常是浏览器关闭了硬件加速。动作不会丢，打开加速再重新加载就能继续。」 ❌「WebGL context lost」/「发生未知错误，请联系管理员」。

## 四、Token 三层架构与治理（v2.4 新增）

> 本节回答「改一处主题为什么要在全库找替换」。现有 token 命名（`--green`、`--ink`…）已经是语义命名，全部归入 L1，**不重命名**，只补层级与规则。

### 1. 三层结构

| 层 | 定义 | 命名法 | 示例 | 引用权限 |
|---|---|---|---|---|
| L0 primitive | 原始值，与用途无关，全库唯一 | `--p-<色名>-<阶>` | `--p-green-500: #4A7C59`；`--p-gray-100: #E4E4E7` | **只准 L1 引用** |
| L1 semantic | 按用途命名，即本规范一~三章全部 token | 沿用现名 | `--green: var(--p-green-500)` | 组件 CSS 唯一入口 |
| L2 component | 个别组件私有别名，按需才建 | `--<组件>-<用途>` | `--agent-accent: var(--green)` | 仅该组件文件 |

**规则**

1. 组件 / 面板 CSS 禁止出现十六进制字面量与 `rgb()` 裸值；一切颜色经 L1。
2. 新的视觉决策先在 L1 加 token（写进本规范）再使用；禁止组件内私造同义值。
3. L0 只在 `globals.css` 出现一次；L1 声明一律 `var(--p-…)` 组合，不许混 hex。
4. 间距 / 圆角 / 阴影 / 动效 token 同样遵守三层：`--sp-*`、`--r-*`、E0–E3、动效时长即 L1，若未来出多主题再下探 L0。

### 2. 暗色模式 scope（显式声明）

**2026 赛季不支持全产品暗色模式。** 这是决策不是遗漏。唯一深底场景 = 官网 hero / 黑底卡片，使用品牌字标一节定义的 `.on-dark` 局部覆盖集；本规范所有对比度数值仅对白底校验。若未来立项暗色，只允许改 L0/L1，组件层零改动——这正是三层架构的前置条件。

### 3. 嵌套圆角（concentric radius）

内层圆角 = 外层圆角 − 内边距，结果小于 4 时**不用圆角**，改发丝线分区。

| 外层 | 内边距 | 内层圆角 |
|---|---|---|
| 模态 `--r-lg` 18 | 24 | 0（18−24<4）→ 分区用发丝线 |
| 卡片 `--r-md` 14 | 16 | 0 → 同上 |
| 卡片 14 | 12 | 2 → 仍用发丝线 |
| 浮岛 pill | 8 | 10−8 ≈ `--r-sm` 10 与 8 取 8 |

**禁则**：32px 以下高度的控件禁用 `--r-sm` 10（已近胶囊临界）；胶囊只属于发送键。

### 4. 等宽字体栈

```css
font-family: "SF Mono", "Cascadia Code", "JetBrains Mono", Consolas, "Courier New", monospace;
font-variant-numeric: tabular-nums;
```

只用于：错误「技术细节」折叠、代码片段、assetId / 错误原文 / 诊断信息；字号 11–12px。禁用于正文、按钮与 Agent 台词。西文正文仍是 Inter，两者不混用同一段文字。

### 5. Token 治理流程

1. 改值 / 新增：先改本规范（版本号 +0.1）→ 用户点头 → 改 `globals.css`。
2. 落地后全库 grep 校验：组件 CSS 无残留 hex 字面量、无未在规范登记的 token 名。
3. 废弃 token 不删除，标注 deprecated 并给替代名，下个赛季统一清。

## 五、AI 生成态设计（v2.4 新增）

> 本产品是 agent 驱动的工作台，「AI 在干活」不是加载态，是第一公民的界面形态。五原则先行，规格随后。

### 1. 五原则

| 原则 | 含义 | 禁止 |
|---|---|---|
| 过程即界面 | 生成过程可见、可中断、可撤回；进度是叙事不是转圈 | 只给 spinner 的等待 |
| 克制的机器感 | 智能靠排版、灰度与响应表达 | 紫渐变、发光、sparkle 泛滥、打字机音效 |
| 不确定性诚实 | 提案 ≠ 结果；缺信息就列「还差什么」，不猜 | 把 AI 输出伪装成既成事实 |
| 速度是美学 | 120ms 内必有可见反馈，流式优先于整体等待 | 点击后长时间无反馈 |
| 语言即 UI | 「说人话、给出路、不道歉不推责」贯穿 Agent 全部台词 | 客套、预告、总结性空话 |

### 2. 生成过程（过程即界面）

- 生成中 Agent 区**分步叙述**（P2 muted，逐行追加，如「读简报 → 摆座位 → 核对出口」）；完成后折叠为一行摘要（P2 muted），正文只留结果一句。
- **生成完成前不出确认钮**（呼应 T-05「生成完再亮确认」）；提案卡只在生成完成后出现。
- **生成可中断**：生成中发送键原位变为停止钮（同位替换，不并列两颗钮）；中断后已生成的部分保留并如实标注「未完成」。
- **可撤销**：确认落盘后 8s 内底部 toast 给「撤销」；画布改动一律走 provider `onApply` 进撤销历史（85ed11c 收口），不因是 AI 产出而绕过。

### 3. 流式输出规则

- 逐 token 渲染，尾随 1px 墨色光标，闪烁 800ms；流式完成光标即消失，不留残影。
- 流式期间按钮呈禁用态，但**文本可选中、可复制**；上滑即停止自动滚动，出现「回到底部」ghost 小钮，不强行拉回。
- 屏幕阅读器：流式区 `aria-live="polite"` 且**节流批量更新（每 800ms 一次）**，逐 token 播报视为禁令。

### 4. 提案卡规格（不确定性诚实）

- 白底、1px `--hair`、`--r-md`、内边距 16；标题 H3，正文 P1。
- 头部一行 P2 muted 状态行：**「这是提案，尚未落盘」**；已落盘则换「已按提案布置 · 可撤销」。
- 每张提案卡**恰一颗主行动**（绿，确认类），次行动 ghost（改方案 / 收回）；无第二颗绿钮。
- 数字必须可核：座位数、面积、人数用 tabular-nums，并带**来源行**（P2 muted）写清依据，如「按你的要求：40 人 · 室内 12 × 9 m」。
- 信息不足时**不猜**：列「还差什么」清单（P2 + 文字链），而不是用默认值填满后再道歉。

### 5. Agent 台词规范（语言即 UI）

- 一动一句，至多两句；**做完才报，不预告**（禁「我正在为您生成…」这类过程客套，过程交给分步叙述区）。
- 禁词：抱歉、请稍等、作为 AI、希望这能帮到你、总结性空话；也说人话、给出路、不道歉不推责。
- 结果句带关键数字与画布角标同名（「空白场地立好了：12 × 8 m」）；术语一律与 UI 文案一致，不造同义词。
- AI 参与不伪装成人格化过度：统一「已生成 / 已改好 / 已撤」，不写「我帮你弄好了哦」。

### 6. 机器感禁则

- 禁紫渐变、发光（glow）、彩虹描边、噪点「科技风」贴纸；`Sparkles` 图标只允许「生成 · Agent」一处，不得扩散到按钮与标题。
- AI 产出与人工产出**在画布上一视同仁**（同一撤销历史、同一材质渲染），差异只许出现在 Agent 区的状态行里，不许给 AI 产物加特殊边框或角标水印。
