## 2. 真机证据（2026-10-27，浏览器子代理走查）

1. **空闲态**：左轨 3 枚流程图标（布置/评审/执行）+ 分隔线 + 1 枚「工具」展开钮（点击才展开活动需求/图纸尺寸/执行资料/方案评审/场景模板/物料工具/合同约定七件，平时收起）；左栏默认活动简报；右栏零绿钮、无 n/4；演示条在顶部。
2. **简报联动**：输入「我们活动 80 人，场地 12×9 米」→ 左栏简报人数 80、场地 12 × 9 m，画布标题同步 108.0 ㎡。
3. **导出链路**：输入「导出给搭建方」→ 右栏出「导出预览」卡，主钮「确认导出」、辅助「先不了」，同时刻仅此一颗绿钮；点「确认导出」→ 进入执行页，提示「完整活动交接文件已导出，可离线打开与打印」。
4. **布置确认**：输入「帮我布置一个 30 人的工作坊」→ 方案预览卡主钮「确认布置」；确认落盘后播报「108 ㎡ · 21 件物料」「没有重叠，也没超出场地。」
5. **Undo 同步**：画布工具栏「撤销」（非 disabled）点击成功 → 右栏预览卡/提案态清空、无任何绿主钮，回空闲态。

## 4. 待核（未扩 scope）

1. **左轨第 4 枚「工具」钮**：卡片 §4.1 字面「左轨永远三图标，永不第四」；但 §2 scene-delivery 行又写「导出能力保留……深埋到『工具』」。本轮把七件业务工具收进这枚展开钮作为「深埋」实现，平时收起、只切工具不切换三模式。若验收认为该钮也算第四图标，需另点名将七件工具改道（如纯对话指令触发）。
2. **确认导出后落执行页**：点「确认导出」后进入执行台面，该台面可见六 Tab 条。卡片管的是「主路径默认壳」，此为确认后的工具台面；若验收要求确认后也不见 Tab 条，需另点名。
3. **「确认布置」在浏览器子代理手下坐标点击失败**：系走查工具的视口坐标问题，最终经 DOM 点击完成验证；人工操作无此问题。
