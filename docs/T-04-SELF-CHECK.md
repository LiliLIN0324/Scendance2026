## 2. 真机证据（2026-10-26）

### 2.1 评审页两条出口

页面显示：

- 「发给客户 / 核对后导出离线 HTML，或发布云端只读链接；都由你发送」
- **离线评审 HTML**：「不依赖登录；生成并下载后由你发给客户，文件冻结在生成时。」
- **云端只读链接**：「需要登录并保存到云端；发布后由你复制链接，系统不会自动发给客户。撤销后链接失效，已下载的文件收不回。」
- 右栏 Agent：「准备客户评审」+「离线 HTML 不用登录，下载后你自己发；云端只读链接要登录并保存到云端，在评审页里发布、复制。系统不会自动发给客户。」

点击「打开发布管理」：

- 账户面板打开，左侧「发布管理」为选中态；
- 显示「发布云端只读链接要先登录，再把方案保存为云项目。」
- 显示「离线评审 HTML 不需要登录，可在「方案评审」里生成并下载。」
- 显示「去登录」按钮；**没有生成链接，也没有发送动作**。

### 2.2 参考填入 → 手改 → 生成

点「生成说明参考」，填入：

```text
【方案简述参考 · 工作坊 · 80 人】
本方案为“周末共创工作坊”准备，约 96 ㎡，46 件物料。每位参与者有可操作的台面，讲师区与投影视线无遮挡。
以上为方案说明参考；实际尺寸、材质与数量以现场复核和最终确认为准。
```

点「生成待确认参考」，填入：

```text
【待确认参考】
1. 插座、投影位置与讲师区视线需现场确认。
2. 场地实测尺寸、入口净宽与可用层高。
3. 用电位置、总功率与进场/撤场时间。
4. 重点物料的颜色、材质、交期与备货数量。
5. 搭建、撤场与运输的责任分工。
```

在说明中手工加入一行「已核对入口。」后点「生成评审包」：

- 出现 iframe「客户评审预览」与「下载评审文件（HTML）」；
- 预览 `srcdoc` 21,458 字符，包含上述手改内容、待确认参考、项目名与 96 ㎡ / 46 件；
- 无 `input` / `textarea` / `select`；
- 无 Agent、素材库、租约、编辑权、内部备注或 `PRIVATE_`；
- 无「已发送给客户 / 已通知甲方」话术。

手写后再回到空态复测：说明栏已有手写内容时「生成说明参考」按钮隐藏，并显示「已有手写内容；参考不会覆盖，需要时先清空对应栏再生成。」；待确认栏仍为空，因此「生成待确认参考」仍可用。

> 下载按钮点击后页面显示「已发起下载，请确认文件已保存。」；in-app Browser 的落盘目录未在 `~/Downloads` 找到对应文件，**文件是否真正保存到磁盘未在本轮复核**，见 §6-5。

### 2.3 执行页与本机边界

切到「方案执行」：

- 左栏标题「执行 · 本机内部资料 / 活动安排、点验、导出与本机备份」；
- 面板标题「本机内部资料：安排活动任务，核对物料并导出交接内容。」；
- Agent 显示「执行 · 本机内部资料 · 周末共创工作坊」「46 件物料 · 96 ㎡」；
- Agent 说明「物料清单只看不改；要改回「布置」里调。导出文件留在本机，由你交给搭建方。」

切到「导出」页签，点击「导出完整活动交接 HTML」。为核对文件内容，在页面内临时拦截下载锚点并读取 Blob（随后已恢复 `HTMLAnchorElement.prototype.click`，未改仓库文件）：

- 文件名：`周末共创工作坊_内部活动交接_<uuid>.html`
- 标题：`周末共创工作坊 · 内部活动交接`
- 章节：活动需求与现场条件 / 全部活动任务 / **逐件物料工作单 46 行** / 同快照摆位示意 / **全部场景实例 46 行**
- 画布实际 46 件，逐件工作单与场景实例均为 46 行；
- 无「消防 / 疏散 / 合规」字样，未把内部备注或素材库写进交接文件。

### 2.4 切回布置

从执行切回「空间布置」：

- 仍为「青序 · 香氛快闪」46 件物料 / 96 ㎡；
- 项目名仍为「周末共创工作坊」；
- 选中物料 0 件、撤销按钮禁用——与进入评审前一致；本轮没有制造选中态或撤销栈变化，见 §6-6。

## 5. 交互与文案钉

1. 评审主钮统一「准备客户评审」，不再假装已生成链接。
2. 两条出口各写清代价：离线 HTML 不依赖登录、由人下载发送；云端链接需登录并保存云项目，由人复制，系统不代发，撤销后已下载文件收不回。
3. 参考只填空字段；手写后按钮隐藏并提示先清空，不覆盖；填入后仍是普通可编辑文本，改了要重新生成评审包。
4. 参考文案不写「已发送 / 已通知客户 / 客户已确认」。
5. 执行区始终写「本机内部资料」，不写「云端协作」「现场履约」。
6. 发布入口只打开账户面板「发布管理」；未登录与未绑定云项目分别给下一步。
7. 左轨保持三颗阶段图标；未新增第四颗。

## 6. 待核 / 已知边界

1. **主出口策略未裁决**：`C.publish-dual-exit` 仍待 PM。本卡没有删除任一出口，也没有把某一条说成唯一正确路径。

3. **登录后的云项目路径未真机跑**：本轮未登录、无云项目；未绑定云项目与未登录两种下一步由 `cloud-panel` 单测覆盖，登录后发布/撤销的真实链路未在本轮复核。
4. **`/view/` 真机未打开**：没有可用的已发布分享 token，也未登录云账号；客户页只读与撤销拒绝由单元回归覆盖，真机发布/撤销链路仍待有账号时验收。
