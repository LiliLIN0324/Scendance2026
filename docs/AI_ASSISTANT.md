# AI 场景助理接入

2026-10-02。基于已上线前端分支 `codex/scendance-first-launch` 的 `c727f00`，在独立分支 `codex/deepseek-assistant-ui` 实现。后端沿用专用 Supabase 的提案接口，不改数据库或系统提示词。

## 使用

1. 点击「AI 助理」，通过「打开云项目」登录、打开或创建项目并获取编辑权。
2. 输入需求。空场景使用 layout 初稿模式；已有物件使用 modify 模式，发送真实场景及所选物件 ID。
3. 查看说明、俯视预览、物件变更和空间提示。预览不修改画布、不保存云端。
4. 「确认应用并保存」调用现有原子提案接口，完成后更新画布与云端版本。可用画布撤销恢复应用前布局；撤销是本地修改，需再次保存到云端。

生成期间仍可编辑、保存或交接。场景修改、云版本改变、租约变化或提案到期会禁用旧提案。确认保存期间发生的新编辑保留为本地草稿，云端版本与保存指纹仍更新，避免误报已同步。供应商缺配置、额度耗尽等 AI 错误保留人工编辑与保存能力。没有自动重试或自动应用。
