## 1. 产品一句话 + 本轮目标

**一句话**：幕景卖「活动场景方案」——布置 · 物料 · 文案，对话主路径，视觉干净 AI-native。

**本轮目标（硬）**：先把 **活动组织 / 活动布置流程** 做成可打动人的 AI-native 体验。已有适合做 3D 的技术合作方——**先用布置流程打动对方**，3D 后谈。本轮 **不做 3D 深挖**。

成功标准（给人看的）：合作方打开 `/editor`，用几句对话走完「办一场活动 → 布置确认 → 物料 → 文案 → 优化 → 交付」，页面逻辑清晰、安静、专业——不是表单壳，也不是说明书墙。

## 3. 信息架构

```
左轨（三图标 only）     对话主路径（右栏）           画布（中）
─────────────────     ─────────────────────     ────────────
布置  ←──────────────→  场地 / 布置 / 物料 / 文案 / 优化
评审  ←──────────────→  客户交付（离线 HTML 主 / 云链次）
执行  ←──────────────→  本机内部资料 / 导出意图
```

| 左轨 | 用户任务 | 成功标准 |
|---|---|---|
| **布置** | 用对话办完一场活动的方案：场地→布置→物料→文案→优化 | 画布上有可拖改方案；确认前不静默落盘；左栏只是活动简报（跟聊天同步） |
| **评审** | 给客户看方案（专业、只读） | 离线评审 HTML 主流程可用；云端只读次入口；客户页无编辑控件 |
| **执行** | 给工作室导出搭建资料 | 对话意图→预览→确认导出；不把六 Tab 当主舞台 |

**硬钉**：左轨永远 **布置 / 评审 / 执行** 三图标，**永不第四**。对话进度（场地→布置→优化→交付）只在聊天上下文里走，不升格图标。

## 4. 页面交互原则（绝对简洁）

### 4.1 禁旁注文案清单（DO NOT）

- 禁止在按钮旁、卡片旁堆「说明你点这里会怎样」的说明书句。
- 禁止常驻「下一步：…」「请先…再…」教程式绿入口。
- 禁止空闲态多颗绿主钮；禁止「确认应用」与「确认布置」并存。
- 禁止用六 Tab / n/4 进度条制造交付向导感。
- 禁止 AI 在每个控件旁自动补解释文案（未来 tutorial 教，不靠 UI 注脚）。

### 4.2 唯一主按钮态

| 态 | 绿主钮 |
|---|---|
| **空闲** | **零** 绿主钮 |
| **提案 / 预览** | **仅一颗**：布置用「确认布置」；导出用「确认导出」 |
| **确认后** | 回到空闲（零绿钮）；画布已更新；可继续对话 |

### 4.3 允许的安静 UI

- 左栏活动简报数字（名称 / 人数 / 尺寸）跟聊天同步，无第二套表单。
- 状态仅「做好了 / 发现问题」（点+短词）。
- 演示条诚实保留：「演示环境 · 方案由本机规则生成 · 未连接真实 AI 模型」（mock 大脑 OK）。
- 晴光：Qingguang 3D 毛绒头像；**无 Bingo**。

## 5. 活动组织主流程（用户故事走查）

主线卖点顺序：**布置 → 物料 → 文案**（再优化、再交付）。每步 **对话意图** 为主；**禁止第二套表单**完成同一目标。

| 步 | 用户说 / 做 | 系统做 | 禁止 |
|---|---|---|---|
| 1. 办一场活动 | 「办一场 80 人室内酒会 / 12×9」 | 对话 intake；左栏简报更新；壳体/预填卡可点改 | 逼填完整活动需求表 |
| 2. 布置确认 | 「按这个摆」/ 点确认 | 提案预览 → **确认布置** → 落画布 | 静默 apply；代拖；确认前报假米数 |
| 3. 物料 | 「出物料清单」 | 对话出清单预览 / 可改；与画布件数一致 | 打开六 Tab「物料工作单」当主路径 |
| 4. 文案 | 「写方案说明 / 给客户看的文案」 | 对话生成可改文案；人改优先 | 按钮旁长说明；代发客户 |
| 5. 优化 | 「太挤了 / 检查一下」 | 只报冲突动线 + 可一点的改法预览 → 一确认 | 装合规；氛围/mood |
| 6. 交付 | 「导出给搭建方 / 准备客户评审」 | 意图 → 预览卡 → **确认导出** / 评审包 | 空闲挂绿导出钮；四段左轨 |

走查口令：四句对话后画布应有可见变化（或明确预览待确认）；**不得**再出现「先填完左栏表单再生成」的第二路径。

## 6. 视觉与组件纪律（干净 AI-native）

- **纸面系统**：paper / plane / hairline / ink / 一颗 accent 绿（`--wk-*`）；整页安静，不泥绿。
- **逻辑清晰**：左轨阶段 → 右栏当前任务 → 中画布结果；一眼知道「我在布置还是在交付」。
- **组件**：预览卡 > 表单；一屏一决策；图标三枚左轨 + 画布 14 键原位（本阶段不改 14 键数量/位置）。
- **文案**：控件标签短；长说明进未来 tutorial，不进按钮旁。
- **IP**：晴光毛绒；无扁平、无 Bingo。
