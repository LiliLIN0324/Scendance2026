## 2. 对标竞品与四条法则（2026-11-04 检索）

**Prismm（原 AllSeated，领域最像）**：教程中心按功能线分主题短系列（Designing a Floorplan / Chair Management / Guest Management / External Collaboration…），另有 "First Steps" 起步系列与按对象的深挖视频。启示：**起步主线短，深挖内容按对象拆条目**。

**酷家乐（国内 3D 设计，教程体系最全）**：官方「工具学习专区」给学习路径——①快速掌握户型创建 → ②软装摆放 → ③手动打光，"零基础 3 天掌握"；视频课程（学习中心/B 站全套）+ 帮助中心分步文章。启示：**路径按任务排序、每步一个动词**，不是按菜单讲功能。

**Figma（onboarding 教学法标杆）**：Help Center「Figma Design for beginners」= 建号 → 认界面 → 核心概念 → **动手练习（用形状拼出自己的头像）** → 模板 → 进阶工作流。启示：**第一课必须产出摸得着的成果物**。

由此钉四条法则：

1. **任务线优先，功能线做参考**：主线六章按真实使用顺序；功能细节收进条目表，不做功能目录。
2. **第一章就有产出物**：读完第二章用户手里有一版能看的方案（例句→生成方案→确认），不是读完概念。
3. **每一步指认真实入口**：只写 `data-tip`/按钮实名（统一写「场景锚定」，不写「地图选址 / 地图圈画」）；写不清位置的入口宁可不写。
4. **边界诚实**：沿用版本说明的四段密度（能直接用到的/边界与未做），不教不存在的功能、不把受限路径写成畅通路径（生成走本机代理的限制要在边界里说明）。

## 3. 能力清单（写教程的事实底座，逐条有代码证据）

- **首屏冷启动**：Bingo 对话卡 `PlanHome`——三句例句（「80 人发布会，室内 12×9」「30 人圆桌晚宴，室内 15×10」「120 人市集，户外 20×14」）+「生成方案」+「改类型或人数」折叠（活动 chips：品牌快闪/工作坊/展览市集/发布会/婚礼聚会；场地：室内 12×9/10×8/户外 20×14；人数：30/80/120）。`plan-flow.tsx:3-35,273-350`
- **生成与确认**：例句/说话 → Bingo 对话生成 → 提案卡预览 + 唯一确认钮（「确认布置」口径待复核 §5-Q1）→ 确认才落画布，可撤销。`agent-panel.tsx:1966-1986`
- **四格 lane**：总控（门洞，汇总另三条线对话）/ Bingo（球，现场布局·动线·布置方案）/ 空间（立方）/ 物料（锥）+ 轨脚设置（切回官网/新手指引/GitHub/隐私政策）。`room-organizer.tsx:2078-2127`、`settings-menu.tsx:44-56`
- **画布右轨工具列**（12+ 颗随状态增减）：选择 / 移动整体场景 / 平面·立体 / 高斯实景·识别轮廓 / 进入漫游 / 视角（一颗钮循环 整体→俯视→正面机位）/ 尺寸（标注）/ 网格吸附 / 卫星贴地 / 撤销 / 重做 / 缩小 / 放大 / 导出效果图 / 氛围（人群/天气/时段/现场灯光）/ 发布。`scendance-workspace.tsx:456-565`
- **场地三种来源 + 统一的地面层锚定**：
  - 空白：新建「从空白开始」（12 × 8 m · 立刻开工）；无图纸时「用一句话写清总宽、总深、层高」。`venue-picker.tsx:134-150`、`reconstruction-panel.tsx:603`
  - 图纸：空间 →「图纸与照片」→（未连接时）「连接场景服务」前置卡 → 上传 → **两点定标尺**（「确认标尺并进场地」）→ 结构核对（「确认长度并锁定比例」+ 墙段勾选）→ 三维候选 →「确认应用并保存」。主按钮「生成布置预览」。`reconstruction-panel.tsx:639-672`、`floor-plan-ruler.tsx:105-173`
  - 场景锚定（不是第四种场地）：任何场地建好后都可写 `sceneAnchor`——`geo`（素材带 GPS）/ `manual`（人工指定原点、朝向、尺度）/ `null`（默认 1m 网格，无底图）；地名只用于填锚点，不生成独立户外场地。需高德 Key/安全密钥（只留本机）。`docs/51 §11`
  - 生成：空间面板「生成高斯空间」（World 世界模型）/「重建真实场地」（Aholo，通常约 15-30 分钟，消耗额度）；「场景模板」也在空间面板。`space-panel.tsx:106-127`、`aholo-guide-card.tsx:24`
- **物料**：物料库点「添加」进画布；生成走物料对话左下「＋生成物料」（描述/图片两路），勾「确认扣额度后才会提交」→「生成」；Lux3D 通常约 3-5 分钟；完成后自动进画布（历史任务可在库里「点击放入空间」）。`material-create-cell.tsx:126-158`、`aholo-guide-card.tsx:10-15`、`generated-model-library.tsx:71`
- **交付**：右轨「发布」→「发布当前版本/重新发布版本 N」+「手机看方案」二维码（版本锁定，后续编辑不改已发布版）+「发评审链接」（对方只读平面落钉留言）+「导出交接」（确认卡：活动需求/物料工作单/制作计划/数量点验 · 本机生成）+「打开资料」「到场清单」；评审包最多 6 张画面。`share-menu.tsx:143-251`、`project-review-panel.tsx:291-306`、`agent-panel.tsx:2016-2022`
- **多场地（v3.3.0）**：空间选择模式点选不同高斯场地切换（保留相机）；物料随所属场地变换；楼层 1F/2F 带方向；「移动整体场景」与物体编辑分立；轮廓按高斯体积投影（仍需复核）；云端首版单层场地限制。`CHANGELOG.md:3-35`
- **账户/额度**：应用内每日额度已取消（2026-10-03），生成走 **Aholo 云额度**确认闸；登录 90 天；账户中心两栏（左团队右项目，「我的项目/我的素材库」）；团队成员与直接消息独立面板、按邮箱邀请（Supabase）。`docs/30-AI使用额度.md`、`material-create-cell.tsx:158`、v3.2/v3.3 tag 注释
- **教程入口**：官网 `introduction.html` 顶部导航+页脚「新手指引」、工作台设置菜单；打包 `scripts/package-pages.mjs` 从根 `guide.html` 写入 `frontend/public`。锚点直链机制保留。
