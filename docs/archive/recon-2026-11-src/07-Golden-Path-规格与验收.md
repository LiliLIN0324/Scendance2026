# 07 · Golden Path 规格与验收（2026-11-04）

> 目标：普通用户 **10 分钟内**完成一次真实空间创作，结果可直接发给潜在客户。
> 本文把五步拆成可测原子动作，规定入口、依赖、降级与计时口径；体检结果见 [08-现状体检](file:///08-Golden-Path-现状体检.md)。
> 只读走查，未改源码、未 commit/push。

## 0. 计时口径

| 项 | 规定 |
|---|---|
| T0 | 用户打开工作台，**场景画布完成首次可交互渲染**（能看到场地，不包含登录页） |
| T5 | 另一台设备（未登录）打开分享链接，**看到方案首帧** |
| 计入用户耗时 | 生成等待、Agent 等待、上传/加载等待、失败后的重试 |
| 不计入（单独记「摩擦耗时」） | 登录、充值/购额度、等待人工审批；**不因此放宽 10 分钟** |
| 判定「10 分钟内」 | `T5 - T0 ≤ 600s`，且五步均达到各自验收条件；任一步需要下载/上传文件即判失败，不再计时间 |
| 计时方式 | 走查脚本按毫秒记录每一步（见 §6） |

**一句话**：10 分钟是「从看到场地，到客户在手机上看到方案」的墙钟时间，含系统生成等待，不含登录与买额度。

## 1. 五步原子动作与判定

### 第 1 步 · 选真实场景 / 导入扫描

| 原子动作 | 入口 | 判定（全部满足才算通过） |
|---|---|---|
| 1.1 打开空间 | 左轨「空间」 | 1 次点击内打开，场景列表可见 |
| 1.2 选一个真实场地 | 场景列表 / 「新建换场地」 | 列表里能看到**已扫描的真实场地**并一次选中；不要求先建空白项目 |
| 1.3 无扫描时导入 | 「重建真实场地」或「导入扫描」 | 走照片/视频重建时，提交后**自动**挂上高斯环境，无需手工改尺寸 |
| 1.4 进入即用 | 画布 | 选中后 ≤3 s 出现在画布，场地尺寸与扫描米制一致（误差 ≤2%） |

- 依赖：`space-panel.tsx`、`venue-picker.tsx`、`room-organizer.tsx`（splat 绑定）、`site-capture.ts`、Lux3D/Aholo 代理。
- 降级：没有已扫描场地时，显式给「空白场地 / 演示厅」两个选项并标注「非真实」；不得把演示资产伪装成真实场地。
- 当前证据：场景列表仅 1 个「宴会厅 A」；换场地弹层只有「从空白开始」与云项目（登录）；「重建真实场地」需 ≥20 张照片或 1 段视频，默认「干跑」只挂样例。

### 第 2 步 · 输入需求生成原创装置

| 原子动作 | 入口 | 判定 |
|---|---|---|
| 2.1 打开生成 | 物料面板「生成物料」→「通过描述生成物料」 | ≤2 次点击到达表单 |
| 2.2 填需求并提交 | 表单 | 有描述框、扣额度确认；提交后任务出现在「我的生成」，进度可见 |
| 2.3 取回产物 | 自动轮询 | 完成后**.glb 自动入库**，不出现「下载→转换→上传」任何一步 |
| 2.4 环境要求 | 生产构建 | 用户全程不碰终端、不需要本机代理 |

- 依赖：`material-generate.ts`、`lux3d-import.ts`、`aholo-assets.ts`（`DIRECT_BASE` / `isLux3dLocalProxy`）。
- 降级：生成不可用时，明确提示「当前环境不可生成」并提供「从库中选」，**不得**给出可点但必失败的按钮。
- 当前证据：表单可达且可填；`isLux3dLocalProxy()` 要求 `NODE_ENV=development` 且 127/localhost。

### 第 3 步 · 自动进场景并调位置大小

| 原子动作 | 入口 | 判定 |
|---|---|---|
| 3.1 自动进入 | 无需用户操作 | 生成完成 → 装置自动出现在场地中心并选中；≤1 个额外动作（若降级为「放入」按钮） |
| 3.2 贴地 | 画布 | 包围盒底面与地面高差 ≤2 cm，不悬空、不埋地 |
| 3.3 米制可信 | 结构/标定 | 场地已知长度可校准，误差 ≤2%；装置尺寸按米显示 |
| 3.4 调整 | 选中工具条 | 移动/旋转/缩放可用，刷新后位置与尺寸保留 |
| 3.5 撤销 | Bingo / 工具条 | 一次撤销可回到上一步，且不丢其它物件 |

- 依赖：`glb-normalize.ts`（单位/轴向/底面中心）、`online-model-library.tsx`（onAdd）、`layout-reducer.ts`、`use-splat-preview.ts`（标定/落地）、`calibration-hud.ts`。
- 降级：自动落位失败时，保留「放入画布」按钮并在画布中心预览，不得静默失败。
- 当前证据：库件加入画布成功（5→6 件）且出现移动/旋转/缩放工具条；`use-splat-preview` 已返回 `calibrate/setGround/addAnchor/landingPlan`，但界面无标定入口。

### 第 4 步 · 通过 Agent 改方案

| 原子动作 | 入口 | 判定 |
|---|---|---|
| 4.1 精确移动 | Bingo 输入框 | 自然语言「把 X 往西挪 2 米」→ 位移误差 ≤5 cm |
| 4.2 精确缩放 | Bingo 输入框 | 「把 X 放大 10%」→ 尺寸误差 ≤2% |
| 4.3 加物件 | Bingo 输入框 | 「加两盏暖色灯光」→ 新增数量与语义一致（2 盏） |
| 4.4 先预览后落盘 | 提案卡 | 未确认不写画布；「确认布置」后落盘；「撤回」可整体回退 |
| 4.5 可解释 | 提案卡 | 说明改了哪几件，不出现「挪/转 1 件」这类与实际动作不符的文案 |

- 依赖：`workbench-agent.ts`（`plan.revise`）、`agent-panel.tsx`（提案/确认）、`layout-reducer.ts`（`moveItem/resizeItem`）、`use-scene-lighting.ts`。
- 降级：识别不到物件名时，列出可选物件并让用户点选，不得只说「没接住」。
- 当前证据：移动「共创桌」西移 2 米实测 `Δx=-2.000`；「两盏灯」实际新增 1 件；「放大 10%」结果异常（见 08）。

### 第 5 步 · 保存并生成可分享 3D 方案

| 原子动作 | 入口 | 判定 |
|---|---|---|
| 5.1 自动保存 | 左下状态 | 停止操作 ≤2 s 显示「已保存」；刷新后内容一致 |
| 5.2 生成分享 | 发布卡片「生成只读 3D 分享方案」 | ≤1 次点击得到链接/二维码；不需要登录才能生成**只读**链接 |
| 5.3 客户打开 | 另一台设备、未登录 | 首帧 ≤5 s；只读、无编辑控件；显示件数与布置一致 |
| 5.4 场景可信 | 分享页 | 显示真实环境背景（3DGS）+ 方案；或明确标注「平面预览」并说明不含真实背景 |
| 5.5 物料成套 | 分享页/卡片 | 件数、品类、尺寸与画布一致；不得出现两套数字 |
| 5.6 云端发布 | 发布卡片 | 登录后可发布；含本机资产的方案不得被静默拦截，应提示「需上传」并给出动作 |

- 依赖：`share-menu.tsx`、`share-snapshot.ts`、`app/view/page.tsx`、`layout-preview.tsx`、`backend-adapter.ts`、`aholo-assets.ts` 上传。
- 降级：无登录时仍可生成只读本机链接（现状已具备）；云端发布未登录必须明确提示，不得半途失败。
- 当前证据：只读链接生成成功、客户页可打开；未登录发布提示「登录后再发布」；含库件的分享链接报「分享链接不完整」（见 08）。

## 2. 不可接受的行为清单

1. 让用户下载 GLB 再手工上传，或要求手动换算单位/轴向。
2. 装置生成后悬空、埋地、比例明显失真，或刷新后位置丢失。
3. 场地尺寸与扫描不一致却不提示，仍宣称「可量尺寸」。
4. 生成按钮可点但在当前环境必失败；或错误文案要求用户运行终端脚本。
5. 生成/扣额度不告知，或失败后重复扣额度。
6. 分享链接需要客户登录、或打开后白屏/「链接不完整」而无替代说明。
7. 分享页只有 2D 平面却标注「3D 方案」；或宣称「真实场景」但背景不是现场。
8. 同一方案在 Agent、发布卡片、到场清单出现不同件数/不同品类。
9. 需要用户自己判断「用哪个链接/哪个导出」，且两种链接差异未说明。
10. 演示资产（宴会厅样例、干跑重建）被当作真实场地交付，无「演示」标记。

## 5. 单步失败时的降级矩阵

| 失败点 | 允许降级 | 不允许 |
|---|---|---|
| 无真实扫描 | 空白场地/演示厅（带标记） | 把演示当真实 |
| 生成不可用 | 从库选 + 说明原因 | 可点必失败 |
| 自动落位失败 | 「放入画布」+ 居中预览 | 静默 |
| 标定不可用 | 显示「未校准」并禁用尺寸承诺 | 继续声称米制可信 |
| 无 3DGS 环境 | 2D 平面只读页（明确标注） | 标成 3D/真实 |
| 无登录 | 本机只读链接（自包含） | 客户端白屏 |
| Agent 未识别 | 候选物件列表 | 只说「没接住」 |
