# 西湖场地素材核查与采集缺口（scene-3d，2026-11-04）

> 核查范围：`scene-3d/`（32 个文件，206,311,868 B）
> 核查方式：**只读**。未修改、移动、重命名、删除任何素材，未启动任何重建。
> 证据口径：所有结论后附文件名 / EXIF 字段原值 / 命令输出；无数据的项直接写「没有」。
> 本文档用于与技术路线调研合并，不替代技术选型结论。

---

## 0. 结论（BLUF）

**不能做重建。** 这批素材是**同一晚、同一机位附近、以云台旋转为主**的 24 张有效静态图 + 54 秒二次转码的 720p 视频；全景帧之间平移基线接近 0，SfM 会在三角化阶段退化。

最大的硬伤按严重度排序：

1. **没有的位置（数量意义上的零）**：26 张图全部 `drone-dji:GpsStatus="Invalid"`、`GpsLatitude/GpsLongitude="+0.000000000"`，EXIF GPS 是 `(nan, nan, nan)`；6 段视频无任何位置标签。**0/32 文件具备可用坐标**，无法落到西湖的任何一个点位。
2. **没有基线**：素材以 `pano_original`（11 张）与机内拼接 `pano`（10 张）为主，是原地旋转的全景采集，不是绕场行走。没有平移就没有视差，摄影测量与 3DGS 都缺必要输入。
3. **没有尺度**：无 GCP、无测距记录、无 IMU/点云，产出物无法落到米制。
4. **成像条件最差的一档**：夜间拍摄，天空占幅面大面积且近乎纯黑（无纹理），湖面大面积反光 + 远处城市灯光逆光，曝光从 1/6.25 s 到 1/100 s、ISO 210–4040 漂移。

现状能交付的上限是：**一张 360/180 全景氛围贴图 + 一份人工估读的体块草图**，够做“环境背景层”，不够做可量化、可漫游的三维场景。

## 3. 时间信息

### 3.1 EXIF 时间（26 张）

- 最早：`2026:11:02 19:33:07`（`-23.jpg` / `-24.jpg` / `-4.jpg`）
- 最晚：`2026:11:02 19:37:16`（`-18.jpg`）
- **跨度：4 分 09 秒（249 秒）**，全部同一天、同一时段。

### 3.2 时区与文件系统时间的不一致（需注意）

| 来源 | 值 |
| --- | --- |
| EXIF `DateTimeOriginal` | `2026:11:02 19:33:36`（无时区字段） |
| XMP `xmp:CreateDate` | `2026-11-02T19:33:36+00:00`（写了 +00:00） |
| 文件系统 mtime | `2026/11/2 21:03`（本地时间，晚于 EXIF 约 1.5 h） |
| 文件名前缀 | `2026-11-04 03:12:03` |

mtime 比 EXIF 晚 1.5 小时，与“导出/拷贝”行为吻合；若 XMP 的 `+00:00` 成立，本地应为次日 03:33，但此刻天已大亮，与画面全黑矛盾。**因此按 EXIF 的 19:33–19:37 视为本地时间**，画面（纯黑天空 + 对面城市灯光）与该判断一致。

### 3.3 光照一致性

同一晚、同一时段，但**曝光并不一致**：

| 指标 | 范围 | 说明 |
| --- | --- | --- |
| `ExposureTime` | 0.16 s（1/6.25）– 0.01 s（1/100） | 跨 16 倍 |
| `ISOSpeedRatings` | 210 – 4040 | 跨约 19 倍 |
| `ApertureValue` / `FNumber` | 恒定 2.0 | 固定光圈 |
| `LightSource` | 2（荧光灯）/ `WhiteBalance` 0（自动） | 只能参考，非真实色温 |

结论：**时间一致、光照条件不一致（夜间低照度 + 自动曝光漂移）**。这对多视图一致性（尤其 3DGS 的曝光补偿）是不利项。

### 4.1 设备单一性

### 4.2 光学参数

| 字段 | 值 | 含义 |
| --- | --- | --- |
| `FocalLength` | 6.5 mm | 实际焦距（固定，不可变焦） |
| `FocalLengthIn35mmFilm` | 20 mm | 等效约 20 mm 广角 |
| `FNumber` / `MaxApertureValue` | 2.0 / 2.0 | 恒定 f/2.0 |
| `LensSpecification` | (6.5, 6.5, 2.0, 2.0) | 定焦 |
| `Flash` | 0 | 未闪光 |
| `MeteringMode` | 1（平均测光） | — |

20 mm 等效广角对室内/半围合空间是合适焦段，但配合 1 英寸传感器 + 固定 f/2.0，在夜间只能靠拉长曝光与高 ISO，代价是噪声与抖动。

### 4.3 是否环绕 / 是否等距

云台姿态字段（`drone-dji:GimbalYawDegree` / `GimbalPitchDegree`）统计：

- **yaw 范围：−52.4° → +50.2°，跨度仅 102.6°**
- **pitch：绝大多数落在 ±124°–180° 之间**（如 `-1.jpg` = `+176.90`，`-10.jpg` = `-178.20`，`-18.jpg` = `-133.80`）

判读：**yaw 只扫过约 103°，且 pitch 大量是“大角度/近倒置”**，这是 Osmo Pocket 3 全景模式由云台原地转动产生的姿态，不是人绕场行走的连续拍摄。**没有发现环绕采集的证据**（没有 360° 的 yaw 覆盖，也没有均匀等角间隔）。

### 4.4 连拍 / 等距环绕的迹象

- 相邻帧最小间隔 1 秒（19:33:07 → 19:33:08 → 19:33:10 → 19:33:11，对应 `-23/-24/-4/-22/-8/-20/-21`），属全景扫描过程中的连续出帧。
- 分辨率按模式分组严格一致（见 1.2），说明每张都是“完成一次模式拍摄”的成品，而不是连续的等距环绕序列。

## 6. 数据规约对照：高质量重建至少需要什么

以「单座 50–200 m² 半围合场地、可在编辑器中量尺寸并漫游」为目标，逐条对照：

| # | 规约项 | 门槛要求 | 当前素材 | 判定 | 缺口 / 补采要求 |
| --- | --- | --- | --- | --- | --- |
| 1 | 有效图像数量 | 200–600 张（≥250 张/100 m²） | 24 张唯一静态图 | **缺失** | 至少 200 张有效视角；现存量差一个数量级 |
| 2 | 环绕层次 | 3 圈（低 1.3 m / 中 1.6 m / 高 2.2 m）+ 俯视 1 圈 | 单机位、yaw 仅 103° | **缺失** | 至少 3 层环绕 + 1 组俯视；每层 360° 全覆盖 |
| 3 | 相邻重叠率 | 70–80%，baseline/depth ≤ 0.3 | 旋转为主，基线≈0 | **缺失** | 必须靠**平移**产生视差；步进 ≤ 10–15° 且机位同时前移 |
| 4 | GPS / GCP 精度 | ≥3 个 GCP 或 RTK，误差 <5 cm（或至少一条已知长度做尺度基准） | 0 个坐标，0 个 GCP | **缺失** | 现场摆 2–3 个 1 m 标尺/ArUco；或量取 2 条实际长度（如柱距、栏杆通长） |
| 5 | 光照与时间一致性 | 单一光照、避开强逆光与夜间；相邻影像曝光差 <1 EV | 单一时段（249 s）但曝光跨 16 倍、夜间 | **部分满足** | 改白天阴天或均匀人工光；锁定曝光/白平衡 |
| 6 | 动态物体排除 | 无行人、车辆；或后期遮罩 | 有路人、有可移动导览牌 | **部分满足** | 清场拍摄；无法清场的，遮罩即可，影响可控 |
| 7 | 水面 / 天空处理 | 二者合计 ≤30% 画面，或明确遮罩 | 二者常合计 >50%，天空无纹理 | **缺失** | 提高机位俯角、把湖面压到画面下缘；天空单独用 HDRI 替换 |
| 8 | 尺度基准 / 米制落地 | 必须有 | 无 | **缺失** | 同 #4；否则产物只能靠“场地最长边等比缩放”兜底（现有 `fitSplatBox` 的临时做法） |
| 9 | 内参一致 | 同一设备同一焦段 | 单机单镜，26/26 序列号相同 | **满足** | 保持用同一台 Osmo Pocket 3 |
| 10 | 原始文件、未二次转码 | 保留原始码率与元数据 | 图片为机内直出；**视频已被转码成 720p** | **部分满足** | 视频必须保留原始文件（不要用编辑器二次导出） |
| 11 | 位姿 / IMU 先验 | 有则大幅降低失败率 | 只有云台 yaw/pitch 标量，无 IMU 序列 | **缺失** | 改用可导出位姿的设备，或接受纯图像解算 |

## 7. 重建路径评估

| 路径 | 当前素材是否可行 | 理由（对应证据） |
| --- | --- | --- |
| 摄影测量（COLMAP / Meshroom / Metashape） | **不可行** | 全景帧基线≈0（§4.3），SfM 初始化即退化；天空占幅无特征（§5）；水面反射产生伪匹配；夜间低照度 SNR 差 |
| 3D Gaussian Splatting（nerfstudio / gsplat） | **不可行** | GSplat 依赖 COLMAP 位姿输入，位姿解不出来就无从训练；即使强行训练，也只能得到“贴着画面的一张纸” |
| NeRF | **不可行** | 同上，且夜间曝光漂移会直接毁掉颜色一致性 |
| 单目深度 + 人工补模 | **可行，但只是近似体块** | 可从全景/单张估出开间、柱距、檐口高度、地面范围；误差量级 10%–20%，不能当实测尺寸 |
| 重新采集 | **唯一能到编辑器精度的路径** | 需要按 §6 规约重拍，再走 Aholo World |

预期质量与新采集缺口（若按 §6 补齐）：

- 补齐后走摄影测量：可出**闭合 mesh + 纹理**，精度取决于 GCP，做到 ±5 cm 量级才适合“量尺寸”。
- 补齐后走 3DGS：可出**可漫游 splat**，观感优先、量尺寸次之（现有前端预览正是这条）。
- 还需补的关键角度：**场地四角**（现在完全没有）、**檐下与柱础近景**（判断结构）、**俯视**（判断地面轮廓）、**夜间没拍到的深色木构背光面**。
