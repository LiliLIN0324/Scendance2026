# 含未核验原文的云场景：授权编辑设计

当前状态：普通项目与分享读取返回中性只读投影；若投影不同于原始场景，旧接口的取编辑权、保存、提案应用和生成均保守拒绝。项目成员可在工作台主动读取、下载原场景；界面提交仍禁用，不能称这类项目已可正常编辑。

未部署迁移 `20261107100000_original_scene_reviews.sql` 仅新增私有评审表和 service-role RPC，不更改既有表。隔离试验中，评审创建绑定用户、项目、租约、原始场景、版本及候选；确认事务锁定原始项目与评审，核对原始 JSON、版本、候选 hash，再保存并记录单次结果。PGlite 与无网络 Docker PostgreSQL 验证了权限拒绝、并发只提交一次、同版本原值变化拒绝、连接中断回滚以及原备注保留。

纯函数 `prepareOriginalSceneReview` 仅允许不改变旧备注、设计记录、场地/结构/来源/尺寸的有限编辑；锁定物件不可变，提供中性投影的逐项差异。它不提供授权，也不能代替数据库 CAS。原始说明中的模型判断仍未经核验，不作为消防、疏散、无障碍或容量结论。

服务端已提供显式授权原值读取、原 hash 与 revision 核对取租约、预检与私有 RPC 组合的中性差异记录、显式确认提交和断线后只读状态查询。HTTP/PGlite 测试覆盖权限、原字段保留、错误 hash、未确认、并发和提交后响应丢失；Docker PostgreSQL 已验证底层 RPC 的并发与事务中断，但尚未验证 HTTP 路由与 Docker 组合。

正式启用前仍须完成真实前端差异确认及应用链、跨组件身份和权限变更、对所有旧入口的独立审查、真实服务端响应丢失与并发测试，以及部署兼容性验收。当前 UI 不提供提交按钮，旧项目继续只读；不可把投影作为原始场景写回，也未部署此迁移。
