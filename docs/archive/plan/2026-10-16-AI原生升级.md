## 1. Cross-cutting IA（横切壳）

### 1.1 一个工作台壳

| 面 | 路由 / 入口 | 职责 |
|---|---|---|
| 主工作台 | `/`、`/editor/`（`?local=1` / `?project=`） | 唯一三维编辑壳：左阶段轨 + 中画布 + 画布右工具列 + 右 Agent 栏 |
| 工作室 | `/projects/` | 工作室/项目/成员治理；不塞三维编辑 |
| 客户只读 | `/view/` | 分享令牌；无编辑控件 |
| 介绍 | `/introduction`（静态） | 营销；不进工作台壳 |

**不做**：为「策划 / 建模 / 模板 / 合同」各开独立页面；执行交付另起 SPA；客户交付做成可编辑副本路由。

### 1.2 阶段 vs 模式（勿混）

| 概念 | 定义 | UI 落点 |
|---|---|---|
| **阶段 Stage** | 布置 / 评审 / 执行（左轨三图标） | 决定右栏主任务与哪些导出暴露 |
| **模式 Mode（布置内）** | 出方案（Agent 布局）vs 人工改（库+变换）vs 模板预览确认 | 右栏对话步骤 / 物料抽屉 tab；**不**升格为第四阶段图标 |
| **氛围** | 漫游 / 人群 / 天气 / 时间 | **仅**画布右工具列（及 Agent 单条提议作快捷入口，打开同一控件）；不做成左轨第四项 |

### 1.3 禁止重复的页面/面板

| 已有双出口风险（PM brief） | 升级原则 |
|---|---|
| 「方案评审」HTML vs 云「发布管理」只读链接 | **客户交付**叙事统一为「评审阶段一个主出口」；另一入口降级为次要，文案写清何时用哪个（Open Decision） |
| 账户面板「团队演示」vs `/projects/` 真成员 | 演示权限不得暗示已写服务端；真管理只认 `/projects/` |
| 资料分类 7+ 入口 | 按 Figma 去向：需求→摘要卡；图纸→拖入底图；模板→物料抽屉；评审/执行→对应阶段；合同→执行「相关资料」或「更多」（待核是否默认隐藏） |
| 本地活动 / 云项目 / 场景连接三态 | 壳层同一套；保存边界文案必须可见；不新增第四「连接」阶段 |

### 1.4 Current → Target（横切）

| | Current（文档证据） | Target |
|---|---|---|
| Agent 形象 | Binggo/小狗右下角 | 晴光 **3D 毛绒裁切 32/40**（对齐左轨三阶段图标尺寸；另备 24/@2x），右栏头部一行；空态/宣传可用全身毛绒；**禁扁平** |

5. （下一 MVP）DXF-first：CAD 进场 → 确认墙/开口 → 校准 → 可编辑结构。

### 2.5 数据契约（实现 AI 必守）

| 字段 | 约定 |
|---|---|
| 单位 | **米**；角度集中转换；领域用 `width/depth/height`（勿与上游「height=平面深」混用） |
| 坐标 | XZ 地面；原点：编辑器中心（现有 `backend-adapter` 待核对齐点） |
| Scene | v1 可读；**v2** 含多边形轮廓、参数墙、门窗归属墙、柱、物件、来源图、尺寸约束、识别状态（见 floorplan-v2） |
| **wall vs furniture** | 墙/柱/开口 = 结构层（保存校验、防穿墙）；桌椅台背景等 = 物件实例（可锁、可撤销组） |
| 底图 | 图片资产引用 + 地面投影变换 + 透明度；**不**自动写入墙几何（本期） |
| 室内外 | 枚举 `indoor \| outdoor`；影响屋顶可见与天气提议，不单独存第二套场景 |
| DXF MVP（预留） | 导入图层 → 候选墙段（米）→ 用户确认集 → 写入结构；未确认不得当墙 |

- [ ] PASS：DXF/DWG/PDF 本期不渲染结构，画布不变。  
- [ ] PASS：单位米；保存重开 L×W 与物件一致。  
- [ ] FAIL：把底图透明度当「已识别墙」。  
- [ ] FAIL：删减画布右工具键或替换 logo。  
- [ ] FAIL（本期）：静默把 CAD 当成功导入。

## 3. Pillar B · 布置修改（编辑）

### 3.1 Jobs

选择、移动、旋转、复制、成组、锁定、撤销/重做、从库放置、属性编辑（尺寸米制、颜色等已有能力）。

### 3.2 落点分工

| 动作 | 左/物料 | 画布+右工具列 | 右属性（选中） | Agent |
|---|---|---|---|---|
| 选/多选/框选 | | ✓ | 跟随选中 | 可读选中作上下文 |
| 移/旋/缩 | | ✓ 变换 | 精输数值 | **提议→预览→确认**（场景级） |
| 复制/删除/锁 | | ✓ | ✓ | 删锁类须确认 |
| 成组 | 待核现有 | 待核 | 待核 | 不可静默拆组 |
| 库放置 | 抽屉 | 落点预览 | | 「我来调」只展开库 |
| 撤销重做 | | **工具列原位** | | 「撤回这步」= 同一历史栈 |

### 3.3 冲突规则（硬）

1. **Agent 不得静默覆盖当前选择或未确认提案写入画布。**  
2. 破坏性 / 场景级（清场、整场替换模板、批量删、改结构墙）：**propose → 用户确认** → 一次撤销组。  
3. 人工编辑或版本/租约变化 → **旧提案失效**（已有 DeepSeek 契约）。  
4. 锁定物件：工具与 Agent 均不可改；提案须报出跳过项。  
5. 「明确指令直接应用」若保留：须 UI 明示范围；默认仍预览（JEV/多候选同理）。  
6. 重叠/超出场地：琥珀标记；**不**包装成消防合规。

### 3.4 Acceptance

- [ ] PASS：库放置后可继续变换；撤销一步回到放置前。  
- [ ] PASS：Agent「舞台往左挪」→ 绿框新位 + 虚线原位 → 确认/撤回（对齐 S10）。  
- [ ] PASS：选中属性与聊天不同时遮死画布主操作。  
- [ ] PASS：模板替换须预览确认；确认前不写场景。  
- [ ] FAIL：Agent 未确认清场或改锁定件。  
- [ ] FAIL：为「简洁」去掉工具列撤销/重做。

### 3.5 Out of scope（B）

实时多人同编、写实渲染、任意 CSG、吊挂叠放、自动排座满场、物理碰撞仿真。

### 3.6 Current → Target（B）

## 5. Pillar D · Agent（晴光）

### 5.1 Jobs

1. **Intake**：活动类型、人数、场地（室内外 + L×W/底图）。  
2. **Propose layout**：基于库/参数族出可编辑初稿。  
3. **Explain**：短句（≤2 行/条）说明做了什么。  
4. **Fix conflicts**：重叠/超出/锁定跳过 — 报问题，不装合规。  
5. **Fill delivery fields**：为评审/执行预填可编辑字段（用户改）；不替用户发客户链。

### 5.2 UI

| 元素 | 规格 |
|---|---|
| 栏 | 右栏主；可收起；收起后画布变宽、状态保留 |
| 头 | 48px 一行：晴光 **3D 毛绒裁切 32/40**（对齐左轨；另备 24/@2x）+「晴光」+ 状态点文案 + n/5 进度；禁扁平 |
| 状态文案 | 主用 **做好了 / 发现问题**；进行中「出方案中」/「等你确认」可并存 |
| 预填卡 | Agent 先填；字段点改；每屏**一个**绿主按钮 |
| 禁止 | Bingo 狗；**扁平头像**；头像角标代替状态；首屏三连 chip 提问 |

### 5.3 Tool loop 契约

| 可调用（对齐现有 DEEPSEEK_AGENT） | 须用户确认 | 禁止 |
