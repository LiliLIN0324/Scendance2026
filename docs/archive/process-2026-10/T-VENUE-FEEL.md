## 钉死

- 纯「改成 L×W」= **只动场地壳**，不是新开一轮布置提案。
- 卸模板可以突然，但文案/黄条不要吓人；入口少绕一层。

## 别扭 → 改法

### 1. 只改尺寸却拉起整套「预览→确认布置」

**现象**：对话「改成 15×10 / 20×12」时，角标尺寸对了，但同一次又开布置预览进度，还可能留「画布被改动、预览作废」黄条。

**改**：
- 识别为「仅改场地尺寸」意图时：走 `replaceVenueWithShell` / `raiseVenue` 立壳即可，**不要**进入生成布置 / 预览卡 / 绿钮确认布置。
- 清掉或不要挂「预览作废」恐吓黄条（尺寸-only 路径）。
- 播报保留一句短的：「场地改成 L×W m」或「已离开模板，按新尺寸立壳」。

### 2. 空白场地入口多绕一层

**现象**：要先「展开物料库」再点「场景模板」才看到首卡「空白场地」。

**改（选最小一种，优先 A）**：
- **A**：左栏简报 / Agent 空闲时给一条文字链：「空白场地」→ 直接执行与模板轨首卡相同的立壳（12×8），不必先开抽屉。
- **B**：进编辑器默认落在「场景模板」轨（若会冲其它工作流则不做）。
- 进场时若已有默认桌椅壳，简报不要写「尺寸还没定」——与角标真实米数对齐（跟 T-VENUE 同步 raw 同一套）。

### 3. 从模板改尺寸无确认、物件瞬间没了（文案已有，再轻一点）

**现象**：青序 →「改成 20×12」无确认卡，模板物件瞬间消失；文案有说明，黄条仍吓。

**改**：
- **不要**加第二颗确认（避免又变啰嗦）。
- 卸模板瞬间：底栏/Agent **一句**说清「模板物件已撤，自有物料能留的已留」；去掉重复恐吓条。
- 撤销仍须能回模板态（回归勿破）。

## 验收

1. 空白场地：≤1 次显性点击（或文字链）能立 12×8 空壳；简报有米数，无「尺寸还没定」。
2. 对话「改成 15×10」（无模板）→ 角标/简报变；**无**布置预览卡、**无**「确认布置」绿钮、**无**预览作废黄条。
3. 载入青序 →「改成 20×12」→ 卸模板立壳；一句说明；无恐吓黄条；撤销回青序。
4. 回归：「40 人，室内 12×9」仍预览→确认布置（与改尺寸路径分开）。
