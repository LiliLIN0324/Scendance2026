## 2. 真机证据（2026-10-26）

页面可见（`visibilityState=visible`），本轮截图可用。场景：体育馆 · 黑客松样例，画布实际 22 件物料。

1. **刷新基线**：`localStorage['scendance-editor-local-v1']` 119591 字节 / 哈希 2084829914；工具栏「撤销」`disabled=true`。
2. **体检**：输入「看看哪里有问题」→ 右栏：
   - 「我按画布几何看了一遍 22 件，找到 1 条」
   - 「只报挤、压墙/柱、出界、挡门前留空和座椅拉不开，不是合规审查。」
   - 「这张场地没有可识别的入口或门，入口通道我不猜。」
   - 「靠边的椅子拉不开。东侧 2 把、西侧 2 把、南侧 2 把椅子背后只有 0.35 m（不到 0.45 m）。」
   - 动作胶囊「按这条改：把靠边的桌椅往场中挪」
3. **点改法（预览）**：画布出现「AI 修改预览 · 尚未加入场景 · 半透明为候选，线框为原位置」；右栏到 `3/4 优化`，卡片「改法预览 / 108 ㎡ · 只挪位置，其他没动 · 挪了 20 件 / 确认布置 / 确认前不会写进画布 · 撤回」。**`localStorage` 哈希仍为 2084829914，撤销仍禁用。**
4. **撤回**：预览横幅消失，右栏回空闲；「撤了：预览收回，物件都还在原位。」哈希仍 2084829914；撤销仍禁用。
5. **再体检 → 再改 → 确认**：哈希变为 2993763508 / 119309 字节；撤销变可用；播报「确认了：20 件换了位置，其他没动。不想要就撤销一步，整体退回原位。」
6. **撤销一步**：哈希回到 2084829914 / 119591 字节，撤销重新禁用，桌椅全部回原位。

> 挪 20 件而不是只挪 6 把椅子：每把临界椅子与它所属的桌+椅组一起平移，保持组内相对关系；动作文案写的是「桌椅」，卡片只写「只挪位置」，没有增删件。

## 4. 体检口径与改法边界

- **查**：重叠（按连通组报）、压墙/压柱、出界、入口/楼梯留空、桌间过道（< 0.9 m）、座椅拉椅空间（< 0.45 m）。
- **不查**：消防/疏散/无障碍/承重/合规认证；隔墙边的起身空间这版不量（报告里有这句提示时才说）；没有入口数据就不推入口通道。
- **不动**：锁定件、结构标记、挂墙件、户外件；找不到不压墙、不碰其他物料的落点就返回 `moved=0` 并说清原因（`locked` / `no-spot`）。
- **不写**：`layout-review` 无 React / 存储 / 网络；改法只返回候选 `RoomLayout`，由右栏复用 T-02 的 `onPreview → 确认 → applyLayout`。

## 6. 待核 / 已知边界

1. **画布撤销后右栏回显卡不刷新**：确认后用工具栏「撤销」退回原位，物料已回原样，但右栏仍停在 `planReady` 的「这一版布置 108 ㎡ · 22 件物料」。这是 T-02 既有同步缺口（非 T-03 引入），本卡未扩 scope；要补需让外部 history 操作失效当前提案，建议另开小卡。
2. **无入口数据**：样例场景没有入口/门，本轮只能验证「不猜」；有入口的 `floorKeepOut` 分支有单测，未真机造入口。
3. **锁件只在单测/面板测覆盖**：真机没有锁椅可点；实现与文案已钉「锁着没动」。
4. **隔墙边的起身空间不量**：`reviewLayout` 对存在内墙的场景会附一句「隔墙边的起身空间这版没量，只查了压墙」，避免把半套检查说成全部。
5. **组移范围**：拉椅空间修复按「桌+临界椅」整组平移，可能挪动多于问题件数；卡片与播报只报「挪了 N 件」，不承诺只挪椅子。
6. **预设标签 21 件 vs 当前草稿 22 件**：当前草稿比体育馆预设多一件上一轮留下的「软包餐椅」，本地持久化所致；体检按画布实际 22 件计算，不是计数错误。
7. **本轮不改**：14 键口径与座位数算法仍挂下一轮；T-04 未动；氛围未点名不开。
