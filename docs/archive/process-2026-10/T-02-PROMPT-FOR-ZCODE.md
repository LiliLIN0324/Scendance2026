## 3. In / Out

### In（本卡可做）

- 假定 T-01 场地已可布置：壳体 + 主入口 + 层高已就绪；**只在已确认壳体上摆物件**。
- 对话出布置初稿：预填卡（活动类型/人数等可点改）→ 一点绿主按钮出提案。
- Agent 流程：**建议 → 画布预览（绿框新位 + 虚线原位，对齐 S10）→ 确认 / 撤回**；确认前**不写场景**、**`objects` 不落盘**。
- 人工布置：库放置、选/移/旋/缩、复制删除锁；属性米制；撤销重做与工具列**同栈**；画布右 **14 键工具列原位冻结**。
- 家具 / 物料写入 **`objects`（或等价家具层）**，**不污染 `structure` / 墙门环**。
- 重叠 / 超出场地：琥珀标记；通道 / 出口类提示若有 → **只读壳层**，文案须带 **「非合规认证」**（不包装成消防结论）。
- 锁定件：工具与 Agent 均不可改；提案须报出跳过项。
- 右栏 chat-first；进度亮对话四步 **②**；**一屏一张预填卡 + 一个绿主钮**；状态仅「做好了 / 发现问题」点+文字。
- 头像 / 状态切图：见下节 **「IP / 晴光硬钉」**（面板 32/40 毛绒；ask/done/issue 用独立切图）。

### Out（明确不做）

- **氛围 / mood / 天气 / Bloom / 室内雨 / bake 进 Scene / 新开氛围页 / 布置步提 NPC** → 全部留给 **T-03**；T-02 **零氛围码**。
- 再改 **`venue.site` / `venue.height` / 墙门环 / 比例尺度** → 要改尺度 **退回 T-01**，本卡不动场地真相。
- 另造平行高度字段（如 `ceilingHeightM`）；确认前报假米数（场地侧属 T-01，本卡亦不碰）。
- 静默落画布、代拖 3D、未确认 apply、静默拆组 / 清场 / 整场换模板；说「已帮你摆好」或确认前报「已保存」。
- 左轨改成四图标；**新开布置页**；精简画布右 14 键；换 logo；首屏 chip 连环问；角标叠在头像文件上。
- 代发客户链、评审/执行交付（T-04）；DXF-first、假装已识别 CAD。
- 实时多人同编、写实渲染、任意 CSG、自动满场排座、物理碰撞仿真、消防承重认证。

## 4. Agent 流程（建议 → 预览 → 确认）硬钉

1. 用户在右栏说清意图（或点预填卡后主按钮）→ Agent **只出提案**，画布上可视化预览（**绿框 = 新位，虚线 = 原位**）。  
2. 右栏主按钮文案 **「确认布置」**，次要 **「撤回」**；**用户点确认** → 一次写入 `objects`；写入进撤销栈（可一步撤回）。  
3. **用户点撤回 / 忽略** → 场景保持确认前状态；**未确认前 `objects` 不落盘**。  
4. **禁**：静默落盘、代拖物件、未确认就改 `objects`、覆盖当前选择而不提示；不说「已帮你摆好」、确认前不报「已保存」。  
5. 破坏性 / 场景级（清场、整场替换模板、批量删）：同样 **propose → 确认**；锁定件跳过并在提案中列出。  
6. 人工编辑或版本变化 → **旧提案失效**（对齐现有契约）。  
7. 话术与头像状态切换见下节；布置步**不提**氛围 / 天气 / NPC。

### 4.1 IP / 晴光硬钉

**头像文件（面板只用这些，禁 flat / Bingo）**

- 默认面板：`frontend/public/assets/assistant/qingguang-3d-32.png`、`qingguang-3d-40.png`（及对应 `@2x`）。  
- 状态切图（**独立文件**，**禁**把角标叠画在头像上）：  
  `qingguang-3d-{32|40}-{ask|done|issue}.png`  
  - **ask**：提案 / 等你确认  
  - **done**：用户确认落盘后  
  - **issue**：冲突、缺入口、层高未确认等需处理  

**话术（短、克制、先问再做）**

- 提案示例：「先出一版可拖的初稿，确认前不会写进画布。」  
- 确认前示例：「还没落盘，点确认才应用。」  
- 状态文案仅用点+字：**「做好了」** / **「发现问题」**（不用头像角标代替）。

**禁越权**

- 不代拖；不说「已帮你摆好」；确认前不报「已保存」。  
- 布置步（T-02）不提氛围 / 天气 / NPC。

### 4.2 UIUX 硬钉

1. **提案态**：画布绿框 = 新位、虚线 = 原位；右栏主钮「确认布置」+ 次要「撤回」；未确认前 `objects` 不落盘。  
2. **右栏**：进度亮 **②**；一屏一张预填卡 + 一个绿主钮；**禁**首屏 chip 连环问。  
3. **工具列**：14 键原位冻结；禁代拖；锁定件在提案中列出跳过项。  
4. **文案**：左轨仍「布置 / 评审 / 执行」；状态仅「做好了 / 发现问题」点+字。  
5. **禁**：氛围、新开布置页、精简工具列、换 logo。  
6. **验收锚点**：确认前场景不变；确认后可拖改。
