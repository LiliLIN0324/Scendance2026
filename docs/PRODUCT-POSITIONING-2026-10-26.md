## 1. 品牌 slogan（2026-10-29 钉死）

| 位 | 文案 | 用在哪 |
|---|---|---|
| **主 slogan** | **为相聚，留一方空间。** | 官网 hero、宣传册封面与收尾、一切对外物料；一字不改 |
| 固定断行 | 为相聚，<br>留一方空间。 | 官网 hero 照此断行 |
| 副标 | 从一个想法，到一场真实活动。 | 主 slogan 下方一行 |
| 眉标 | 三维场景协作 · AI 驱动的活动空间设计 | hero eyebrow，不单独当 slogan 用 |

- **只此一句。** 不自造第二句口号。「用一句话，布置一整场活动」「说清楚，就排得出来」这类是能力描述与说话风格，不进封面、收尾，也不与主 slogan 并列。
- 主 slogan 不拆词当小标题（「留一方空间」不单独拎出来做标题）；副标与眉标不互相顶替。
- 与设计规范的同一张表（`docs/design-spec-2026.md` §三.4）保持一致，改一处必须同改两处。

## 2. 卖什么 / 不卖什么

| 卖（主线） | 不卖（不是核心卖点） |
|---|---|
| **活动场景方案**：布置物料策划 + 文案 / 交付的专业感 | **3D 空间重建能力**本身（自研世界模型、自建重建产线） |
| 对话布置、物料清单、可交付方案包 | 「我们会训世界模型 / 自研 3DGS」话术 |
| 信息差 + **全流程服务**赚差价 | 把重建 API 当产品主价值对外包装 |

一句话：**幕景卖的是活动场景方案，不是卖 3D 空间重建能力。**

## 3. 成本与商业故事（外包重建）

- **3D 重建**：外包即可。参考量级——Viggle 约 **$0.06–0.14/次**，或国内约 **¥50/月包**（选型细节与价格表见 `3dgs-demo/docs/image-to-scene-vendors-2026-10-26.md`；**勿在本文件改价表数字**）。
- **充值节奏**：**有客户再充**；未成交不囤额度。
- **物件生成**：几乎零成本（库件 / 轻量生成），不挡主线。
- **利润结构**：信息差 + 布置策划 + 文案交付 + 全流程服务 → **赚差价**；重建是成本项，不是卖点。

### 成功样板（演示叙事）

模拟跑通一次完整故事（可假可真外包，观感层够用即可）：

1. **场景重建**（假对接样例 splat，或真实外包一次）
2. **单体布置**（glTF / 库件落位）
3. **物料**（清单 / 规格）
4. **文案产出**（方案说明、交付专业感）

验收观感：客户感到「方案与交付很专业」，而不是「你们重建技术很强」。
