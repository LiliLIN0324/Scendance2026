## 二、SfM 探针结论（判哪些素材能用）

工具 pycolmap 4.2.1，脚本与报告在 `%TEMP%\scene3d-probe\`（`outdoor_report.md`、`outdoor_final2_report.json`、`outdoor_views_m0..2.png`、`outdoor_points_final_m{0,1,2}.ply`）。

1. **焦距先验裁切陷阱**：同机 4 种裁切模式下，max-edge 归一化会让竖切先验错 1.33 倍（真实 f≈1175px @1600，横幅 889.6px）；先验错 → 配准卡死在 4 张碎片。修复后正常。
2. **窄视场全景裁切 BA 退化**：SIMPLE_RADIAL 在 2.67:1 裁切上 f/k 互相补偿（f 冲到 250 万）；**按模式冻结 SIMPLE_PINHOLE 是最稳形态**。
3. **雕塑环绕有真实视角断层**：A/B 簇之间 tvg≥30 桥接对 = 0，调参/提分辨率都救不了——**采集问题，不是算法问题**。
4. **白天↔夜晚跨时段对全是假几何**（树木重复纹理），必须剔除只留会话内对。
5. 门槛实测：mapper "insufficient size" 丢弃门 = init 后点数 < 0.5×图像数；`min_model_size=1` 才能让小碎片现形。

## 三、Aholo 真调（**已打通：视频路径重建成功**，2026-11-05）

### 三层真相（每层都实测过）

1. **建任务层**：`POST /world/v1/reconstructions` **必须带 `x-source: openapi` 头**——不带就报误导性错误 BIZ_-1「文件链接不对」（与素材无关，纯路由/项目上下文问题）。已修进代理 `lux3d-dev-proxy.mjs`（world 请求统一带该头，需重启代理生效）。
2. **图片资源运行时层**：建任务受理（带 x-source）后，**图片素材在运行时 ~1 分钟速死 FAILED**（本日凌晨 ×8 + 本晚 ×1 同模式，退款），API 不吐失败原因。开放平台 OUS 上传的图片当前跑不通——疑似 recon worker 读不到 OUS temp 文件，**这是 Aholo 侧待报的 bug**。
3. **视频资源层**：`type=video` + x-source → **完全正常**。`3FO4K4RKIQ9S`（0194 亭内 26s 走拍，极速预览档）：**8.5 分钟 SUCCEEDED**，SPZ **6.1MB**，upAxis=Z。

### API 规则实测（第一手）

- 图片路径硬性 ≥20 张；**图/视频不可混传**；纯视频须全部 `type=video`。
- OUS 流程（domestic token → single/block upload → status.url）与 OpenAPI 一致即可用；国际网关无 `asset/v1/token`（404）；status.url 落在 `holo-cos.aholo3d.cn`（`ous-cos.kujiale.com` 形态 404，不存在可换）。
- `/world/v1/list` 未开放（404 project not exist）；任务失败原因不通过 API 暴露，**只能靠账单页反推**（失败退回 +50/±80/±20 对应 normal/high/low）。
