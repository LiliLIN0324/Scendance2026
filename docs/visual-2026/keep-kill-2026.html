01KEEP（必须留下）

条目说明
KEEP · 一条主路径选活动 → 定场人数 → 生成 → 确认 → 导出
KEEP · 左轨三枚布置 / 评审 / 执行；没有第四枚
KEEP · 确认前零写入提案预览；人点确认才落盘 / 改仓
KEEP · 一步一主钮空闲无绿色主按钮；确认钮只在待确认态出现一次
KEEP · 三视图一份方案布置 · 物料 · 执行资料可来回切，不另开产品
KEEP · 晴光场边一次右栏对话是生成主入口；不另开全屏聊天吃掉画布
KEEP · 高德只定场地图圈画 + 采集单；重建走现场素材 / 干跑
KEEP · 观感只铺背景.spz / 3DGS 不进碰撞、不进落盘几何；壳体 + glTF 布置不变

02KILL（必须杀掉）

条目为什么杀
KILL · 第二工作台重建 / World / Lux 另开一套首页 = 产品碎成两半；全部挂回布置轨「观感」
KILL · 卫星当重建素材高德/卫星不可作 3DGS 重建输入；采集单与面板顶条必须写清禁令
KILL · 样例冒充本场干跑历史宴会厅等样例须标明样例；不得暗示「这就是你刚圈的场地实拍重建」
KILL · 第四枚左轨场景 / 物件 / 合成 / 接口测试升轨 = IA 崩
KILL · 两颗确认 / 向导化n/4 步骤条、双确认、空闲绿钮引导 = 考试感
KILL · 生成中可确认对着空气点确认 = 不确定性不诚实
KILL · 中英混用主钮界面主行动必须中文动词统一
KILL · 未确认就导出当真交付物只能来自已确认方案（或明确标注草稿）

03一句话自检

做功能前问
  • 它是否让「选→定→生成→确认→导出」更快更清楚？
  • 它是否需要新左轨图标或新工作台？需要 = 停
上观感前问
  • 素材是否现场采集（非卫星）？
  • 屏上是否写清样例 / 干跑 / 不进碰撞？
