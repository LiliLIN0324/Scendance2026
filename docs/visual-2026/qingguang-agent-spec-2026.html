三条不可让的硬钉

一句话进来，先走这七段

你打的字到画布上的物料，中间是这七道。后面每一幕对话，都能在这里指出它卡在第几段。

1命令闸

先当命令认：停一下 / 撤回 / 换一版 / 出清单 / 导出。认出来就不进简报，免得「停一下」被记成需求。

2归一化

去空格、全角转半角、中文数字转阿拉伯。「十二乘九」和「12*9」走同一条路。

3先抠面积再数人头

「108 平米」不能被读成 108 人；顺序反过来就会算错。

4听懂

接上云项目先问模型 /brief/extract，12 秒不回来就用规则版兜底。

5跨句记忆

这一句没说全的，沿用上一句记下的。分三句说完和一句说完是同一版方案。

6决策

四种回法：出方案 / 只催缺的那格 / 复述已记下的 / 承认这句没接住。

7落地

立壳体 → 算候选 → 逐帧预览 → 人点确认才一次 applyLayout。

地图支路硬钉：定场 ≠ 重建素材

户外地图支路已接通采集单与左栏「场地观感」。晴光说话时必须把定场与重建分开，不许暗示卫星图能出 3D。

高德只定场 + 采集单

圈画报真实米数、立壳体、给出沿边界站位。不说「用地图直接重建」。用户问卫星能不能当素材时，直接拒绝并指向现场视频/照片。

你说能不能用卫星图重建这块地
晴光说不能。卫星和高德图只用来圈范围；重建要你按采集单在现场拍视频或绕场照片，再进左轨「观感 · 场地重建」。
观感层不是布置几何

World / 场地重建铺的是背景观感；碰撞、落盘、导出几何仍只认壳体与 glTF 物料。不要说「点云也能拖动物料」。

附录 C · 验收：照着打一遍就行

打开 /editor，本机 mock 即可。前八条来自上层框架的截图级 checkbox，后段是对话级判据。每一行都能截图或实测证明。

打这句判据
「80 人发布会，室内 12×9」画布有可见方案或明确待确认预览——不是只涨聊天气泡
空闲右栏找不到任何 btn-primary（含导出、下一步类）
「发布会」→「80 人」→「12×9」分三句只出一版；中途每次催的都是缺的那格
「今天天气不错」琥珀一句，画布不动，不空跑一趟生成
「108 平米」播报带「按 4:3 折算、你改过我才当准」，墙标 inferred
「改成 15×10」只动壳、一句短播报、不把你从 2D 拽回 3D
拖图纸 →「300平米，按图纸估」折的是 300 ㎡ 不是画布旧空地，播报含「你说的 300 ㎡」本次修好
「改成 200×150」报出 100 米上限与一句可说的下一步；简报退回真实米数本次修好
「加两把椅子」只加两件的绿框；放不下几件就直说只放得下几件
预览期间「改成 8×6」预览作废并说明原因；确认前撤销栈里没有提案
摆一版后「看看哪里有问题」六类按固定顺序报；算不出改法就直说不硬挪
锁 6 件后「换一版」卡上出现「锁定 6 件我没动」；云端动了锁定件则确认钮按住
「停一下」→「接着摆」预览收回、画布没动；接着摆从第 N 帧续，不重演
「换区」如实说没有分区层并给替代路径，不硬演一个假控件
「导出给搭建方」未确认时绿钮不亮并给一句原因；确认后只在本机生成
本机 mock 下打开右栏常驻「演示环境 · 未连接真实 AI 模型」一条，不许摘
看抬头状态点只出现「做好了」/「发现问题」两种说法
数左轨图标永远三图标；对话进度不升格成第四图标
