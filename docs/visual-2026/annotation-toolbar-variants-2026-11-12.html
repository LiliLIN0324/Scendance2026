唤出态 · 白色菜单

父钮形制图标 + 右下下拉箭头，箭头与图标间细分隔槽；父钮显示当前选中形状，选中态绿底；点图标区直接用当前形状，点箭头开菜单（同 Figma）。
菜单形制白色 #fff 圆角浮层 + 发丝描边，行高 36：勾选列 + 图标 + 名称 + 右侧手势/快捷键徽标；当前项浅绿底 + 绿字，顶部小三角指向父钮。
属性行（本轮纳入）颜色取图层 token 色板：缺省标注紫 #8e44ad，另墨 / 绿 / 蓝 / 橙 / 粉 5 点，不另造色值；线宽细 / 粗两档，仅形状显示，文本备注不显示。选中工具后浮在浮条上方，取消即收起。契约 color 已有；线宽需在 PlanAnnotation 补可选字段（thin / thick）。

落地复用：这套菜单在代码里已有同形制——选择工具菜单（sc-tool-pop 弹层、sc-canvas-tool-row 行、sc-tool-key 快捷键徽标、sc-tool-check 勾选），标注形状父钮照此套接线即可，不新造弹层。手势徽标位可先放「拖 / 两点」「点 3 点」，快捷键待全局键位确定后补。入口钮（右轨 #tool-annotate）图标沿用现状 edit_note；浮条内形状父钮显示当前选中形状，两者不要混用。

入口图标候选

入口图标本轮选定现状 Material Symbols edit_note（三条横线 + 斜铅笔），沿用现有 Material 体系，不换图标族；下方按语义列出备选，供后续迭代参考。功能 = 文本备注 + 四种形状圈画，圆钮内为 18px 线稿示意。

编辑便签 edit_note 选定

三横线 + 斜笔，「在笔记上改注」；沿用现状图形，不换图标族。

Material 码点表 edit_note: 0xe745 + edit_note-fill.svg 双闭环，右轨三钮同为 Material 体系；OUTDOOR_TOOL_ICONS.annotate 保持不变
便签 Sticky Note 备选

折角便签 + 两行文字，偏「留备注」；FigJam、MS Whiteboard 的 Add Note 都用便签形。本轮未选，留作后续迭代。

若日后换此形：右轨钮切到 Lucide sticky-note（StickyNote 已注册闭环）；本地 Material 未登记便签 glyph，不走 Material 名
留言气泡 MessageSquareText

气泡内带横线，偏「评审 / 反馈留言」；MS Whiteboard 的 New comment 用蓝气泡。若标注主要是给方案提意见，这个最贴切。

Lucide 需新增注册 message-square-text；Material 对应 comment
定位图钉 Pin / MapPin

把标记钉在场地上，定位感强；但不体现备注文字。注意与设施点位的 MapPin 区分，避免两个定位图标打架。

Lucide pin 需新增；map-pin 已注册；Material 对应 push_pin
纸 + 笔 SquarePen

载体（纸）和动作（笔）都在，折中方案；比 edit_note 主体更完整，30px 下不碎。

Lucide 需新增注册 square-pen；另有 notebook-pen、pen-line 可选
高亮笔 Highlighter

圈划重点，偏手绘；FigJam 工具条有高亮笔。不体现文本备注，适合标注以圈画为主的定位。

Lucide 需新增注册 highlighter；Material 对应 highlighter_pen
