读法：绿边 = 现状在用；绿底 = 本轮推荐；其余为备选。同一列工具钮最终只选同一族、同一填充与尺寸档；小景唯一保留手绘形体，Material 只作退路。 所有数字为示例，不改动业务代码。

一、三种风格方向（先定族，再挑图形）

族的选择比单枚图形更重要；规范默认通用 UI 走本地 Material 实心。

A · Material 实心 300

规范默认族；圆角实心、currentColor 取色；左轨工具钮主用这一档

B · Material 实心 400

个别字形 300 过轻时改 400 填充；仍同库同圆角，不另起描边

C · 线条描边（例外）

只给面板内编辑工具；左轨入口不进描边族，避免与户外面板工具栏混源

二、小景 · 唯一 Agent（身份槽）

身份槽的作用是「认人」，成熟产品助手位也用头像式形体与工具钮分层；不与工具族混源。

三、空间 · 场地结构 / 图纸 / 环境

职责：选址后的场地结构、图纸与环境。

四、物料 · 物件规格 / 模型 / 生成

职责：物件规格、模型与生成。

五、拍摄场地 · 拍照 → 当场判断重建 → 出 3D

行为是面板开关，不是外链；备选覆盖「拍摄 / 扫描重建 / 三维」三种语义侧重。

六、户外规划 · 地图上画边界 / 分区 / 动线

右侧地图常驻；轨钮只切左栏户外面板。

七、成熟产品参考（按分组）

分组参考案例可借鉴点
助手 / Agent 身份槽Slack bot 头像、Discord 机器人头像、Notion AI sparkle、ChatGPT 侧栏助手字形助手位用圆角头像式形体，轮廓与下方工具图标分层；不进同一直方实心族
工具功能槽（同族实心）VS Code 活动栏、Linear 侧栏条目、Notion 侧栏页面 / 数据库、Slack 频道列表同一列工具钮同一字形库、同填充同尺寸；图形只表达动作 / 对象，不带角色脸
采集 / 扫描动作系统相机工具栏、扫描类 App（备忘录扫描、扫描件入口）取景钮动作型入口用识别度高的相机 / 扫描实心形；三维含义另配副标识，不靠图标独自承担
地图 / 户外Google Maps 入口、浏览器地球、地图产品罗盘 / 点位图标整片场地用地图或罗盘，单场地用四宫格，单物件用箱体；层级不要互相串
真人身份槽微信 / Discord 私聊头像 + 未读圆、团队成员状态头像头像族保留照片 / 首字母圆片；未读圆与 Bingo D 徽标同形同尺寸，只配色不同
待定：空间与户外是否都用地图类图标需要拉开层级（建议户外用 map / explore，空间留 grid_view）；拍摄场地是否在图标旁副标「3D」文字，第二轮定。
