> 状态：待用户点头 · **未点头不改产品仓代码**

## 一句话判断

现版像「上个时代的活动工具」：暖奶油底 + 鼠尾草绿 + 木色，Chrome 厚、说明多。  
2026 方向：**冷中性纸面 + 近黑字 + 单点靛蓝强调**，架构不动，气质换成 Linear / 当代设计工具那一类。

## 架构（保留，不改）

| 区 | 职责 |
|---|---|
| 左轨 | 仅三段：**布置 / 评审 / 执行**（可缩成图标） |
| 中场 | 3D 画布为主；周边工具岛 **静默**（T-06：无旁注说明书） |
| 右栏 | **chat-first Agent**（晴光头像 32/40 3D 毛绒，禁扁平/Bingo） |
| 左简报 | 对话驱动填参；人只改，不逐项问卷 |

## 气质（绝对简洁 · AI-native）

1. **负空间优先**：顶栏一条细线；面板不要双层卡片套卡片。  
2. **禁按钮旁说明书**：图标即可；悬停再出短 tooltip。  
3. **工具岛静默（T-06）**：画布边竖条或底中一条，只有图标，无「选择 / 移动 / …」常显文案。  
4. **一屏一事**：右栏聊；中场看与拖；左轨切阶段。  
5. **强调色只用一次**：选中左轨阶段 + 发送键；别处不要再铺靛蓝块。

## 色板（全新 · 勿沿用旧 token）

| Token | Hex | 用途 |
|---|---|---|
| `bg.app` | `#F4F5F7` | 冷石纸面（**不是** `#F3F4EE` 奶油） |
| `bg.panel` | `#FFFFFF` | 右栏 / 浮岛 |
| `ink` | `#141416` | 主字、选中图标 |
| `ink.muted` | `#71717A` | 次级字、未选图标 |
| `line` | `#E4E4E7` | 发丝分割 |
| `accent` | `#4F46E5` | **仅**阶段选中 + 主操作（发送） |
| `accent.soft` | `#EEF2FF` | 选中底（极淡） |
| `canvas.void` | `#E8EAED` | 画布空态地面/墙暗示 |

**明确禁用：** `#F3F4EE`、`#66835D`、`#A58B69` 及一切暖黄绿奶油洗。

## 组件规则（可执行）

| 组件 | 做 | 不做 |
|---|---|---|
| 左轨 | 三段图标；选中 = `accent.soft` 底 + `accent` 图标；文案「布置/评审/执行」可缩到悬停 | 不要「空间/家具/氛围」等产品外三段；不要长标签常显 |
| 画布工具岛 | 6 内图标、圆角 12、白底 `line` 边、无字 | 不要每钮旁说明；不要大色块工具条 |
| 右栏 Agent | 短气泡；输入框一条；发送 = `accent` | 不要欢迎长文案墙；不要问卷式表单抢 chat |
| 顶栏 | 品牌字 + 项目名下拉 + 极简右侧 | 不要帮助中心入口常显；不要黄绿 logo 底 |
| 底栏素材 | 默认收成一条「素材」 | 不要展开占半屏 |
