图标整体风格 · 五个方向对比

基线 main 工作树 ｜ 小样用同一枚户外地球示意各风格 ｜ 只出方向判断，不改代码

先回答：是的，我推荐通用工具/控件走实心主族——你刚觉得这枚实心地球顺眼，正是因为导航轨压在地图浅底上，实心小尺寸重量足、辨识度高。但这不是全产品一把实心：家具、结构、道具这类领域图形仍留线性族；品牌身份和状态计数是例外。下面五个方向并排看，最后一列标了各自在我们产品里落在哪。

A · 实心主族

推荐主族
fill 实心
fill 实心
成熟案例：Affinity 深轨实心一族、Google Maps 圆钮、Android Material
利：小尺寸重量足、地图浅底上清晰、导航列整齐；本地已有 fill 资产与桥接，收敛成本最低。
弊：细碎图形全实心会偏闷，不适合画家具/结构。
我们落点：左轨工具四枚、右轨通用控件、按钮、面板行内图标。

B · 全线性主族

不作主族
outline 线性
outline 线性
成熟案例：Miro 左轨、Figma 工具条、Lucide / Tabler outline
利：轻盈现代，镂空细节好表达，适合画物件。
弊：地图浅底上 16/20 线性辨识度偏弱；要另起一套，现有 fill 资产用不上，两套线性族并存的老问题还在。
我们落点：不做通用主族；保留给家具、结构、道具等领域图形（现 Plotcraft 线性族）。

C · 双重量成套

借思路 · 不养双套
静息 outline
激活 fill
成熟案例：Tabler Line / Fill 双重量成套，反义状态同骨架
利：静息线性、激活翻实心，状态层次细腻。
弊：每个图标要维护 outline + fill 两套字形，设计与回归成本高。
我们落点：只借“选中加重”的表达，不养双套；选中态用左绿条 + 图标转绿/反白完成。

D · 块面 + 单点品牌色

仅限例外位
墨黑块面
大陆块品牌绿
成熟案例：Affinity 局部彩色工具、转塘艺讯盾形 + 绿点
利：有记忆点和品牌温度，身份位辨识度高。
弊：彩色一旦外扩到工具钮就会乱；品牌绿全产品只该出现在选中指示和发送键两处。
我们落点：只限总控、Bingo 这类身份/状态例外位；工具钮保持单色 currentColor。

E · 同族多字重分档

配合 A 使用
16 行内
20 控件
24 面板
32 空态
成熟案例：Phosphor 16/20/24/32 四档六字重；Material 可变字体自带 weight / grade / optical-size 轴
利：同一族靠字重和尺寸分档，大小处都清晰，不必为小尺寸另换一套字形。
弊：要把档位写进规范，消除现行 14/15/26 这类脱离档。
我们落点：配合 A——16 行内、20 控件、24 面板、32 空态；导航工具入口统一 24，品牌/状态例外可到 28。
分层落点（推荐组合）
品牌身份位
总控 door 软形体 + 眼睛，例外自有形，不进工具族（方向 D 的温度只留在这里）。
状态计数位
Bingo 圆环 + 角标 + 勾形，构形即状态，保留例外。
通用工具 / 控件
方向 A 实心主族：左轨工具四枚、右轨通用钮、按钮、面板行内；按方向 E 分档。
领域图形
方向 B 线性族：家具、结构、道具、场地构件；与通用控件分族，不混重量。
选中 / 激活
借方向 C 的加重思路，但不养双套：左绿条 + currentColor 转绿或反白。
品牌点缀色
方向 D 仅限例外位；品牌绿全产品只出现在选中指示与发送键，工具钮单色。
