01旅程总览

主办人的完整旅程是五段直线。重塑前，四个按钮散落在两条支路上、动词不统一、主次颠倒；重塑后，每一阶段只有一个需要点的主按钮。

STAGE 1

接需求

写目标、定类型与人数；可点 ✦ 生成需求参考。

按这份细表生成预览
STAGE 2

备资料

上传平面图或现场照片；未连接时出现前置卡。

连接场景服务
STAGE 3

出预览

填已知尺寸 → 识别结构 → 核对比例与墙线。

生成布置预览
STAGE 4

定方案

画布上核对候选，确认才写入场地；可撤销。

确认应用并保存
STAGE 5

交执行

活动安排、物料点验与本机备份，导出交接。

执行资料

情绪曲线：上传后等待识别是唯一低谷（②→③），已用前置卡说明等待预期；确认应用与导出是两个高点。

02四阶段明细：痛点 → 解法

① 接需求

客户需求页签
重塑前
  • 底部并排「生成布置预览」与「暂不填写」，主次尚清但去向不明。
  • 不知道「暂不填写」点了会发生什么。
重塑后
  • 主钮改叫「按这份细表生成预览」，把「这是按你填的细表算的」写进按钮；is-manual 次要样式保留，生成主入口仍在右栏对话。
  • 次钮改为「暂不填写 · 先回画布」，把去向写进按钮。
  • 左栏改过一项（活动类型／人数），右栏简报与对话回显立刻跟上；没保存过的表单默认值不算你填的，不冒充简报。

② 备资料

图纸与照片页签 · 上半
重塑前
  • 「准备场景连接」裸露为一个常驻按钮，不知道何时该点、点了干什么。
  • 「编辑当前场地」卡片占据面板顶部主视觉，像是流程第一步，实为维护动作。
重塑后
  • 连接改为前置卡：只在未连接时出现，说明「资料会保留、连接不改场景」，按钮「连接场景服务」；连上即消失。
  • 场地编辑降级为底部「进阶」块，标题带当前尺寸。

③ 出预览

图纸与照片页签 · 输入与核对
重塑前
  • 「Generate 重建并设计方案」中英混用，与另一支路的「生成布置预览」指同一类动作。
  • 尺寸输入无标题，只靠占位文字。
重塑后
  • 中英混用的「Generate 重建并设计方案」改成「生成布置预览」，动词统一为中文。
  • 输入区补标签「已知尺寸（米）」。
  • 客户需求支路那颗同日已降为「按这份细表生成预览」——两条支路不再共用一个词，是因为右栏对话才是生成主入口。

④ 定方案 → ⑤ 交执行

画布与执行页签
重塑前
  • 候选确认按钮嵌在巨大表单 fieldset 里，与「我在填的输入」混在同一个禁用域。
重塑后
  • 结果区独立成「结果与确认」分区，与输入分区平级；场地编辑期间由函数守卫互斥，不再靠嵌套连坐禁用。
  • 候选应用并保存后，结果区出现「回对话继续布置」，一点把光标交回右栏对话；这条支路干完活不再断头。

04信息架构：嵌套分区

fieldset 收缩回「只锁输入表单」的本职；任务状态、结构核对、候选结果升为平级分区，各分区自管互斥。

图纸与照片
├─ ① 资料           上传卡 + 图纸列表 ＋ 参考底图（折叠）
├─ ② 输入           fieldset「生成输入」（唯一禁用域：场地编辑 / 表单未就绪）
│      连接前置卡（条件渲染）→ 已知尺寸 → 尺寸清单 → 模式与要求 → [生成布置预览]
├─ ③ 进度与核对     任务状态 / 结构核对（比例闸 + 平面图 + 墙线）/ 原图对应
├─ ④ 结果与确认     三维候选 → 确认应用并保存 / 放弃；当前方案创意（折叠）
└─ 进阶            编辑当前场地（草稿 → 对比图 → 勾选确认）

05五条设计原则

一步一主钮每个旅程阶段只允许一个墨底主按钮，其余全部降级为次级或前置。
前置成卡先决条件不用裸按钮，用会消失的说明卡，把「为什么」讲完再给动作。
维护降级编辑、微调类动作沉到底部进阶区，标题即状态（当前尺寸）。
动词统一同一类动作跨页签同名；中文界面不出英文按钮。
去向透明出口类按钮把目的地写进文案，用户点了就知道发生什么。
