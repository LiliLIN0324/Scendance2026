一、先分清三个工具：Move / Hand / Scale

Figma 菜单里三行分别是什么；本项目合钮只对应前两个。

Move / 选择（V · 本项目 S）

选中画布上的物体、拖动局部物体移动。对应本项目的「选择工具」。

Hand / 抓手（H · 本项目 H）

不选中物体，按住拖动整张画布平移视图。对应本项目的「抓手工具」。

Scale / 缩放元素（K · 不纳入）

选中元素后拖控制点做等比缩放、旋转。本项目没有等价的「缩放选中物体」工具，合钮不放这一项。

三、单钮循环切换 · 可点方案

取消弹层；点钮在抓手 ↔ 选择间循环；前后图标交换位置；底部状态条播报当前工具。

画布 · 示意
抓手工具 H 点击钮或按 H / S 切换

规格要点

  • 槽位：沿用工具族 40×40 正圆；图标栈 20×20。
  • 前景：当前工具 20px，ink / green-deep，完整清晰。
  • 后景：另一工具 16px，偏右下 3px、faint 色露边；不响应点击。
  • 切换：单击循环互斥；H / S 快捷键直达保留；不开菜单。
  • 过渡：前后图标 0.14s 换位，后景淡入；不做夸张立体投影。
  • 状态条：paper 底 + hair 边 + E1 投影；工具名 + 快捷键徽标 + 提示；aria-live 播报。
