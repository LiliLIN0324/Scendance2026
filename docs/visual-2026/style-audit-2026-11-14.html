三、调整方向（按优先级）

沿 petitmaker 一个组件一个组件改；令牌先行，业务逻辑不动。

P0

禁用态收口：删掉三套整钮透明度

右轨 disabled opacity .45、walk/grid 内联 .35、楼层柱 .55 并存；规范禁用口径是 plane 底 + faint 字、opacity 1。

调整：抽统一禁用基础类，内联 opacity 全部迁出；未接住的能力置灰 + tooltip 说明，不触发室内壳。

P0

静息态品牌绿回收

漫游钮未选中就是深绿字（#35624A），属静息态用品牌绿；规范品牌绿只给选中指示与发送键。

调整：静息回 ink-soft；选中再显绿边 + green-deep 字；地图罗盘红针属领域语义，保留。

P1

槽位与阴影上收到同一套工具令牌

右轨 30、覆盖层 34、罗盘 36 三档；投影轻重断层，覆盖层 4px 14px 超出 E1。

调整：工具钮统一 --tool-size（桌面 40 / 窄屏 36）、E3 级轻投影；浮层/tooltip 才用 E1；左轨 40 触达不动，r12 回 r-sm 10。

P1

图标档位与族收编

26px capture、13px Bingo svg、菜单行 15 / 勾 14 越档；覆盖层字符 ▢/◱ 作图标；自绘 HandStop / MoveScene / GridSnap 待逐枚对照登记表。

调整：控件图标 20、行内 16；字符钮换已登记 map / layers 族；有同语义 Material 形优先替换，确属领域图形的登记例外。

P2

覆盖层内联样式迁入 CSS 类

交付钮、底图钮、底图面板、2D/3D 胶囊的尺寸/边框/投影走内联与 PLANNING_* 常量，主题变量接管不到。

调整：迁到 globals.css 工具族基础类，接 --tool-* 令牌；PLANNING 常量只保留面板内部布局，不落到钮面规格。

P2

地图控件角区归位

缩放 +/- 现在在右轨底部，未与底图钮成组；罗盘、比例尺、署名在左下，落点与地图惯例对照。

调整：底图钮 + 缩放 +/- 收右下地图簇（待真机对照拍板）；署名贴左下，比例尺/罗盘落点对照 Google / Mapbox 惯例。

四、仍需拍板的口子

1. 工具钮槽位：上收 40，还是保 30 圆钮 + 补 32 触达（建议 40）。
2. 楼层胶囊：深色圆头箭头柱是否改白底工具族圆钮。
3. 缩放 +/- 留右轨底部，还是挪右下地图簇成组（建议挪，待真机对照）。
4. 跨栏选中表达：左绿条 / 右绿描边维持两套族语义（建议维持，只对齐令牌）。
5. 自绘三枚图标：哪些换 Material、哪些登记领域例外，逐枚对照 outdoor-tool-icons.ts。
6. 户外方案层是否需要在地图簇旁补快速上下切换入口。
