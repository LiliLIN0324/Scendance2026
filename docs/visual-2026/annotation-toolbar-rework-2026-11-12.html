成熟案例对照

三款产品的标注 / 绘图工具条，规律一致：一级工具纯图标、分组用分隔线、手势说明进 tooltip，属性（颜色 / 粗细）二级浮现。

Excalidraw

顶部一条白色浮条：选择、矩形、菱形、圆、箭头、直线、画笔、文本、图片全是图标；同组竖线分隔；悬浮出名称与快捷键。颜色 / 描边宽度在左侧属性板，不常驻工具条。

Figma · FigJam

底部圆角浮条，图标为主；同类形状收进一个带小下拉的图标钮；文本用「T」字形；画布内只留一句占位提示（Press Enter to add text），不写操作段落。

Snipaste

截图下方一条工具条：矩形 / 椭圆 / 直线 / 箭头 / 画笔 / 文字 / 马赛克 / 橡皮全部图标；空心实心等变体选中后再切；颜色与粗细紧跟工具出现，说明靠 tooltip 与快捷键。
