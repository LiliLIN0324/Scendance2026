# 编辑器信息架构 Phase 1（2026-10-16）

## 变更摘要

工作台顶层由并列「资料分类」改为三模式流程：

| 模式 | 中文 | 内容 |
|---|---|---|
| `layout` | 布置 | 画布 + 素材架 + 选中属性；活动需求嵌在布置首屏（无独立「策划」模式） |
| `review` | 评审 | 方案评审；浮层标题为「发给客户」 |
| `delivery` | 执行 | `SceneDeliveryPanel`（活动安排 / 物料 / 制作计划 / 点验 / 导出 / 本机备份） |

视觉壳：左侧约 48px **流程轨**（可展开），点模式后**向右浮出内容层**盖住画布边缘；素材架同样浮层。画布始终是视觉主体。Binggo / 云项目 / 「资料」「助手」头栏入口仍为停靠辅助，不与三模式同权。

## 降级（代码保留）

- 合同与约定 → 布置工具「更多…」
- 图纸重建、场地照片 → 活动需求内「更多」折叠
- `ActivityWorkflowGuide` → 一次性可关闭教练（`localStorage` key `scendance.workflowGuide.dismissed`），非常驻面板

## 氛围（布置画布工具条）

`ScendanceViewTools` 底栏胶囊内联「氛围」分组：**漫游｜人群｜天气▾｜时段**（默认全关）。

- 接现有 `walkthroughMode` / `showNpcs` / `weather` / `timeOfDay`（引擎 hooks **未删**）。
- **不**进入 `ViewOptionsMenu`，**不**作为第四模式，**不**打开左浮层白板。
- 文案与 `layout.backendLighting`（现称「现场灯光」）分开：工具条为「室外天气 / 室外时段」。
- 开人群时旁注「约 3 人」；开漫游时退出 2D。

深度氛围能力见氛围调研结论（2026-10-16）。

## Phase 1.5 修正（同日）

先前误把氛围做成左浮层 `AtmospherePanel`（与素材架抢白板）。已改为底栏胶囊内联控件，并移除左轨「氛围」入口与 `AtmospherePanel` 主路径。

## 项目入口

`/projects` 仍为工作室与项目源；编辑器 CloudPanel 文案改为「云项目快捷入口」，避免与主站项目管理抢权。

## UI 落地补强（同日）

- 素材架挂在左轨「布置」浮层内，不再使用底栏宽货架。
- 底栏胶囊：撤销 / 视角 / 吸附与缩放 / **内联氛围**（漫游｜人群｜天气▾｜时段）（及 Binggo 停靠）。
- 同屏只开一张浮层白板：属性 / 素材 / 活动资料；氛围不再占用左浮层。
- 布置编辑态默认浅色；`评审`（发给客户）与 `/view` 客户页使用深色预览壳。
