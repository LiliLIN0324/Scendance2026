## 结论口径

**本地构建通过到「范围确认」，但还不是正式站/云端 pass。**

- 空白项目：`boundary 0 / zones 0 / plan 167B`。
- 组合句：`在杭州湖滨银泰in77做200人发布会，户外广场30×20米，签到台放西侧入口，留出通道`
- 本地确定性入口保留完整地点 `杭州湖滨银泰in77`，没有再把「户外广场」拼进检索词。
- 真实 3199 高德代理返回 **5 条候选**；界面显示 3 条：
  1. 杭州湖滨银泰in77
  2. 杭州湖滨银泰in77 A区
  3. 杭州湖滨银泰in77 E区
- 选择第 1 条 → `就定这个场地` → 边界候选卡出现：
  - `12 个点`
  - `341.2 × 550.5 m`
  - `99936 ㎡`
  - 卡片同时有 `在地图上重画实际活动范围`（手画入口）和 `确认并应用这一版`
- 点 `确认并应用这一版` 后，本地 plan 为 `boundary 12 / zones 0 / facilities 0 / 766B`。
- 组合句随后由真实 `conversation-api` 解析成功，模型给出默认清单（桌子×1、垃圾桶×2、指示牌×2）并试排；真实范围包含水域/围栏禁区，摆放守卫拒绝写入：

  - 这是有依据的几何拦截，不是静默丢弃，也不是已写入。
