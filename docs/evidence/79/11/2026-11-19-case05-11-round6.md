## A. #5 离线（`docs/evidence/79/05/`）

**方法升级**：第五轮用页面级注入（覆写 `fetch`/`XHR`/`onLine`），本轮改用 Playwright `context.setOffline(true)` = CDP `Network.emulateNetworkConditions`，**连 `<img>` 瓦片也一起断**，并全程录 HAR。脚本 `docs/evidence/79/tools/case-05-offline.mjs`，读数 `2026-11-19-offline-readings.json`。

| 观察项 | 读数 | 判定 |
| --- | --- | --- |
| 离线窗口内的地点检索 | 输入「北京 朝阳公园」后**无候选**（第五轮曾出现"本地最近选过缓存冒充检索结果"，本轮未复现） | 通过 |
| 本机方案 | 分区 0、红线 12 不变，plan 体积 574 → **574**（零变化） | 通过 |
| 离线窗口内的云端写 | **0 条写请求** | 通过 |
| 恢复网络后 | 只剩 `GET /studios` 轮询与 `GET /studios/{id}/settings` 404，**无任何静默重放**（无 POST/PUT 方案写） | 通过 |
| 离线窗口内仍有 2 条 `GET /studios` 200 | 疑为 HTTP 缓存命中（该请求未带 `no-store`），**不是**服务端新应答 | 存疑，如实记 |

**没验到的**：本轮离线窗口内 Agent 回合的失败文案没有抓到（任务卡未被选中），「地图部分（瓦片）」那一格因候选检索直接无结果而没走到渲染层；云端 revision 前后对照依旧取不到（表不存在）。

**结论**：浏览器一栏 **partial**（比第五轮多了"瓦片也被断"与"恢复后无静默重放"两条），云端一栏 **unclaimed**。两个上一轮登记的缺陷——「离线检索无降级文案 / 本地缓存冒充检索结果」与「断网点确认后写入进行态不收口」——本轮**没有复现**（前者未复现是因为没有候选被渲染，后者没有待应用提案可点）。
