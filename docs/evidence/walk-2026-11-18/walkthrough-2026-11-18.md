# 户外漫游 W1/W2/W3 真机走查（2026-11-18）

这一轮把「户外第一人称漫游」的三件事第一次真机跑了一遍：**W1 玩家被场地物件挡住**、**W2 自己的身体与走动能起身**、**W3 岗位按 E 一句台词**（对应提交 `b1479215`）。

结论：**三项都拿到了原始读数，不是「应该能行」**。读数全部来自页面里已有的本机验收桥 `window.__scendancePlan3dDebug`（第一人称下相机位 == 玩家位），驱动方式是真实键盘事件（W/A/S/D/E），没有直接调内部函数绕过交互。

## 怎么跑的

| 项 | 值 |
| --- | --- |
| 客户端 | 本机 Chromium（Playwright 自带 chromium-1254），`--use-gl=angle --use-angle=swiftshader` |
| 服务 | `next dev -p 3220`（独立 worktree `.worktrees/w123-close`，避免与并行会话的 dev 抢 `.next`） |
| 场景 | 往本机 localStorage 注入一份户外草稿：矩形红线 30×20 m、锚点西湖平湖秋月，**不设 designScope**（这样漫游进场点是场地中心而不是场外镜头位） |
| 进场 | 右轨「第一人称漫游」→ 角色选择框「自由漫游」→ 指针锁被拒后退到「拖拽转头」兜底，WASD 照常走 |
| 复现 | `node probe-walkthrough.mjs all`（脚本即本目录的 `probe-walkthrough.mjs`） |

> 本机 CPU 满载 + 无头软渲染，帧率低（实测有效步速约 0.45 m/s，标称 1.8 m/s），所以采样间隔放宽到 0.7 s。**几何结论与帧率无关**：停住位置、落座眼高、台词文本都是绝对读数。

## W1 · 玩家被场地物件挡住 —— 通过

场景：场地中心正前方 3 m 放一顶 3×3 m 的帐篷（世界坐标 `(0, −3)`，占位 z ∈ [−4.5, −1.5]）。

| 步骤 | 读数 |
| --- | --- |
| 进场 | 玩家 `(0, 1.6, 0)`（场地中心），前进方向 `(0, −1)`（正北） |
| 按 W 前进 | `z = 0 → −0.27 → −0.63 → −0.90 → −1.2199`，随后**连续 5 次采样位移全为 0**（再压住 3 s 纹丝不动） |
| 停住位置 | `z = −1.2199`，离帐篷面 `1.5 − 1.2199 = 0.2801 m` |
| 对照：按 S 退 | `z = −1.2199 → −0.4999`（退了 0.72 m，说明没卡死） |
| 再按 W | 又停在**同一个** `z = −1.2199`（间隙仍是 0.2801 m，可复现） |
| 按 W+D 斜走 | `x = 0 → 1.3364`，`z` **一直是 −1.2199**（沿帐篷面横向滑走，没有穿过去也没有卡死） |
| 场地约束 | 停住与滑走后的 `|x| ≤ 15`、`|z| ≤ 10`，没有被推出红线 |

**判据**：`0.2801 m ≈ 玩家半径 0.28 m`（`PERSON_WALK_RADIUS_M`）。停住位置与「帐篷面 + 玩家半径」逐位对上，这是几何上的精确匹配，不是「看起来没穿过去」。

截图：`w1-0-start.png`（进场）、`w1-1-blocked.png`（贴面停住，帐篷占满下半屏，提示条「E 测试帐篷」）、`w1-2-slide.png`（沿面滑走）。

## W2 · 自己的身体与走动能起身 —— 通过

场景：场地中心正前方 1.8 m 放一张可坐设施（`oneplan:icon:evacuation-chair`，名「疏散椅」，世界坐标 `(0, −1.8)`）。

| 步骤 | 读数 |
| --- | --- |
| 进场 | 近邻条目已是座位：`kind=seat`、`label=坐下 · 疏散椅`，提示条「E 坐下 · 疏散椅」 |
| 短走 0.36 m | 玩家 `(0, 1.6, −0.36)`，离椅子 1.44 m，仍在近邻半径 2.2 m 内 |
| 按 E 落座 | 玩家瞬移到 `(0, **1.132**, **−1.68**)`：眼高 1.6 → **1.132**（降 0.468 m = 坐面 0.45 + 坐姿眼高 0.63 + 地面 0.052），横向落在椅子后 0.12 m（髋部后移，规格值） |
| 提示条 | 由「E 坐下 · 疏散椅」切到「E 起身 · 疏散椅」 |
| 按 W 起身 | 玩家回到站立眼高 **1.6**，位置 `(0, 1.6, −1.32)`：规格起身落点是 `−1.8 + 0.57 = −1.23`，差 0.09 m 是**起身那一帧只起身不前进、下一帧按键未松又往前走的那 0.09 m** |
| 提示条 | 回到「E 坐下 · 疏散椅」，落座态已清 |

截图：`w2-1-near.png`（走近）、`w2-2-seated.png`（落座，提示条已切「起身」，镜头降到坐姿眼高）、`w2-3-stood.png`（起身回站立眼高）。

| 步骤 | 读数 |

## 边界与没验到的

- **场景是注入的**：本机 localStorage 里的一块矩形场地，不是云端保存的真实活动；真实场地的物件尺寸、密度、互相重叠的摆放差异没有覆盖。
- **指针锁被拒**：无头浏览器里走的是「拖拽转头」兜底路径（HUD 会显示「拖动鼠标转头」）；真实指针锁下的转头手感、边角精度没有验证。
- **角色模型没到位**：HUD 显示「角色加载中…」，第三人称化身用的是几何人；选中角色的 GLB 在本机没加载成功，化身换模这条链路没有验到。
- **椅子模型是占位盒**：落座后镜头贴着椅面（截图里大片深红），真实椅子的 GLB 到位后观感可能不同；落座与起身的几何读数不受影响。
- **没有 sit 剪辑**：角色没有坐姿动作，落座时保持站姿（允许的退化）。
- **第三人称相机防穿**、云端保存、分享链接、移动端均不在本轮范围。
