# 户外漫游第二轮真机走查（2026-11-18 夜）

这一轮补的是上一轮列出的边界，对应提交 **`694398f6`**（相机防穿 / 化身加载兜底 / 无坐姿下沉对位）。
做法与第一轮一致：本机 Chromium + swiftshader，往 localStorage 注入户外草稿，进 3D → 进漫游，
**用真实键盘事件（W / E / F5）驱动**，读数取页面里的本机验收桥 `window.__scendancePlan3dDebug`。

复跑：`node docs/evidence/walk-2026-11-18-round2/probe-walk2.mjs all`（dev server 端口用 `WALK_BASE` 覆盖）。

## 一、相机不再钻进设施 —— 通过

场景：帐篷 3×3 m 放在玩家正后方 2 m（世界 `(0, +2)`，占位 z ∈ [0.5, 3.5]），第三人称后拉 4 m。

| 项 | 读数 |
| --- | --- |
| 视角切换 | F5 后提示条变「第三人称 · F5」 |
| 相机 z | **0.2303** |
| 判据 | 帐篷近面 0.5 − 相机半径 0.25 − 表面余量 0.02 = **0.23** |
| 是否在帐篷内 | **false** |

后拉 4 m 的机位本应在 z = +4（帐篷内部 z ∈ [0.5, 3.5]），实测停在 0.2303，说明机位被按射线
求交缩到了帐篷面外；朝向不变，所以画面只是“贴到人身后”，不会甩到后脑勺。
截图：`cam-1-third.png`、`cam-2-walked.png`。

## 二、化身加载不再无限转圈 —— 通过（软超时那段）

第三人称下每 2 s 采一次漫游 HUD（`wait` 场景）：

| 采样 | HUD |
| --- | --- |
| t = 0/2/4 s | 角色加载中… |
| **t = 6 s 起** | **角色模型较大，先用几何人代替；下载完会自动换上。 + 「重试」按钮** |
| t = 8…36 s | 同上（本机 3.7 MB 角色模型在软渲染下始终没加载完） |

软超时按设计生效：界面不再用一句“加载中”把人挂死，同时给重试入口。
**没验到的**：加载真正晚到后自动换真模型的路径——本机整个观测窗口（36 s）内模型都没就绪，
所以“自动换上”目前只有代码保证，没有画面证据。
截图：`wait-1-early.png`、`wait-2-timeout.png`、`wait-3-late.png`。

椅子用物料库真模型（`office-lobby-and-facilities-canteen-stacking-chair-3440c7d8`，可叠放座椅），
不再用图标占位盒。

| 步骤 | 读数 |

| 进场 | 近邻条目 `kind=seat`，提示「E坐下 · 可叠放座椅」 |

## 本轮仍然没验到的

- **真实云端活动**：用的是仓库里打包的经典案例规划，不是登录后从云端拉取的用户活动。
- **指针锁**：无头 Chromium 拿不到指针锁，仍走「拖拽转头」兜底；真实指针锁手感未验。
- **角色 GLB 到位后的第三人称观感**：本机软渲染下 3.7 MB 模型始终没加载完（见上）。
- **相机俯仰穿楼板**：这一版只做水平后拉射线的 2D 盒求交，抬头视角的遮挡不在范围内。
