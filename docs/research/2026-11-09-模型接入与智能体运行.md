# 模型接入与智能体运行：实施参考

## 已核实的接入方式

- [阿里云百炼 OpenAI 兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)支持通过服务端配置地域、接口地址、模型名称和 API Key 调用。北京地区现有 DashScope 域名仍可用；官方也提供业务空间专属域名，密钥、模型权限与地域需要匹配。
- [百炼工具调用](https://help.aliyun.com/zh/model-studio/qwen-function-calling)要求应用接收模型提出的工具调用、执行工具并把结果关联原调用返回。流式场景中参数可能分片，需先拼接并校验完整参数，再执行；不把模型声称当作工具回执。
- [Dify Agent 节点](https://docs.dify.ai/en/cloud/use-dify/nodes/agent)和 [LangGraph 的 Agent 建模](https://docs.langchain.com/oss/javascript/langgraph/thinking-in-langgraph)均把模型决策、工具执行和状态处理分开。幕景可沿用单 Agent，不需要为每个工具另建 Agent。

## 幕景当前边界

仓库已有 `bailian-qwen` 服务端适配，并在隔离本机环境用百炼真实模型进行过单次虚构需求测试。该结果不证明正式站已接入，也不证明任意活动或工具链可靠。正式使用需要目标后台、服务端密钥、地区与模型权限、前端配置以及相应服务和保护机制共同就绪；API Key 不应放入浏览器或 `NEXT_PUBLIC_*` 配置。

界面应区分项目是否连接、本次是否调用模型、调用失败或超时，以及工具是否实际执行。模型响应超时或结果未知时，不应自动重发可能计费或有副作用的请求。预览、用户确认、实际应用、回读与独立检查仍是各自的步骤；真实场地、库存和规范结论需要独立核验。

本记录仅总结官方文档及本仓边界，不包含生产项目凭据，也不代表生产配置或部署已完成。
