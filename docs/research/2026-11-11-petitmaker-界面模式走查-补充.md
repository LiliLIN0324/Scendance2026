对象：petitmaker.com.cn，同一会话续跑（任务「在友邻中心南侧沙滩边种2棵椰子树」从暂停→批准→拒绝→停止全程跟了一遍）。
目的：补上次 `2026-11-11-petitmaker-agent-run-学习.md` 没记、但能直接提升操作舒适度的前端细节。
边界：只观察，没碰「清除密钥/清除历史」，没付费，没改我们仓库任何代码（除本文档）。监督档中途误切过一次「自动」，已当场切回「严格」还原。

## 一、本轮已采用（我们这次直接落地的四项）

- **建议卡带缩略图 + 落点圈 + 预填**：照抄「建议不是文字，是可一键执行的半成品」——候选卡配场地小图 + 落点虚线圈 + 点一下就把指令预填进输入框。
- **停止确认弹层**：照抄「要停止这项工作吗？取消 / 停止」双钮弹层，避免运行中误触停止。
- **完成态人话边界 + 续问预填**：照抄「主动交代实现妥协 + 要不要继续 + 续接指令预填进输入框」。
- **过往任务归档折叠区**：照抄「完成/停止的任务收进『过往任务 N ⌄』，当前任务永远占主区」。

## 二、建议新增（本轮新走查到的模式）

### A. 可立刻落地（纯前端渲染/文案/状态色，不动运行时协议）

1. **状态头颜色编码 + 猫头表情随状态换**【agent-panel.tsx 头部】
   上次只记了「五态文案」，这次看清了它是一套**颜色 + 图标 + 猫头**三件套：等你确认=黄色头 + 「?」+ 猫头像旁冒对话泡；正在思考=浅米头 + 「▶」+ 猫戴灯泡💡；已停止=灰棕头 + 「■」方块；中途停下=灰头 + 「‖」。一眼区分「等我做决定」和「它在干活」。改动量：给现有 phase 枚举加 `tone` 字段 + 换 4 个猫/状态图标，约半天。（截图 11、12、17）

2. **等你确认：黄左边框待批卡 + 批准/不用双选 + 决策后变状态徽章**【agent-run-panel.tsx 提案卡区】
   严格模式每步改动弹一张卡：黄左边框高亮 + 地图缩略图 + 「批准」深主钮 / 「不用」浅次钮；点完钮不消失，原地换成「✓ 已批准」绿徽章或「× 你拒绝了」粉徽章。底下再放一行低强调「取消任务」。我们现在的候选卡只有批准语义，没有「不用/拒绝」和决策后留痕。改动量：提案卡组件加 rejected 分支 + 徽章态，约半天。（截图 11、12、15）

3. **工具流水每步右侧结果标记 + 完成数量胶囊**【agent-run-panel.tsx 流水行】
   上次记了「人话名 + 勾」，这次看清细节：进行中=转圈，成功=绿✓，被拒=红×；成功的放置类步骤还在标题后追加「1 个物品」数量胶囊。一眼看到哪步成了、哪步被我否了。改动量：流水行加 `status` 圆点/勾 + 可选 quantity 胶囊，约 2 小时。（截图 12）

4. **「N 条已答复的询问」聚合回折条**【agent-run-panel.tsx 流水底部】
   一串批准/拒绝不占地方——收成一行「3 条已答复的询问　✓ 已批准 ⌄」，聚合结果徽章随最后一次决策变（全批准=绿，有拒绝=粉），点开才展开明细。我们现在逐条决策会把流水撑长。改动量：流水底部加一个 collapsible 聚合条，约半天。（截图 13、15）

5. **输入框 placeholder 随状态换五套文案**【agent-panel.tsx 输入条】
   待机「输入任务或问题」/ 运行中「为下一步添加备注」/ 待确认「或用文字回答」/ 暂停「补充说明后继续」/ 圈选模式「请在地图上圈选范围」。我们现在输入框常年一个 placeholder。改动量：一个 switch 映射，半小时。（截图 11、12、17、18）

6. **运行中输入条旁的红色停止方块 on 粉底圆**【agent-panel.tsx 输入条】
   发送键左边多一个粉底圆 + 红方块的紧急停止钮，和深色发送键形成强对比；停完自动消失。我们停止钮埋在头部，运行时不够显眼。改动量：输入条右侧加一个仅 running 态出现的按钮，约 2 小时。（截图 11、12）

7. **已停止态的三句人话收尾**【agent-run-panel.tsx 终态卡】
   「改动已保留」副标 + 「地图上保留了 N 处改动。」+「停止时还有一个问题没有回答。」+「撤回会一次性还原整个作业，Ctrl+Z 则是逐步还原。」——把改动数、遗留问题、两档撤销语义全说在人话里，不用用户猜。我们的 blocked/stopped 文案偏技术。改动量：stopped 卡文案重写 + 保留改动数，约 2 小时。（截图 17、21）

8. **设置面板头部实时摘要 + 监督分段控件每档配一句人话**【agent-panel.tsx 设置弹层】
   设置头副标实时显示当前配置「MiniMax M3.1 Flash、严格」，切档即时跟着变；监督三档不是干标签，下面各跟一句说明（严格=「每次改动前都先问你。」/ 关键节点=「在计划步骤和大范围改动前询问。」/ 自动=「自动执行，无需逐步确认。所有修改均可撤销。」）。我们有档位胶囊但没有这句解释。改动量：设置弹层加副标 + 分段控件下随档换文案，约半天。（截图 08、09、10）

9. **危险操作视觉降级**【agent-panel.tsx 设置弹层底部】
   「清除密钥」「清除历史任务（N）」做成底部一排浅色小胶囊，带钥匙/时钟小图标，和大深色「完成」主钮完全拉开层级。我们的危险按钮容易和普通按钮同级。改动量：底部加一行浅色 danger 组，1 小时。（截图 08）

10. **确认弹层默认 focus 在「取消」**【agent-panel.tsx 弹层】
    停止确认弹层打开时焦点落在「取消」（安全项），按回车不会误停。我们的弹层没做焦点管理。改动量：弹层给「取消」加 autoFocus，一行。（截图 16）

11. **hover 出白色圆角 tooltip**【agent-panel.tsx / 地图工具栏】
    右侧圆形工具栏 hover 出白色圆角小气泡（「切换视图 2D」），图标钮不靠猜。我们图标按钮没 tooltip。改动量：给图标钮套一个 title/Tooltip 组件，约半天。（截图 20）

12. **快捷键直接写在按钮标签里**【agent-panel.tsx】
    「区域负荷：F7」这种钮直接把 F7 印在文字后面，不用翻帮助。我们的快捷键只存在于文档。改动量：按钮 label 拼上快捷键字符串，1 小时。

13. **状态头计时器一直走**【agent-panel.tsx 头部】
    mm:ss 在头部右侧实时累加，用户感知到任务跑了多久。上次建议过，这次确认它是每态都显示、不是只有运行态。改动量：头部加一个 useEffect 计时器，约 2 小时。（截图 11、12、17）

### B. 需要大改（涉及运行时控制/模式切换，先记下来排期）

14. **「在本步结束后暂停」预约暂停钮**【agent-run-panel.tsx 头部】
    运行中头部有个按钮，点了不是立刻停，而是**等当前这一步干完再停**——既不打断正在写的步骤，又能在下个确认点接管。我们只有「立即停」一档，容易把正在执行的步骤截断。需要运行时支持「步末暂停」标志位，约 1–2 天。（截图 12）

15. **限定工作范围：整面板切成「在地图上画」模式**【agent-panel.tsx 模式切换】
    点 crosshair 钮后，面板头变「正在圈选范围 / 请在地图上绘制」，输入框 placeholder 变指令，发送键 disabled，底部弹出画笔/形状/长宽工具条；画完才能发。这是一套独立的「画范围→作为任务约束」模式，不是简单按钮。需要画布选区交互 + 任务约束数据结构，约 2–3 天。（截图 18）

16. **停靠面板按钮（浮动 ↔ 侧边栏）**【agent-panel.tsx 外层】
    面板外侧有个 dock 图标，能把浮动气泡面板停靠成右侧常驻栏。我们面板定位方式要重构，约 1 天。（截图 17 右上角那个小图标）

## 三、走查备注

- 拒绝路径很轻：点「不用」后该步立即在流水里标「你拒绝了」，不弹窗问原因，agent 自己想下一步——我们别给拒绝加摩擦。
- 「共 N 步，显示最后 3 步」这个滚动窗口在本次从 7 步涨到 11 步时表现正常，旧步骤自动折进折叠区，面板高度不涨。
- 已停止后地图上那 1 处改动是**保留**的（不是回滚），回滚要主动点「还原到开始」或 Ctrl+Z——这是个有意识的默认值，我们别做成停止即回滚。
