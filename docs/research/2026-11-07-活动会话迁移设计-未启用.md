# 活动会话从本地迁至云项目：待验证设计（未启用）

本文件描述待设计能力，不是已部署的迁移功能。现阶段会话保留在原活动作用域，可从历史入口只读查看；切换 ID 不会自动把旧需求写入目标项目。首次连接云项目后需要用户核对当前需求并重新发送。

## 现有边界与不能逐键复制的原因

会话索引、对话正文和结构化需求分别存于本机 localStorage 的三个键；活动作用域编码进各自键名。`use-assistant-sessions.ts` 的 `persistIndex` 依次写索引、裁剪需求、写正文，既不是跨键原子事务，也没有覆盖多标签的原子“目标仍为空”比较。中途失败或页面终止可能只写入其中一部分；独立的回滚又可能覆盖另一标签新写入的数据。当前不能用逐键复制、最后覆盖或无条件补偿实现安全迁移。

现有 `restore-journal.ts` / `local-write-lease.ts` 提供恢复日志、阶段、带 SHA-256 的记录和受限恢复能力，但其 `indexedDbRestoreJournalStore.create` 明确拒绝创建日志，恢复能力的存储授权针对既有 layout、form 与 source 操作，并没有本地会话三键的受限原子迁移域。现有恢复功能仍受暂停边界约束。不能把有日志数据结构等同于可复用生产事务，也不能绕过该限制复用恢复入口。

## 可信绑定记录

用户选择迁移之前，必须由当前实际的绑定操作生成不可伪造、可核验的本地待确认记录，而不是以两个 ID 出现的时间接近推断同一活动。设计记录至少包含：

- 操作唯一 ID、格式版本、源活动作用域与目标云项目 ID；源作用域的用户可辨别名称仅作显示。
- 发起该绑定的本机活动代次、编辑权/租约标识、用户身份与项目访问上下文；记录不包含令牌、密钥或图纸原文。
- 绑定前源布局的确定性 SHA-256、服务端实际创建或绑定返回的目标项目标识、对应的场景基线哈希和版本，以及被复制的来源状态摘要。需验证后端返回的项目确系该次请求结果，且当前账号有访问权。
- 源会话索引、正文和需求的完整快照版本及摘要；预览展示会话标题、条数、需求与待确认项，并说明不会删除源。
- 目标快照及版本。目标为空必须通过受保护事务读取判断；允许系统种下的空会话壳，但任何非空正文、需求、待核验事实或其他用户数据均视为非空，拒绝覆盖。
- 确认人的本地明确操作、确认时间与绑定/预览摘要。记录来源与目标、代次和摘要，确认只能用于这份预览，不给将来的修改授权。

ID 来自云端响应并不单独证明当前布局、来源资料、账号或会话仍未变化；绑定完成前后均须重读并核对。源未发送草稿属于易失内存，除非用户在预览中明确纳入并有安全持久化路径，不应暗中复制或宣称已迁移。

## 后续事务方案与恢复

优先把新版本的索引、正文、需求和迁移日志收敛到同一 IndexedDB 数据库，并在单个事务中执行目标为空的比较及完整写入。若仍需写多个不同存储，必须先将所有普通读写入口接入统一的跨标签写锁和可验证能力，持久化受限日志并实现幂等恢复；不能依靠当前仅覆盖部分入口的检查。恢复日志/标记的创建、使用、清理及权限均须先有单独设计和集成验证，现有受限恢复原语不可直接扩大权限。

顺序：

1. 真实绑定完成后记录源、目标、用户、当前代次与两端基线证据；不迁移。
2. 用户打开只读预览，明确选择要迁移的会话和需求；列出目标非空、未知来源及未保存草稿。
3. 用户确认该预览后，获取统一跨标签写锁与当前编辑权；重新检查两端作用域、代次、身份、绑定证明、源版本、目标确为空及来源摘要。任一变化终止，保留两端。
4. 写入绑定内容、源/目标前后快照、摘要和预备阶段的持久日志；再次验证持锁后在单事务内比较目标、写入完整会话并记录完成。若无法同事务提交，必须使用受限幂等阶段和持久日志，且恢复只可执行日志授权的精确前后值。
5. 提交后读回目标内容和摘要，再显示迁移完成；源保留。释放锁。若结果不确定，显示“待核对”，禁止重试覆盖或宣称成功。
6. 页面异常退出后，通过单独核验的恢复入口检查日志、摘要、身份和实际数据；只在当前值仍符合日志前后快照时恢复，发现其他标签新写入则停下并保留证据，不强制回滚。

## 必须通过的验证

- 新项目空目标、不同活动非空目标、只有系统空会话壳、旧全局未关联记录、源不存在或源损坏；只有空目标可确认，旧记录不自动成为事实。
- 同批 A→B→A、绑定期间改名/改尺寸/追加会话或来源、账号切换、编辑权撤销、授权确认与提交之间目标被其他标签写入：旧令牌不能提交，也不能覆盖新数据。
- 每一写入边界注入失败、关闭/重载、事务中止、磁盘满、权限被撤销、摘要不一致、重复点击和幂等重试；逐项验证源完整、目标完整或明确待恢复，不能产生伪成功。
- 进程/标签并发和锁不可用，无法验证绑定证据、资料仍在保存、图纸内容发生变化时 fail closed；检查真实 IndexedDB 事务和浏览器 Web Locks，而不只依赖内存模拟。
- 恢复前后再次比较当前值与日志；错误日志、过期日志或其他标签已产生新写入时不得覆盖。记录使用真实浏览器及支持矩阵，报告样本和未覆盖边界。

在统一锁、可验证绑定与事务/恢复证明完成以前，本功能保持关闭，仅提供旧会话只读查看；不得声称跨项目迁移已完成。
