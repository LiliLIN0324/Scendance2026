# 智能建造纵向链路：实现与验收记录

状态：**进行中，尚不能称为真实活动交付完成。** 本文只记录能核对的范围，不把模拟模型响应、公开参考图或本地测试当成真实现场验收。

## 外部对照

- [Cvent Event Diagramming](https://www.cvent.com/en/supplier-venue/event-diagramming-software)：比例图、座席和多方协作是交付工作流的一部分；功能为厂商陈述，不等于本项目已具备同等能力。
- [Cvent AI Seating Assistant](https://release.cvent.com/eventmanagement/announcements/join-upcoming-beta-programs-1)：对话给出座席条件、生成后仍可人工审阅修改。本项目以确认前可审阅、候选差异可见为参考，不声称产品能力相同。
- [FlairGPT](https://flairgpt.github.io/) 与[补充材料](https://flairgpt.github.io/supplemental.pdf)：结构化需求、约束映射与求解分层；错误可发生在提取、清洗及映射阶段。论文不是活动安全验证。
- [Hall D5 官方布局](https://www.t-i-forum.co.jp/en/facilities/d5/layout/)：公开场地参考资料，仅作模拟任务和尺寸对照。仓库中的 19×15 米边界是估测，不等于经现场确认的轮廓；官方参考人数不是消防核定容量。

## 已接入并有自动测试的链路

1. 模型接口可返回带原文证据的签到、休息、舞台和人人入座需求。服务端检查证据是否来自当句；前端将模型解释展示给用户确认，无法核实的解释不会直接生效。原文匹配只证明引用存在，不证明解释正确。
2. 已确认或待确认的需求按聊天保存在本机；切换聊天隔离，刷新后可恢复。模型响应按发送次序合并。存储失败有提示，旧版本数据按默认未知迁移。
3. 云端重排收到当前原话和已记录需求；本地候选与云端候选都在确认前检查明确要求的座位数。座位数仅按可识别单人椅计，不是消防容量或可达性结论。
4. 本地候选的场地变化、物件变化和休息区先预览；实际应用不能静默删除校验不通过的物件，也不能在确认之后悄悄重排候选。休息区为待核验示意，不假定现场门位。
5. 门洞、局部间距和网格路径缺少证据时标为待核验；不将虚构的场地中线、边缘采样或缺少开启方向的门弧当作安全通过。交付 JSON 与清单标注检查范围和未知项。
6. 云端应用前对同一份候选做本地预检；请求结果不明确时保留核对记录、阻止重复提交。云端和本地确认应分别核对，不能靠一条按钮回执代替。

## 2026-11-07 产品走查补充

- 参考 [Autodesk AI 透明度说明](https://www.autodesk.com/trust/trusted-ai/ai-transparency-cards)：自动识别的区域可由用户审阅、修改，再确认保存；本项目采用先选择用途、画区域、核对候选的流程。厂商描述不代表现场验证。
- “标注”入口改为“规划区域”，在平面图中显示画区域、画路线、量距离的操作说明；本地浏览器确认引导可见。画线和量距不等于实际通行安全评估。
- 空白空间入口在已有物料或场地资料时拒绝直接覆盖；真实场地切换先检查候选，未知尺寸不沿用旧值；撤销和重做保留场地及其物料关联。
- 本地多标签检测到外部存档变化时暂停自动保存并要求核对，包含事件尚未送达时的写前比对。localStorage 不支持原子比较并写入，极端同时写入仍有竞态；当前尚未建立覆盖所有写入入口的统一锁。跨 IndexedDB 与本地存储的恢复流程仍有崩溃中断窗口。
- 自定义模型配置不完整时拒绝静默回退，错误说明不透传上游异常；尚未完成真实服务调用、费用上限或全部智能体接口的供应商兼容。前端超时不代表上游调用已停止。
- 对话修改不再把背景板当舞台，同类目标不唯一时要求用户指定。签到和休息区不再按固定坐标猜测距离入口远近；位置关系保持待核验。
- 图纸导出无法准确表达的多边形、V2 结构等场地时会拒绝；未定位物件在打印图和本地清单中列明，DXF 暂不允许含未定位物件。
- 交付 HTML 对可能含凭据的链接和文字做保守脱敏；无法保证识别任意没有标记的秘密，导出前仍需审阅。
