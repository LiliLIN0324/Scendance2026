# PetitMaker 智能体首跑实测：卡片与交互模式清单（2026-11-11）

对象：petitmaker.com.cn（用户接入 MiniMax M3.1 Flash 自定义端点后首次真跑）
方式：内置浏览器实机操作，接受主动建议（铺路任务）→ 观察运行态/完成态 → 不可能任务 → 中断 → 设置面板。全程截图存 artifacts。
本文只记「前端可抄的模式」，协议层见 `petitmaker-agent-teardown-2026-11-05.md`。

---

## 一、卡片模式清单（按生命周期）

### 1. 待机：主动建议卡
- 面板头：猫头像 + Beta 徽章 + 状态（「准备好了 / 正在思考 / 正在施工 / 全部完成 / 已停止」五态，随阶段变色变图标）+ 计时器 + ⏸暂停 + ⚙监督设置
- **建议 = 缩略图 + 落点圈 + 预填指令**：「北侧的平整空地适合挖一个 18 格宽的池塘」配地图快照、虚线圆圈标落点；同时把执行指令预填进输入框（「从友邻中心向北侧铺一条小路」）——建议不是文字，是可一键执行的半成品
- 免责常驻输入框正下方：「我会出错，也可能破坏你的设计。」

### 2. 运行态
- 任务卡：任务名 + **斜纹进度条** + 「目前的思考」标签
- 工具流水：每工具一行 = 图标 + **人话名**（「查看区域」「列出物品」「查看地图」——不是 tool_name）+ 完成勾/进行中圈；**「共 7 步，显示最后 3 步」滚动窗口**防卡片无限长；思考时长可折叠（「思考了 0:19 ⌄」）
- 「N 条思考」在面板头可展开
- 状态头随阶段变：「正在思考」→「**正在施工**」（进入改动阶段时）
- **运行中可插话**：输入框 placeholder 变「为下一步添加备注」，发送键旁多停止键
- **真实画布同步可视化**：铺路路径以橙色虚线实时画在地图上（智能体干到哪，画布看到哪）

### 3. 完成态
- 状态头「全部完成」+ 副标「有个问题想问你」（诚实区分干净完成 vs 带疑问完成）
- 结果叙述带**精确坐标与数量**：「起点 x=88, y=62，紧贴中心线……延伸到 (81,34)，共 29 格」
- **主动交代边界**：「中心本体是永久结构，其正北那一格无法铺路，所以路径从紧邻中心的位置起算，看上去仍是连着中心的」——把实现妥协说在人话里
- **追问续接**：「要不要把这段路继续向北铺到草地边缘？」+ 输入框预填续接指令
- 按钮：「建造过程」（回看流水）+「归档」（收进过往任务）

### 4. 中断态
- 停止需确认弹层：「要停止这项工作吗？ 取消/停止」
- 中断卡：灰头「已停止」+「已按你的要求停止」徽章 + 任务名 + 归档按钮
- 遗留：中断后地图上的预览虚线未清理（小瑕疵）

### 5. 归档
- 完成的任务收进「过往任务 N ⌄」折叠区，面板始终以当前任务为主

### 6. 回退语义
- 完成态给「返回」「还原到开始」两档（单步回退 vs 整轮还原）

### 7. 连接设置（⚙ 入口）
- 供应商下拉（自定义/官方预设）+ 端点 + **模型下拉带「刷新」**（从端点拉可用模型列表）
- **监督三档**：「严格 / 关键节点 / 自动」+ 说明「在计划步骤和大范围改动前询问」
- 清除密钥 / 清除历史任务（带计数）

## 二、幕景落地建议（agent-panel 候选卡升级方向）

| PetitMaker 模式 | 幕景现状 | 落地点 |
|---|---|---|
| 状态头五态+计时+暂停 | phase 文案+进度条（已有，无暂停/计时） | agent-run-panel 加 ⏸/计时 |
| 工具流水（人话名+勾+滚动窗口） | 「执行过程」有步骤断言但展示弱 | 把 tool 调用渲染成人话行+勾，超 5 步折叠 |
| 建议卡带落点图 | 建议 chip 纯文字 | 45座/场地建议配 2D 缩略图+落点标注 |
| 完成卡边界说明 | blocked 文案偏技术 | 「从紧邻位置起算」式人话边界进候选卡 |
| 建造过程回看 | 执行完即消失 | 过程卡保留可展开，任务归档折叠区 |
| 监督三档 | 有监督档位文字胶囊（26px 格） | 对齐「在计划步骤和大范围改动前询问」的触发语义 |
| 运行中插话 | 生成中输入框禁用语义（「停一下」除外） | 评估「为下一步添加备注」的排队备注 |

**优先级建议**：工具流水人话化+完成勾（成本最低、体感最强）→ 状态头五态 → 建议卡落点图 → 过程回看/归档。
