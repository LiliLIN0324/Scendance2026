## 落地优先级

1. 一条用户消息：普通回答、需求理解和工具动作共用同一聊天生命周期；流式文本不能边输出边直接改场景。
2. 工具先包装现有的候选生成、差异、检查和清单。活动/会话/楼层/场景版本不匹配则拒绝旧确认。
3. 模型等待与取消明确可见；取消只停止本地等待，不承诺供应商停止计费，结果未知时不自动重发。
4. 多进程防重、持久恢复和成本上限必须在实际服务层实现并测试；这些开源案例不能替代幕景自己的现场和安全验收。

对真实活动平面可研究 [Convention Planner](https://conventionplanner.org/) 的座位自动计数、视线、标注和交接体验。其官网说明软件采用 GPL，官网所列 GitHub 链接本次返回 404，尚未核实仓库、具体版本及完整许可；不复制或引入代码。

## 可选择而非单一路径：成熟产品对照

- [Canva Magic Media](https://www.canva.com/en_gb/help/using-magic-media/) 在素材中提供搜索和生成入口；用户可以对生成结果再生成变体，3D 功能和额度受具体产品条件限制。对幕景：从库中查找、上传模型或发起生成应作为并列方向，而不是模型擅自替用户选。
- [SketchUp 3D Warehouse](https://help.sketchup.com/en/3d-warehouse/searching-and-downloading-models) 提供文字/参考图搜索、分类与文件复杂度筛选。对幕景：多款模型应展示可核对的来源和标称尺寸；目录项不证明现场实物库存。
- [Autodesk Forma Building Layout Explorer](https://adsknews.autodesk.com/en/news/building-layout-explorer-in-autodesk-forma/) 官方将其描述为特定地区商业用户可用的实验性功能，目标是早期生成并评估多个方案。对幕景：方案差异和取舍应可比较；该建筑概念设计功能不是活动场地安全能力证明。
- [Cvent Equipment List](https://support.cvent.com/s/communityarticle/Exporting-the-Equipment-List-in-Event-Diagramming) 汇总图中物件的尺寸和数量并可导出。对幕景：区分图中需要的数量、用户口述现有数量、现场点验和供应商可用性。

幕景现有 Aholo Lux3D 有文字/图片生成入口、费用确认与本地 GLB 导入；当前账户可用性和真实生成未验证。生成所得是模型，不自动代表可购买或可用的实体物料。用户可授权使用积分，但一次请求结果未知时不能自动跨通道重发造成重复扣费。
