分片 A · 活动

负责角色：活动 —— 左轨四形中唯一真对话与生成入口；开场画廊、AI 主对话工作台、进度表达、成员条沉底。

12 张卡 · 12 个产品/模式

  • 开场画廊＝卡片冷启动入口：以本机活动面板为底座升级（S1.1），卡面＝画布快照封面＋活动名＋状态短词，选卡直接进生成，不弹配置向导。
  • 空态从「分派话术」换成「动作建议短清单＋活动卡行」：拆除旧空态与假分派整块。
  • 对话与画布同屏共生：对话是细化通道、3D 画布是结果本体；选中即上下文、每任务一会话；生成三道门接线不动。
  • 进度按状态分线流转（进行中/已完成），不学分步向导；台账暂无进度 UI 锚点，列开放设计项，不进 S1 回归面。
  • 成员条沉底＝真人在线状态小点：现有消息底座复用，在线状态点为新增小项；严守真人与 agent 的边界，成员条不挂 agent。

分片 B · 审校 Bingo

负责角色：审校 Bingo —— 画面钉点 → 意见线程 → 标记解决 → 回流制作者台账；不承担布置生成对话。

7 张卡 · 7 个产品/模式

  • 钉点状态机不新增第三态：open / resolved 足够；补「解决即隐藏＋未读排序＋只看我的线程＋点击跳回画布」四件事。
  • 客户分享页做无编辑只读页：view / comment 两档起步，默认禁下载，本地演示边界在页面诚实标注。
  • 新增 internal / public 评论分层：制作者侧内部备注对客户不可见；本地先落地、云端后置。
  • 一键修复长成「待确认建议」：体检 issue → 预览 → 唯一确认，全程过三道门，客户侧不见修复按钮。
  • Bingo 脸做纯状态台＋「准备客户评审 / 导出评审包」两口令，不保留自由对话输入条（Q3 待 owner 拍板）。

分片 C · 空间 / 物料

负责角色：空间（场与壳的工具面板）＋ 物料（道具库与生成工具面板）—— 两者不是人格，不维持对称式聊天窗。

20 张卡 · 8 个产品（同产品多卡已在下表合并）

  • 空间脸改「环境行列表」范式（一行＝一个场地；active / 显隐 / 可隔离 / 双击改名），承接现有环境槽与建场面板，只收入口不重写管线。
  • 物料脸按统一资产库解剖重构：搜索框＋类型子标签＋网格卡＋右侧「来源/时间/版本」详情列。
  • 生成收为面板内「＋ 一框」：一个生成框＋输入类型芯片，内部模式名不上界面；生成结果落回库网格。
  • 拖入落点规则显式化：道具拖到选中物附近＝关联摆放；拖到空画布＝新放一件；材质拖到已放物料上＝换材质。
  • 面板去人格化：单位是「行」和「卡」不是「话」；选中驱动整换；状态只给短词；空态一句诚实话；默认落点是库/列表，不是 AI。

Q1 · 活动显示名与毛绒头像

台账原文：活动脸显示名确定就叫「活动」？door 形态的毛绒头像是否保留。
