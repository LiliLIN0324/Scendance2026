分片 A · 活动 — AI 主对话工作台 / 开场画廊 · 灵感板

左轨四角色重划后，「活动」是唯一真对话与生成入口：开场活动画廊、AI-native 主对话工作台、非线性填格进度、真人成员条沉底。竞品事实均于 2026-11-04 联网核实（官方 URL 见各卡链接），代码落点只引用导演台账已核实锚点。

日期 2026-11-04 · 幕景 Scendance IA 重划调研 · 冷石 #F4F5F7 + 品牌绿 #4A7C59

处置态
主题

tuijian 推鉴

直接复用

「不写一个字，点三张卡，拿到能直接发出的成品」——卡片点选代替空白输入框的冷启动老板模式。

交互骨架
  • 产品卡 / 客户卡 / 平台卡全程点选，零表单
  • AI 追问一次一题、全是可点选项，最多 7 轮，收成要求摘要再生成
  • 输出=结构化结果页；核验回查为只读后置环节
偷什么
  • 选卡→追问摘要→一次生成→结构化交付
避什么
  • 营销数字（组合数）不上界面；7 轮问卷对活动筹备过重，chips 先行

落点：S1 空态 agent-panel.tsx:1944 拆除后换活动卡行；生成 chrome PlanHome:1947 挂活动脸；引擎 LayoutAgentProvider:264 红线不动

Notion Templates

需改造

选一张模板卡 → 选工作区 → 一个 Duplicate 按钮，模板立刻变成「我的文档」。

交互骨架
  • 模板卡带缩略图 + 一句话用途
  • 唯一动作按钮，无中间配置表单
  • 复制后是你的可编辑副本，不再绑定「模板」概念
偷什么
  • 点活动卡=一键进活动工作台，不弹 wizard
避什么
  • 上万张的模板市场与类目墙不上开场

落点：S1.1 开场画廊 local-activities-panel.tsx（台账：本机活动列表面板升级为画廊入口）

Airtable Gallery View

需改造

每条记录=一张卡：顶部封面图 + 下方少量关键字段；同一份数据可换 Grid/Kanban/Timeline 多视图。

交互骨架
  • Cover Field 指定封面；卡面只放标题 + 2~3 个字段
  • 视图切换不动底层数据；筛选按钮带可见计数
偷什么
  • 「一份数据多视图」= 布置/物料/执行资料是同一方案的三张视图
避什么
  • 「自定义卡字段」配置器不上开场画廊

落点：S1.1 卡面解剖=封面（现有画布快照机制）+ 活动名 + 状态短词

Figma File Browser

需改造

Recents=最近看过的文件网格；Drafts=只有自己能看的草稿箱；星标置顶；删除有垃圾箱。

交互骨架
  • 缩略图网格陈列，跨文件/看板同库
  • Drafts 未归档不进正式列表，可随时移出
偷什么
  • 草稿/归档分区：没做完的活动不混进正式画廊
避什么
  • team/projects 两层文件夹导航对单机本地库过重

落点：S1.1 画廊分区=最近网格 + 草稿/已归档（现有归档恢复能力为底座）

Miro Dashboard

直接复用

Recent 区 + Starred 视图 + 搜索/排序/过滤，每张卡的操作全收进「…」溢出菜单。

交互骨架
  • 排序 created / last opened / last modified；grid/list 切换
  • 卡「…」=分享/重命名/移动/复制/删除/换缩略图
偷什么
  • 卡面不堆按钮；默认按「最近打开」排序=接着上次干
避什么
  • Spaces/Projects 两层组织、团队切换、模板市场都不上

落点：S1.1 工具栏=搜索框 + 最近打开排序；网格/列表切换可选后置

Framer AI

直接复用

agent 对你的真实项目直接动手：生成就是主画布上的可编辑图层，对话是 refine 通道。

交互骨架
  • 生成≠第二预览窗：结果长在主画布，可微调/撤销/手改
  • 画布选中即 chat 上下文；@ 引用页面/素材
  • 每任务开一个新会话，保持 agent 专注
偷什么
  • 对话与 3D 画布同屏共生；选中区域再说话
避什么
  • 模型选择器、分支迭代、外部 agent 连接，全不上界面

落点：S1 会话历史/新建 agent-panel.tsx:1910-1930,1939；默认脸 :1827 与 room-organizer.tsx:2017 同步改活动脸

Notion Agent

需改造

右下角一个友好的脸；打开先给「基于当前页面你能做的动作」短清单，结果块内嵌对话。

交互骨架
  • 空态=动作建议清单，不是空白输入框
  • chat 可侧栏可浮窗；结果表格长在对话流里
  • 写操作先要求确认，且以你的名义发出
偷什么
  • 活动脸第一屏=动作短清单 + 活动卡行；写动作前唯一确认
避什么
  • 给 agent 起名/换配饰的拟人玩法；跨应用代操作后置

落点：S1 空态 :1944 改造；确认门文案对齐（onApplyCreative 只调文案不调接线）

Dora AI

需改造

一个提示框 → 直接生成完整可交付初稿；编辑器在结果之后才出现，工具不喧宾夺主。

交互骨架
  • 首屏=提示框，承诺「一句话出完整东西」
  • 生成后才出现可视化编辑器
偷什么
  • 「一卡/一句话 → 完整方案」的首屏承诺感
避什么
  • 编辑器坞（3D 物件/动画面板）绝不成首屏

落点：S1 生成中 chrome PlanHome:1947 / GenProgress:1962 只出进度与预览，不出工具

Viggle PINOC

直接复用

描述一个场景或丢一张图，一两分钟后在生成的世界里漫游——画布是情绪主体，对话框小而安静。

交互骨架
  • Agent 一个入口；手工编辑器后置分件
  • 生成后状态=可漫游的世界，不是工具面板
偷什么
  • 「World eats chrome」：结果态 3D 画布充满画面
避什么
  • 角色/动捕/MCP 与主产品并列；三编辑器=工具箱

落点：结果态画布≥60% 工作区；空间/物料工具不进活动脸空态（呼应 S3 面板化）

Linear Projects / Cycles

需改造

进度按状态分线计数（进行中/已完成），issue 在状态间自由流转——没有 wizard 步骤。

交互骨架
  • Started 与 Completed 分两条线；曾因混算改版
  • cycle 分 current / upcoming / previous
偷什么
  • 各板块状态自己驱动，自由流转不强制顺序
避什么
  • Insights 管理向图表不上幕景

落点：台账暂无进度 UI 锚点（待决策）；候选宿主=计划卡 :1968-1979 或 S1.1 卡面状态短词，不进 S1 回归面

Slack Presence

新增

在线状态=名字旁一个点（实心绿/空心离开/灰离线），自动切换零管理；点成员直达私聊。

交互骨架
  • 在线自动点亮，10 分钟无操作转离开
  • 自定义状态=一句短文案 + emoji；成员点击弹出通话/私信
偷什么
  • presence 点极小、自动；成员条只是沉底一条
避什么
  • 侧栏频道列表/DM 列表不上——不是第二聊天产品

落点：底座复用 member-chat.tsx / team-messages.ts / account-team-panel.tsx / team-data.ts；presence 点为新增小项

Linear Agents

后置

反向教材：agent 与真人是可区分的两类实体——靠指派委派和 @mention 触发，活动像队友一样可追踪。

交互骨架
  • 委派 issue 给 agent / 评论里 @触发
  • agent 有独立活动页，人始终可见可控；不计席位
偷什么
  • 边界原则：真人沉底成员条，agent 左轨切换，绝不混
避什么
  • 把 agent 做成常驻人格房间；真多智能体编排后置（D6）

落点：守边界——member-chat.tsx 不接 agent 路由；Q1 毛绒头像去留见底稿决策点
