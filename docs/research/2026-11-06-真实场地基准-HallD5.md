## 已实测核对（2026-11-06 主会话亲自抓取官网）
官网 layout 页可访问，数字与上表一致；另确认：带投影设备时课桌 114 人（普通 120）、剧院仍 200、自助餐 150、围坐自助 99；官网原话「人数为 guideline」。
剧院式 PDF（`241-06-01-04.pdf`）实图观测：
- 舞台/操作桌在北墙（图上方），观众朝北；
- 观众席三列块，块间走道 **1000mm**、排距 **900mm**、台前留空 **5000mm**；
- 入口在**南墙一排双开门**，西北角有「非常口」应急出口，东侧备餐间双开门；电梯 EV9/EV10 在西南、SEV1 在西北。
- **门宽与开启方向图上无数字 → 必须记为 unknown**；不存在「南墙中间单门」。
课桌式 PDF（`241-06-01-01.pdf`）实图观测：三列块、每桌 3 人，块间走道 **1200mm**、排距 **1400mm**、台前留空 **5000mm**。课桌式对排距要求远高于剧院式（1.4m vs 0.9m），这是校准硬常数的关键。
广州皇冠假日 PDF 核实完整会议容量表：会议室6 = 12.9×7.1×2.8m/93㎡，中式宴会6桌、剧院80、课桌45、回型42、U型36、长桌34；另有大宴会厅 40.9×20.8m/845㎡、多功能厅 25.5×12.9m/330㎡。
维也纳 WU Meeting Room 6：会议30、U形22、剧院40、分组30、圆圈30、考试30——同房间多布置对照样本。
校准启示：本系统 chair gap / aisle / stage clearance 硬常数应对照真实值（排距 0.9、走道 1.0、台前 5.0）；合成默认南门在 D5 这类场地是错的，必须标 inferred 且不支撑安全结论。

## 用这套基准要跑的对抗检查（P1 验收清单）
1. **事实区分**：系统能否分清「官方面积/家具尺寸（高可信）」vs「出口/门宽/库存（未知）」，未知项不许静默。
2. **方案生成**：能否出讲座布局并解释取舍，而不是只给密度三版。
3. **对照而非照搬**：把系统布局与官方剧院/课桌参考图比较，参考图不是唯一标准答案。
4. **冲突处理**：把人数改成超过公开参考容量（如 D5 填 250 人），系统要指出冲突、给可选调整，而不是默默减椅子。
5. **交付清单**：输出家具数量/尺寸、已检查项、待确认事项；库存不足要显式列缺口。
6. **修改闭环**：人工拖拽堵出口 → 旧结论失效、重跑报警。
7. **四态并列**：系统检查 / 场地方确认 / 执行确认 / 许可，互不替代。

> 说明：D5 与广州会议室都是「真实场地 + 构造任务」；要完成「场地方确认、真实库存、现场执行」的最终验收，仍需找到愿意合作的真实场地方。
