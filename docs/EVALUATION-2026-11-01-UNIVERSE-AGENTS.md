## 0. 江砚的结论（先看这段）

**这是一件完成度很高的作品，还不是一件可交付的产品。**

两个刻度分开打：

| 刻度 | 分 | 依据 |
|---|---:|---|
| 作品级（黑客松、演示、评委） | **8.5 / 10** | 一条路走通、确认前不落盘、物料与交付同源、文档与自检密度罕见 |
| 产品级（工作室付费、真实客户交付） | **5.5 / 10** | 门禁缺失、交付出口未裁决、成本闸被拆、能力下线而入口还在 |

**做对了什么（不重复做）**：主路径只留一颗绿钮、建议→预览→唯一确认才写入、三块视图同一份方案、术语与文案克制。这套约束纪律比功能数量值钱得多。

**三条必做**（按顺序，不要并行）：

1. **把门禁立回来。** 现在 main 上 4029 例里 29 例红，且没有一条会跑测试的流水线。先分清「真欠账」与「满载抖动」，再修或带理由标 skip，不许静默。
2. **给交付出口一个名字。** 离线评审 HTML 与云端只读链接两套语义并存，PM 一直标着「待裁决」。这个口子不封，对外说不清「你把什么交给客户」。
3. **拆第一块巨石。** `creative-studio.tsx` 140 KB、`agent-panel.tsx` 115 KB、`room-organizer.tsx` 100 KB、`globals.css` 96 KB。不拆，后面每一张卡都在同一片泥里施工。

**一条别做**：别再加能力面了。HY-3D 已下线、3DGS 走本机代理、地图选址刚接进来——广度已经超过验证速度，再加只会把「作品」和「产品」的落差拉大。

## 2. 分席意见

### 苏禾 · 产品策划 —— 6.5 / 10

**判断**：主线（选活动 → 定场地人数 → 生成 → 确认 → 导出）是清楚的，一句话能讲完，这是优点。但产品现在有**三个互相拉扯的自我描述**，对外说话会岔。

**证据**：

- README 说「3D 活动方案全流程生成」；定位钉说「卖活动场景方案，不卖 3D 重建能力」；商业计划说重建可外包甚至可假对接。
- 首屏仍列「生成物件」，而 `HY3_RETIRED === 'true'` 时 `generation-input.ts` 直接抛 `410`——**入口在，能力已下线**。
- 交付出口两套：离线评审 HTML（不登录、文件冻结）与云端只读链接（要登录、可撤销），`C.publish-dual-exit` 在文档里仍标「待 PM 裁决」。

**要改**：把「客户最终拿到什么」写成一句可执行的话（例如「拿到一份离线评审 HTML；云端链接是可选」），然后让首屏、导出、销售话术三处都照这一句写。下线能力要么藏起来，要么明确标「暂停」。

### 林序 · 前端组长 —— 5.5 / 10

**判断**：技术选型没问题（Next 15 静态导出 + 原生 three + zustand），但**结构已经到临界点**。

**证据**：610 个 `.ts/.tsx/.css`、约 6.6 MB；475 个组件文件、`panels` 目录 68 个非测试 tsx、`lib` 36 个。单文件：`creative-studio.tsx` 140 KB、`agent-panel.tsx` 115 KB、`room-organizer.tsx` 100 KB、`globals.css` 96 KB、`backend-session.ts` 88 KB。

**要改**：先只拆 `creative-studio.tsx` 三段（简报收集 / 生成调度 / 导出交付），目标 80 KB 以下，**不改行为**；`globals.css` 抽 token 层再讨论，别和结构改动同批。

### 白露 · React 前端 —— 6.5 / 10

**判断**：状态与副作用处理是有痕迹的（ref 兜旧帧、effect 只在真变化时跑、确认后一步可撤销），`agent-proposal` 把「场地真相」和「物料候选」拆成两颗纯函数是正解。

**证据**：更新记录里多次记录「setState 后马上读 state 会读到上一帧」「`directApply` 默认值与蓝图相反」这类真实坑，并且都写明了取舍。

**要改**：`directApply` 默认值与蓝图 §3.3-5 至今相反，挂着「待核」。这类二选一不要靠口头，落到一处常量加注释。

### 陆屿 · 后端组长 —— 7.5 / 10（本仓库最强的一席）

**判断**：这是全仓最像生产的部分。

**证据**：21 个迁移；3 个 Edge Function（`scene-api` / `generation-worker` / `reconstruction-worker`）+ 41 个 `_shared` 模块；鉴权 `Bearer → auth.getUser(token) → 401 UNAUTHENTICATED`；worker 走共享密钥；租约、`expectedRevision`、幂等键、并发互斥都在。

**但两处硬伤**：

1. **纵深防御为零**：15 张表开了 RLS，**0 条 policy**（有意为之——浏览器不直连，全部经 Edge Function + `service_role`）。设计成立，但意味着 `SUPABASE_SERVICE_ROLE_KEY` 是唯一那道门。
2. **成本闸被拆**：`20261003180000_unlimited_ai_usage.sql` 把 DeepSeek / HY3 累计预算改为无上限。商业计划里写的是 300 元总预算。**代码和商业叙事现在是相反的。**

**要改**：给 AI 调用加一道「按项目 / 按天的软上限 + 超额只报错不扣费」，不恢复旧的每日额度也行，但要有闸。

### 齐澜 · 测试工程师 —— 6 / 10

**判断**：用例密度在黑客松作品里罕见（247 个测试文件、4029 例），但**红着 ship 了**。

**我实测（2026-11-01）**：

```
Test Files  12 failed | 235 passed (247)
Tests       29 failed | 4000 passed (4029)
Duration    142.24s
```

单独复跑三份，区分真假：

- `lib/project-review.test.ts`（评审 HTML 快照）+ `lib/project-review-library.test.ts`：单跑 **14 红**，稳定复现 → **真欠账**。
- `lib/commercial-dossier-backup.test.ts`：单跑转绿 → **并行满载抖动**。
- `components/room-organizer/panels/agent-panel.react.test.tsx`：与工作区未提交改动相关，不能算既有欠账。

**并且**：仓里自己的更新记录 10-27 写「全量 3647 过 / 4 失败」，5 天后变成 4029 例 / 29 红。**用例涨了 382 条，红从 4 涨到 29**——没有门禁的测试套件，红会自然累积。

**要改**：先把 29 红分成「修」「带理由 skip」两类清单，再谈覆盖率。

### 常青 · 运维工程师 —— 3.5 / 10（最低的一席）

**判断**：部署链路是通的，工程纪律是缺的。

**证据**：

- `.github` 下只有一个 `agents/3d-expert.agent.md`，**没有任何 workflow**——没有跑测试的流水线。Cloudflare Pages 构建时会过类型检查（`fix(pages): unblock production typecheck` 这条提交能证明），但**测试不在构建里**。
- 无 staging；Edge Function 单独手工部署；`HY3_RETIRED` 这类开关只能靠环境变量，没有开关面板记录。
- 线上站点可打开，但产品对 WebGL 是**硬依赖**：我的环境没有硬件加速，画布直接回落到「三维画布没能启动」——降级文案写得好，可这时产品等于不能用。

**要改**：一条最小流水线（typecheck + vitest + build，红了不许合）、一个 staging、一份回滚步骤。三件里先做第一件。

### 秦时 · UI 设计师 —— 6.5 / 10

**判断**：交互纪律（一屏一颗绿钮、空闲零绿钮、说明 2 秒淡出、左轨三枚）是克制的，这在同类产品里少见。

**但有一处已知未修**：墙色 `#e8dcc4` 压在 `#f9f9f9` 画布底上对比不足，更新记录里被记过两次（10-26「墙色对比度是视觉问题，本卡没动」、之后又复现一次「截图里四面墙看着消失」）。**一个被记录两次的视觉缺陷，等于没记录。**

**要改**：墙材质换成能压住底色的一档，或给画布底加一层极浅的场地阴影。这条十分钟，别留在欠账里。

### 许遥 · 跨端 —— 5 / 10

**判断**：手机查看页（`/view/`）存在且有回归断言（无表单控件、无 Agent 输入、无内部备注、撤销后 `SHARE_NOT_FOUND`），这是对的。但**没有一条真机证据**。

**证据**：更新记录多次写「截图拿不到：面板 `visibilityState=hidden`」「`take_screenshot` 报 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`，这轮只做了 DOM 结构 + 几何复查」。验收表里要求「在大陆普通网络下实测登录、资源加载、三维查看，记录设备、耗时和帧率」，目前没有这份记录。

**要改**：拿两台真实手机（一台 iPhone、一台中端安卓），各走一遍「打开分享链接 → 转两圈 → 切视角」，把耗时和帧率写进 `docs/evidence/`。半小时的事，是产品级交付的硬门槛。

### 周野 · Python（旁听）—— 不出评分

仓库里的 Python 只在 `tools/`（Blender 参数化脚本、平面图工具）与本机代理脚本，不进服务端。一句话：**工具链脚本没有版本化依赖清单，建议加 `requirements.txt` 或 `pyproject.toml`**，否则换机即失效。

## 6. 何时回头看

- **门禁连续两周全绿** → 再谈覆盖率与重构范围。
- **有 1 家工作室用它交付过一场真活动** → 8.5 分的作品分才有机会变成市场分；在那之前不要对外宣称降本或提效。
- **单文件都压到 100 KB 以下** → 再评估要不要把 6 个不相关岗位对应的能力设想砍掉。
- **HY-3D 或替代供应商有结论** → 再决定「生成物件」是恢复还是彻底摘除。
