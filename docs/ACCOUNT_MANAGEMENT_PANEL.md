# 账户与项目管理面板

右上角原云项目入口改为「账户与项目」。沿用现有米白、植物绿界面，账户信息和导航置顶，集中呈现项目、团队演示、权限演示、素材库和发布管理。

## 行为与范围

- 我的项目：名称搜索、工作室筛选、加载/失败/空列表状态；保留创建、打开、重命名、编辑权获取/释放和版本校验保存。
- 当前画布单独显示本地草稿、预设、云端只读或保存状态；本地预设不标成云端已保存。
- 团队演示：虚构工作室和成员、添加/移除成员、编辑/查看角色切换。负责人不可移除或降级。
- 权限演示：查看、编辑、导出、发布、成员管理矩阵；角色预览即时反映选择，支持重置。
- 演示状态只存在组件内存中，切换导航或关闭再打开面板保留；刷新、离开编辑器或切换账户后重置。演示不发送请求，不建立真实成员关系，不修改服务端权限。
- 真实工作室成员管理仍通过项目区内的独立链接进入原 `/projects/` 页面。
- 素材与发布继续使用原组件和同一 BackendSession。共享契约、后端、数据库和依赖均未修改。
- 原生 dialog 管理焦点和 Escape 关闭；面板内按键不传播到画布的删除、撤销等快捷键。

使用隔离工作树、独立依赖和 Node 24.19.0；预览端口 43127，浏览器测试夹具端口 43128。

- 前端完整测试：123 个文件、1,580 项全部通过；面板专项 15 项通过。TypeScript、ESLint（无错误）、Next.js 静态构建和 `git diff --check` 通过。
- 面板回归覆盖项目筛选、失败重试、未保存草稿保护、创建前资料刷新、链接项目切换、预设保存状态、登录/退出、离线团队与权限演示、阻止画布快捷键。
