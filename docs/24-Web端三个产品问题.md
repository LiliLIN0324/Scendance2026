# 54 · Web 端三个产品问题（2026-11-05）

> 结论先行：**优先级 1 > 2 > 3。**
> 问题一：交付包是断的。问题二：Agent 是玩具。问题三：两类客户被当成一类做。
> 本文只写判断与可验证判据，不改代码。

## 0. 一页表

| 优先级 | 问题 | 现状一句话 | 解决判据一句话 |
| --- | --- | --- | --- |
| P0 | 交付包是断的 | 能导出若干文件，但拼不成一份能直接交给甲方的包 | 一个任务一键出四件套，10/10 可交付，无需人工改名拼装 |
| P1 | Agent 是玩具 | 价值停在「你说话它摆家具」 | 同一场地 8 小时内出 3 个风格可辨的完整备选，人工基线 3 天/版 |
| P2 | 两类客户混做 | 场地方与执行公司共用一套界面与交付物 | 10 家访谈 ≥8 家分类一致；两类各有独立首屏与交付默认值 |

## 1. 问题一：交付包是断的（P0）

### 1.1 甲方要四样，现在只交得出一件半

| 甲方要的 | 用来干什么 | 现在有什么 | 断在哪 |
| --- | --- | --- | --- |
| 效果图 | 给老板/客户看气氛 | 画布 PNG、机位册 | 截图级，无统一分辨率、无水印与版本号 |
| 能施工的平面与尺寸 | 进场搭台、量距离 | 平面 DXF（按楼层导出） | 只有几何，缺尺寸标注、材料标注、图框与比例说明 |
| 能报价的物料清单 | 采购与报价 | 物料清单 CSV（名称/尺寸/颜色/数量） | 没有单价、小计、损耗与替代项，不能直接报价 |
| 免安装的分享链接 | 甲方自己打开看 | 分享 token 链接 + 只读快照 | 与交付包不绑版本；快照上限 50 个物料、50 个资产 |

**判断：B 端付钱的依据不是「编辑器好用」，是「我拿到了一份能交给甲方的东西」。**
所以这是「补上就能收钱」的一刀，排在问题二、问题三之前。

### 1.2 什么算解决（可验证）

| # | 判据 | 怎么验 | 通过线 |
| --- | --- | --- | --- |
| 1-1 | 一键出交付包 | 在同一个已确认任务点「导出交付包」，产出 1 个 zip，含效果图 / 平面 / 物料清单 / 分享链接说明 | **10/10 个任务**成功；生成 **≤10 分钟**；**0 次**人工改名或拼目录 |
| 1-2 | 效果图可对外 | 抽查 3 个任务，每任务 3 个机位；查像素、水印、版本号、项目名 | **1920×1080 起**；**3/3** 任务水印与版本号齐全；清晰度主观评分 ≥4/5（3 人盲评） |
| 1-3 | 平面能施工 | 把 DXF 交 CAD 量取 5 处已知尺寸（墙长、门宽、通道） | 5 处误差 **≤1%**；比例、图框、尺寸标注齐全；**3/3** 任务通过 |
| 1-4 | 清单能报价 | 用同一份物料清单复算总额；检查每行是否有单价、数量、小计 | **100%** 行有单价与数量；CSV 合计与页面合计误差 **0**；报价时间 **≤15 分钟** |
| 1-5 | 链接免安装可看 | 用未登录浏览器打开分享链接；断网重试一次 | 首屏 **≤5 秒**；**无需安装/登录**；链接与包内版本号一致；有效期 **≥30 天** |
| 1-6 | 甲方能自答三问 | 让 3 位甲方只看包，回答「多大 / 多少钱 / 什么时候进场」 | **3/3 人**在 **5 分钟内**答对，且不需要打电话问策划 |

不通过说明：任一条不过，交付包就还是「文件集合」，不是「可交付物」；B 端不会为文件集合续费。

## 2. 问题二：Agent 是玩具，不是生产力（P1）

### 2.1 价值差一个量级

- 现在：一句话 → 一版布置。形态是「对话式摆家具」，演示好看，付费理由弱。
- 人做一版完整方案：约 **3 天**。
- B 端会付钱的场景：**同一场地，8 小时内出 3 个风格完全不同的备选方案，让甲方挑。**
- 同一套能力，两种产品形态：单版对话是 demo，批量备选是生产力。吞吐差 **9 倍**（3 版 / 8 小时 vs 1 版 / 72 小时）。

### 2.2 定位改写

从「你说话它帮你摆家具」改成「**批量生成备选方案**」。

一次输入：场地 + 硬约束（预算/人数/层高/通道）+ 3 个风格 brief。
一次输出：3 套完整方案，每套都能独立确认、导出、分享。

### 2.3 什么算解决（可验证）

| # | 判据 | 怎么验 | 通过线 |
| --- | --- | --- | --- |
| 2-1 | 8 小时出 3 版 | 选 1 个真实场地，给 3 个风格词，从提交到 3 套可确认方案 | 总时长 **≤8 小时**；单套 **≤2 小时**；**3/3** 套完整（无越界、无穿模、物料齐） |
| 2-2 | 风格真的不同 | 3 位评审盲看 3 套图，给每套贴回风格标签 | 每人 **≥2/3** 贴对；3 人一致率 **≥80%** |
| 2-3 | 差异可量化 | 对比两套方案：品类替换率、位置变动率、色彩/材质族差异 | 任两套：SKU 替换 **≥30%** 或物件位置变动 **≥40%**；色彩族至少 **1 项**不同 |
| 2-4 | 甲方真会挑 | 10 次真实提案，记录甲方是否在 3 套内选定 | **≥8/10** 次在 3 套内选定；选定时间 **≤2 天** |
| 2-5 | 不比人贵 | 同一场地，人工 3 版 vs Agent 3 版，算工时与成本 | Agent 总工时 **≤人工的 1/3**；单版返工 **≤1 次** |

不通过说明：只能出一版，或三版只是换颜色 → Agent 仍是演示功能，不能按「AI 生产力」计价。

## 3. 问题三：两类客户被当成一类做（P2）

### 3.1 两类客户要的不是同一个东西

| 维度 | 场地方（景区/场馆/园区） | 执行公司 |
| --- | --- | --- |
| 买什么 | **展示资产**：把这块地做成可看的东西，拿去招商 | **生产工具**：接单前快速出方案 |
| 交付物 | 分享链接、可看的三维场地、地理底图 | 效果图、施工平面、物料清单、报价 |
| 频次 | 低频、按场地 | 高频、按项目 |
| 成功指标 | 链接打开率、招商转化 | 出方案时长、报价准确率、中标率 |
| 决策人 | 运营/招商负责人 | 老板/主案设计师 |
| 付费方式 | 年费/按场地 | 按席位/按项目 |

### 3.2 分开的判断依据（if / then）

| 信号 | 归哪类 | 产品取舍 |
| --- | --- | --- |
| 第一句是「怎么让客户看到这块地」 | 场地方 | 首屏给分享链接与三维展示；不把报价、BOM 放第一屏 |
| 第一句是「明天要提案 / 要报价」 | 执行公司 | 首屏给批量备选、平面、清单；分享链接后置 |
| 一年做 **≤3 个**场地 | 场地方 | 默认模板偏展示，允许单场地长期维护 |
| 一个月做 **≥2 个项目** | 执行公司 | 默认模板偏生产，任务可复制、可批量 |
| 客户自带设计师 | 执行公司 | 工具定位，强调导出与协作，不强调代做 |
| 客户没有设计能力 | 场地方 | 展示定位，强调成品链接，不强调编辑器 |

**取舍原则：按第一句话与复购频次分流，不做两边都迁就的折中界面。**
折中的结果是：场地方嫌复杂，执行公司嫌不够用。

### 3.3 什么算解决（可验证）

| # | 判据 | 怎么验 | 通过线 |
| --- | --- | --- | --- |
| 3-1 | 分类可复现 | 10 家真实客户访谈，按 3.2 信号打标，两人独立分类 | **≥8/10** 一致；分歧项有明确归因 |
| 3-2 | 两类各有独立首屏 | 分别用两类账号走首次任务 | 每类 **≤10 分钟**到达第一个可交付物；**0 次**进入对方主流程 |
| 3-3 | 场地方路径成立 | 上传/生成场地 → 铺地面层 → 发分享链接 | 链接打开率 **≥60%**；无需登录；**3/3** 场地可看 |
| 3-4 | 执行公司路径成立 | 批量 3 版 → 平面 → 清单 → 报价 | 从接单到可报价 **≤30 分钟**；**3/3** 项目通过 |
| 3-5 | 不互相拖累 | 分别统计两类任务的完成率与放弃点 | 两类完成率都 **≥70%**；放弃点不集中在同一屏 |

不通过说明：两类共用一个首屏且都低于 70% 完成率 → 产品定位没切开，继续做只会两边都不够用。

## 4. 顺序与依赖

1. **先补交付包**：它是当下唯一能直接收钱的一刀。
2. **再做批量备选**：3 套方案 × 1 个交付包 = 一次提案出 3 份可交付物，放大第一件事。
3. **最后切客户**：前两件跑通后，用真实数据决定默认模板与首屏，不靠拍脑袋。

依赖关系：问题二的「3 套」必须复用问题一的「1 个包」；问题三的分流必须复用前两件的产物，否则只是换皮。

## 5. 明确不做

- 不把「编辑器更好用」当卖点。
- 不用单方案 demo 证明 AI 生产力。
- 不把截图冒充施工图。
- 不做同时讨好两类客户的折中界面。
- 不在交付包里放不可复算的报价数字。
