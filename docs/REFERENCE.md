## 一句话定位

晴光 = **单体多段毛绒活物**：鼠尾草绿圆顶头 + 奶油→卡其圆脸贴片 + 深橄榄绿珠眼 + 头顶一枚暖白发光体，身体中下部渐收、无四肢、无耳、无鼻、无胡须。**3D 毛绒质感，绝非平面插画，绝非小狗/Bingo。**

## 造型（几何）

- 轮廓：**灯泡/水滴/灯笼型**——顶部圆润、中段最宽、下部收窄到圆底；头与身体**一体缝合，无明显分界**，不是大球+底座的灯罩，也不带独立四肢。
- 头 = 上 1/4 的**鼠尾草绿圆顶**；中部是椭圆形**奶油白→卡其**面贴片；下部身体渐深并收尾。
- 无投影贴片以外的任何道具/衣物/边框/文字。

## 五官

- **眼睛**：两颗**实心圆形**深橄榄绿珠（`#2E5D3E`）；单眼直径约 **脸宽 1/5、脸高 1/4**；位于奶油面贴片**中上部**，**眼距≈单眼直径**，对称。
- **嘴巴**：**细弧线微笑嘴**，同色深橄榄绿，单线勾勒无唇线；位于面部**中下部**，弧顶距下巴约脸高 1/6。
- **无**鼻子 / 耳 / 胡须 / 眉毛 / 任何狗特征（垂耳、长吻、斑点都没有）——抽象极简风格。

## 发光元件（IP 签名）

- 位置：**头顶正中央**，一枚**正圆形暖白发光面**（`#FFF9E6`），嵌入头顶开口内；**不是**外置灯、不是彩色光斑、不是红角标。这是「晴光」的辨识签名。

## 材质

毛绒感来自三点，必须同时具备：
1. **绒毛边缘**：轮廓带轻微模糊/微绒过渡（不是硬矢量描边）。
2. **柔和高光带**：顶面与右侧各一条柔和高光。
3. **短距离渐变阴影**：非硬边、非 flat 色块，体现体积。

判定：**3D 渲染毛绒**，**禁 flat / 线稿扁平风**。

## 与「旧锚」的差异（Phase 1 重烘依据）

上一版把晴光当成了「奶油白球 + 一圈鼠尾草绿 rim + 深色眼」，均值 `#c7b394`。实际主锚是：

- 头顶是一整块**鼠尾草绿圆顶**（不是细 rim），占图约 1/3；
- 脸是**奶油白上 → 卡其下**的渐变贴片（不是整团奶油）；
- 身上**一定有头顶暖白发光体**（旧 40px 产品图基本丢失）；
- 眼睛是**深橄榄绿**（不是纯黑）；
- 身体中下段**渐收**，带灰绿褐暗部（不是正圆）。

## 40px 缩小保真要点

40px 仍要认得出晴光，靠这四样：
1. **灰绿圆顶 + 卡其脸** 的两段式头部（轮廓即签名）；
2. 头顶**一点暖白高光**（发光体缩成保留的高光点）；
3. **两颗深橄榄绿眼点**（对比脸贴片足够清晰）；
4. **向下渐收的身体**轮廓 + 短渐变阴影（非圆饼、非线稿）。

## DO / DON'T

- DO：3D 毛绒、灰绿圆顶、奶白→卡其脸、两颗橄榄绿珠眼、头顶暖白光、下收身体、透明底。
- DON'T：flat / 线稿扁平；小狗/Bingo（耳/吻/斑/鼻）；细 rim 替掉整块灰绿顶；红角标/文字/边框/道具/场景（除非 prompt 显式要求无缝纯白或透明底）。
