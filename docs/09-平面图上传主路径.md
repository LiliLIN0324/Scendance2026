# 平面图上传主路径（产品钉 · 2026-10-31）

> 状态：**用户钉死** · 话术与 KEEP 对齐用  
> 技术落地另开云端；本文不改代码

## 一句话

上传平面图后，用户**只需要一步**：在图上点两点，确认这两点之间是多少米（AI 可先预填），确认后落到场地。

## KEEP（主路径）

`上传平面图 → 两点定标尺（可带 AI 预填米数）→ 确认进场地`

## KILL

- 多余标定步骤（多页向导、反复量边、未确认就静默定米）
- 把「手输长宽矩形壳」当成上传图后的必经主路径（手输是无图时的旁路，不是上传后的默认）
- 上传后堆识别墙门柱 / 层高 / 主入口才让进场地（这些可后置，不挡「先落地」）

## 成功标准

1. 上传后下一屏就是两点标尺（或等价：点两点 + 米数输入，AI 可预填）。
2. 用户改米数或接受预填 → 一键确认 → 进入可布置场地。
3. 确认前不报假米；确认后 `scale.confidence=high` 可追溯。

## 与 T-3D 关系

- 对齐并收紧 `T-3D-03`：人闸就是「两点/一边定标尺」，不是多步向导。
- `T-3D-02` 手输长宽保留为**无平面图**旁路。
- 结构草稿 / 主入口 / 层高不插进上传主路径中间。
