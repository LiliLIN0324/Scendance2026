方案 A/B 采用此前询问中推荐的独立切换方式。本机方案历史和自建编组随本地草稿保存；云端协议仍保存当前选中的场景，不会同步全部历史/编组到其他设备。界面明确标注此范围。每个本地草稿最多保留 20 个方案、100 个自建层；可移除非当前方案或编组，物料不会随编组删除。自带材质的 GLB 延续原有不能改色的限制；批量移动跳过锁定物料，并对结构冲突保持整组原位。

## 验证结果

- 前端完整回归：125 个测试文件，**1582 项通过**。
- 后端完整回归：16 个测试文件，**151 项通过**，使用隔离 PGlite 数据库。
- 前后端类型检查、Next 静态生产构建、Supabase Edge 检查、`git diff --check` 通过。

- 真实浏览器：默认需求、无图纸形状入口、库内点击及拖拽、分类 hover、属性浮层、助手开关、减少动态效果、图层批量移动与刷新、测试账号登录刷新恢复、取消/确认删除、删除后刷新列表。
