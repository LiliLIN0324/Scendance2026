# T-06 画布静默 · 任务卡

> 卡号：**T-06**（3D 画布周边去噪，让场成为主角）
> 用户点名：2026-10-27。T-UI / T-05 已把右栏绿钮与左栏六 Tab 收口，但策划人仍觉得「上下左右都是按钮加文字很啰嗦」，尤其 3D 周围围了一圈东西。
> 依赖：v1.3.1 已发布；T-05 已验收 PASS（可与未发的 T-05 同树，但不绑发版）。
> 产品钉：绝对简洁、chat-first；禁按钮旁说明书；空闲零噪音；教程另做。本卡只砍画布周边「看得见的壳」，不改布置算法、不接真模型、不动 14 键扩功能。

---

## 1. 一句话任务

把 `/editor` 的 3D 画布从「工具岛」改成**默认安静的场**：空闲时画布四周几乎看不见控件与说明字；必要操作仍在，但收进短名单或「更多」；预览说明出现后自动淡出。人一眼先看见场地，再看见工具。

---

## 2. 现状核对（开卡前已对过）

| 区域 | 现状 | 本卡处理 |
|---|---|---|
| 画布顶左 | `sc-canvas-heading`：`3D 场景 / 尺寸 / 物料数 / 面积` 常驻 | **弱化**：默认只留一行极短尺寸（或悬停/点一下才展开明细）；禁止再叠第二行说明书 |
| 画布顶中 | `sc-preview-caption`：「AI 修改预览 · 尚未加入场景 · …」整句常驻 | **淡出**：预览开始时出现，约 2s 后淡出；悬停画布或有新预览时再闪一次；禁止常驻说明书墙 |
| 画布中 | `ap-canvas-pill`：「说一句需求就能出方案 →」等空闲气泡 | **空闲零气泡**：无提案、无生成、无重叠警告时不挂引导气泡；有重叠/失败才出现短警告 |
| 画布右竖条 | `#tool-column`：撤销/重做/导出/视角/2D3D/网格/尺寸/全屏/缩放…一长串 | **短名单**：默认只露 **撤销、2D/3D、视角**（至多再加「全屏」）；网格/尺寸/缩放/导出进「更多 ▾」折叠；折叠默认关 |
| 画布底左 | 「氛围」条（漫游/人群/天气/时段） | **默认收起**且本卡不扩氛围能力；若已有折叠，确保空闲不自动展开、不抢画布 |
| 画布底中 | 「物料库 ▴」大把手常驻 | **保留但瘦身**：只留一个安静把手（图标优先，文字可极短）；展开逻辑不改 |
| 右栏 / 左轨 / 左栏简报 | T-UI / T-05 已收口 | **本卡不重开** |

### 待核（不替产品裁决）

1. **默认露出哪三颗**：建议「撤销 / 2D·3D / 视角」。若实现发现「全屏」比「视角」更常用，可对调，但默认竖条可见图标 **≤ 4**（含「更多」本身）。
2. **顶栏尺寸信息**：建议默认一行 `12 × 9 m`；点数/面积进悬停或点开。若去掉整条顶栏更干净且不伤定位，可整条默认隐藏、悬停画布顶缘才出——写进自检待核。
3. **键盘快捷键**：本卡不强制做快捷键教学；若已有快捷键，保留，不在画布上贴说明。

## 5. 交互钉

1. **空闲第一眼是场**：打开 `/editor` 空闲态，画布中央是场地，四周没有说明书墙，没有「说一句需求就能出方案」常驻气泡。
2. **右竖条短名单**：默认可见 ≤ 4 个控件（含「更多」）。撤销必须在短名单里。网格、尺寸标注、缩放、导出效果图进「更多」，默认折叠。
3. **预览说明会消失**：AI 预览说明最多停留约 2 秒后淡出；不要常驻半透明长句挡画面。
4. **警告才说话**：重叠、生成失败等才允许顶条/短 pill；语气短，不写教程。
5. **氛围默认闭嘴**：底左氛围条默认收起；本卡不扩展氛围。
6. **物料库安静入口**：底中把手保留，视觉更轻（少字或图标为主）；展开行为不变。
7. **一屏一绿纪律继承**：本卡不得在画布上新增 `btn-primary` 绿主钮。
8. **演示条仍在右栏**：不弱化「未接真模型」语义（右栏已有即可，别挪到画布中央）。
