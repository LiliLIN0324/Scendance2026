三、关键接口事实（踩坑换来的）

1. 网关与账号体系

key 在国内平台申请，World 服务只在国内网关 https://api.aholo3d.cn 有账号画像； 国际网关 api.aholo.ai/global 对同一把 key 调 world 会报 BIZ_14001 user not exists。 认证一律 Authorization: <key>（无 Bearer）。

2. Lux3D 响应壳与占位

统一响应壳 {c,d,m,f}，c:"0" 为成功；查询接口在任务运行中 outputs 是 [null,null] 占位——解析必须容忍 null 项，否则 Zod 校验直接炸（已修）。

3. 时效与计费

结果签名 URL 2 小时过期，必须即时落盘自有存储；lux3d 每次生成 20 credits； world 计费未出账，建议邮件 lux3d@qunhemail.com 确认。

四、3DGS 场景比例校准（本次结论）

问题：物料桌椅巨大、高斯场景像玩具

lod-meta 的 forwardBox 只有 6.3×5.9×3.5，最初按它缩放，把整座点云压成了玩具盒； 改按场地缩放仍是错误方向——缩放本身就不该发生。

证据链

lod-meta 分析（tools/aholo/lod-analysis.cjs）：
forwardBox : 6.32 × 5.91 × 3.45
tree root  : 39.61 × 25.59 × 9.92
三轴比值   : 0.16 / 0.23 / 0.35 —— 不一致

→ forwardBox 不是单位换算系数，只是局部子盒；
→ 根包围盒 39.6 × 25.6 m 正是一座宴会厅的合理尺寸；
→ World 生成产物本身就是米制，任何缩放都是错的。

最终方案

1:1 摆放，零缩放：底面贴 y=0、水平中心对到场地中心。点云里自带的桌子约 1.8 米， 与物料桌椅天然同尺度；用户的 10×8 场地是这座大厅里的一块布置区，物料照常摆、照常碰撞。

验证效果

已知余项：点云地面估计存在厘米级固有误差，物件贴地以布置时贴地为准； 「按高斯实测桌距做绝对校准」列为后续可选项。
