# 活动场景量化空间规范表

2026-11-05 ｜ 面向「AI 空间搭建智能体」的可执行约束集 ｜ 1 格 = 1 米

---

## 0. 读法与口径

### 0.1 本文档的用途

把六类活动场景的空间经验，压成**机器可判**的 `rule_id + 判据表达式`。智能体在落笔前用本表做预检，落笔后用同一张表做校验；人不看散文，只看表。

### 0.2 坐标与尺寸约定

| 项 | 约定 |
|---|---|
| 网格 | 1 格 = 1 m × 1 m，正方形 |
| 坐标 | `(x, y)` 为格索引，原点在场地西南角，x 向东、y 向北 |
| 物件占地 | footprint `W×H`（宽×深）占 `[x, x+W) × [y, y+H)` 的整格集合 |
| 旋转 | 仅 0/90/180/270°；非 90° 倍数需先栅格化再判 |
| 净距 | 两 footprint 之间**最小连续空格数**（正交方向测，不用欧氏距离） |
| 通道净宽 | 沿通道走向做 4-邻域 BFS，取垂直断面上的最小自由格数 |
| 面积 | footprint 格数；异形按格数累加 |

### 0.3 取整规则（决定判据是否可复现）

| 规范类型 | 取整 | 例 |
|---|---|---|
| 最小净宽 / 最小间距 / 最小尺寸 | `ceil(m)` | 1.50 m → 2 格；0.90 m → 1 格；0.75 m → 1 格 |
| 最大距离 / 最大坡度换算 | `floor(m)` | 8 m 视距上限 → 8 格 |
| 最小面积 | `ceil(m²)` | 20 m² → 20 格 |
| 人密度换算 | `floor(面积 / 人均)` | 100 格 ÷ 1.0 → 100 人 |
| 比例类（遮荫率等） | 保留 1 位小数，按格数统计 | 40% of 100 格 = 40 格 |

> 因为取整一律保守（下限向上、上限向下），**表内"格数"列可直接用于判定，不必二次换算**。0.75 m 这类值会变成 1 格，意味着"1 格即达标"，这是格子系统的固有精度损失，需在解释文案中说明。

### 0.4 判据写法（伪 DSL）

```
IF <度量> <比较符> <阈值> THEN VIOLATION("<rule_id>", 实际值, 阈值)
IF NOT <存在性谓词> THEN VIOLATION(...)
WARN 级：阈值相同，只降级为提示
```

可用度量：`free_width(path)`、`gap(a,b)`、`area(zone)`、`count(type, zone)`、`density(zone)`、`cover_ratio(zone, shade)`、`clear_height(zone)`、`angle(front, target)`。

### 0.5 来源等级与优先级

| 等级 | 含义 |
|---|---|
| **A** | 国家标准 / 强制通用规范，有条文号，可核验 |
| **B** | 行业标准、地方规范/导则、公安或城管口径，有文件名，可核验但**地域性适用** |
| **C** | 经验值，**无强制标准**，仅作设计目标 |

| 优先级 | 系统行为 |
|---|---|
| **硬性** | 触发即拒绝该次落笔，必须改方案 |
| **推荐** | 允许落笔，回执中列警告与理由 |
| **理想** | 只进评分，不影响执行 |

> 免责边界：本表是**空间几何约束**，不是消防审查、结构计算或安全许可结论。A 级条文用于几何判定时已做简化；B 级地方口径需按项目所在城市替换；C 级不得对外表述为"符合国标"。

## 1. 通用基线（GEN）

所有场景共用，先于场景表判定。

| ID | 指标（中 / EN） | 规范值 | 格数 | 依据 | 判据 | 优先级 |
|---|---|---|---|---|---|---|
| GEN-01 | 无障碍通行净宽 / accessible clear width | 室内 ≥1.20 m；室外 ≥1.50 m | 2 格 | GB 50763-2012 §3.5.1；GB 55019-2021 §2.2.2 | `free_width(any_path) < 1` 或 `室外 < 2` → 违规 | 硬性 |
| GEN-02 | 主要人流通道 / main circulation width | 人流集中处 ≥1.80 m | 2 格 | GB 50763-2012 §3.5.1-1 | `free_width(main_path) < 2` → 违规 | 推荐 |
| GEN-03 | 疏散主通道 / egress main aisle | ≥3.00 m；大型活动按人数 3.5–6 m | 3 格 | 地方公安口径（郑州、无锡、荆州）；GB 50016-2014 §5.5.18 | `free_width(egress) < 3` → 违规 | 硬性 |
| GEN-04 | 安全出口数量 / exit count | ≥2 个；≥10000 人 ≥4 个 | — | 地方公安口径；《大型群众性活动安全管理条例》§11 | `count(exit) < 2` 或 `(N≥10000 and count(exit)<4)` → 违规 | 硬性 |
| GEN-05 | 消防设施净空 / hydrant clearance | 消火栓、灭火器 1.50 m 内禁占 | 2 格 | GB 50016-2014 §8.1；常规消防检查口径 | `gap(any_object, hydrant) < 2` → 违规 | 硬性 |
| GEN-06 | 垂直净空 / clear height | 通道及悬挂物底边 ≥2.20 m；标识 ≥2.00 m | 3 格 | GB/T 36731-2018 §6.2.6.1；GB 50763-2012 §3.5.2-4 | `clear_height(path) < 3` → 违规 | 硬性 |
| GEN-07 | 临时设施退距 / temporary setback | 距固定建筑外墙 ≥3.00 m；不得压消防车道 | 3 格 | 经验值（C）+ 消防车道禁占 | `gap(temp, building) < 3` → 违规 | 推荐 |
| GEN-08 | 人员密度换算 / occupancy factor | 展览厅 0.75 人/㎡；无座活动 1.00 ㎡/人 | — | GB 50016-2014 表 5.5.21-2；地方公安口径（深圳、无锡） | `density(zone) > 0.75`（展览）或 `> 1.0`（活动）→ 违规 | 硬性 |

> GEN-03 说明：3 m 是**小型场地底线**；5000 人以上应按地方公安口径升到 6 m 主 / 3 m 辅，15000 人以上 8 m / 5 m。

## 9. 只保留 12 条判据时选哪 12 条

选择标准：① 覆盖 6 类场景；② 每条都是"一票否决"型，不是加分项；③ 单条即可用格数算出，无需外部数据；④ 覆盖四类致命风险（踩踏、跌落、无障碍受阻、火灾）。

| # | 判据 | 来源 rule | 为什么必须留 |
|---|---|---|---|
| 1 | 任何通行断面净宽 ≥1 格（室外 ≥2 格），主通道 ≥3 格 | GEN-01/03 | 一条判据同时兜住无障碍、疏散、推车、轮椅；是所有场景的分母 |
| 2 | 儿童设备外扩 `max(1.5, 2/3H+0.5)` 格内不得有他物 | KID-01/02 | 儿童跌落是唯一"设备本身即风险"的场景，缓冲环是最后一道物理防线 |
| 3 | 任一可达节点有 2×2 格完整空区 | ELD-01 | 轮椅回转是适老区的存在性条件，不满足则整个区不可用 |
| 4 | 站立观众 ≥1 ㎡/人，座席 ≥0.75 ㎡/人 | STG-01 | 踩踏事故的第一变量是密度，不是通道；这条直接决定容量上限 |
| 5 | 首排距舞台 ≥5 + 4×max(0, H−1.5) 格 | STG-02 | 唯一能同时约束"舞台高度"和"观众距离"的耦合式，地方口径高度一致 |
| 6 | 摊位纵/横间距 ≥2 格，明火摊 ≥6 格 | MKT-02/06 | 市集唯一的高频事故源是明火与连片摊；间距即防火分区 |
| 7 | 营位 ≥20 格、间距 ≥2 格、帐篷间 ≥4 格 | CMP-01/02/03 | 露营的三维底线：面积、通行、防火，缺一即不可运营 |
| 8 | 展位通道 5/3 格，且 <8 格只可单侧设展 | EXH-01/02 | 这条把"通道宽度"和"展位数量"绑死，避免智能体用摆摊吃掉疏散宽度 |
| 9 | 出口 ≥2 个；≥10000 人 ≥4 个，且直通场外 | GEN-04 | 数量型硬约束，计算成本极低，却能在任何场景兜底 |
| 10 | 通道与悬挂物净高 ≥3 格（儿童自由空间 ≥3 格） | GEN-06 / KID-03 | 唯一约束"向上"的判据；树冠、灯架、棚、标识都归它管 |
| 11 | 硬底水体近岸 2 格内水深 ≤0.7 m，否则设护栏 | KID-09 | 亲子与露营共用的水域安全线，且是明确的国标数值 |
| 12 | 座椅间距 ≤15 格且遮荫 ≥40% | ELD-06/09 / KID-11 | 唯一管"舒适与停留"的判据；没有它，智能体会产出"能走但不能待"的场地 |

**落选说明（重要）**：观展视距 1.5H、打卡位 3×3 m、调音位 15–25 m、遮荫率 50%、无障碍营位 2% 全部是 C 级经验值，只在场景表内生效，不进系统提示词——它们容易让模型把"经验"说成"规范"。市集垃圾点、灭火器数量等**运营类**指标也不进提示词，因为它们靠配置清单而非几何判据。

**提示词写法建议**：12 条按"度量 → 阈值 → 动作"三段的短句写，不要写成长段；每条给出 `rule_id`，让模型的校验回执能直接引用编号，而不是复述规则。

## 11. 与工具层的对接（实现提示）

| 表字段 | 落到工具参数 |
|---|---|
| 规范值（米） | 校验器内部常量表，按 `rule_id` 索引 |
| 格数 | 直接与 `footprint` 格数比较，不做浮点运算 |
| 判据 | 编译为 `validate_structure(scene, rule_id)` 的断言；返回 `{ruleId, severity, actual, expected, bbox}` |
| 优先级 | `hard` 阻断落笔并回滚；`warn` 落笔但进回执；`ideal` 只进评分 |
| 冲突组 | 同一 `conflict_group` 的规则同时触发时，只报最高优先级一条，避免回执刷屏 |

建议校验顺序：`GEN（全局）→ 场景主表（分区内）→ 冲突组（跨区）`。先粗后细，能在 O(格数) 内失败，不必跑完全部规则。
