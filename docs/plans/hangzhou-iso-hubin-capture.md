# 湖滨三公园至东坡路 · 等距样片采集

2026-11-08。样片范围暂定西湖三公园岸线、湖滨路与东坡路一侧。目标是在同一斜视画面里核对建筑屋顶和立面、岸线树冠、步道与开敞铺装。现有 `D:/Scendance2026/hangzhou-map-lab/iso-near-700.png` 作为程序渲染基线。

## 已定位的实景与图纸

以用户提供的湖滨斜视实拍为主参考，补采范围沿湖从一公园延伸到三公园。照片前景的银泰五期可见连续深灰坡檐、浅色柱廊、内退的平屋面与屋顶平台。沿岸树冠大片相接，路口和入口广场有明确的开口。建模时分别记录这些形体和空间关系。具体建筑轮廓与 OSM 对应关系仍待核验。

## 出样前的核对

1. 在底图标出两张地面照片的机位和朝向。以三公园岸线折点、临湖步道与路口、建筑临街转角作为三类对照点。
2. 用覆盖样区的俯视或斜视画面描出树冠成片区域、开敞地和步道开口。地面照片用于核对遮挡下的空间。照片年代不同时分开记录。
3. 输出同机位对照，左侧现有 iso，右侧依据已核实照片和图纸修正的样片。逐项对照建筑退台和屋顶、树冠疏密、步道开口及岸线。现阶段只有图源和机位记录，样片与整块航拍覆盖待完成。
