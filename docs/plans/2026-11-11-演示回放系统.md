# 演示回放系统（tour-reel）· 幕景前端升级规格

日期：2026-11-11 · 对标：petitmaker.com.cn 首页自动演示 + 帮助中心「新手提示」卡组
目的：把「产品怎么用」从文字说明升级为**在你自己的工作台里回放真实操作**的引导系统。

---

## 0. 对标产品的做法（2026-11-11 实测）

1. **不是录屏视频，是真实操作的脚本回放**：导览光标在真实画布上移动、点击、拖拽（实测区域负荷 F7→G1 被它真实改变），旁白卡显示「你在 · 禾夏」+「如果没有其他操作，8 秒后会自动按下」。
2. **每张卡 = 旁白 + 真实控件回放 + 「动手试试」**：文字说明在上，演示在中间，看完可以立刻亲手试用同一个控件（接管回放现场）。
3. **8 步卡组覆盖首访全流程**（移动视角 → 模式切换 → …），分页圆点 + 上一步/下一步。
4. **帮助中心 = 目录 + 搜索 + 每主题嵌一个 mini-reel**（上手/建造/生成 三组共 14 个主题，每主题一张卡：要点两行 + 演示卡「按住增高，拖动延伸」+ 底部说明）。
5. **随时还原**：每个演示卡带「还原演示视频」按钮，可无限重看。

## 1. 幕景要建什么

### 1.1 回放引擎（核心，新组件）

`frontend/components/room-organizer/onboarding/tour-reel.tsx`：

- 输入：一份「步进脚本」`TourStep[]`，每步：
  ```ts
  interface TourStep {
    caption: string;            // 旁白（一两句人话）
    target: string;             // data-tour 目标控件的标记
    action: 'click' | 'fill' | 'wait' | 'press' | 'move';
    payload?: string;           // fill 文本 / press 键
    highlight?: boolean;        // 目标加高亮圈
    autoPressMs?: number;       // 倒计时自动执行（默认 8000），用户可先手动
    handsOn?: boolean;          // 「动手试试」：暂停回放，等用户亲手做
  }
  ```
- 执行器：驱动**真实 reducer/store**（不是模拟截图）：每步在目标控件上放高亮圈 + 光标动画，倒计时或用户点击后执行 action（直接调用既有 actions，与真实用户同一入口），旁白卡跟随目标位置。
- 状态机：`idle → playing → handsOn → done`；跳过/还原/重放三键；进度圆点。
- 关键约束：**不碰 COLLAB 独占区之外的状态**；动作全部走既有 dispatch（回放=真实操作，可撤销栈可退）。

### 1.2 首访 8 步卡组（内容）

| # | 旁白 | 动作 |
|---|---|---|
| 1 | 先说一句你想要的布置 | fill 输入框「社区健康讲座，45人」→ 发送 |
| 2 | 模型理解后回你确认 | wait（等回复，旁白讲「待核对」是什么） |
| 3 | 确认后三版候选 | click 示例「出方案」 |
| 4 | 看座位数和待核验项 | highlight 候选卡（只看不点） |
| 5 | 满意就确认写入 | click「确认布置」 |
| 6 | 物料清单自动汇总 | 切物料面板（只看） |
| 7 | 评审链接发给客户 | highlight 发布→发评审链接 |
| 8 | 交付包给执行同学 | highlight 导出交接 |

### 1.3 帮助中心（第二期）

- `?` 按钮开面板：目录（上手/布置/交付）+ 搜索 + 每主题嵌 mini-reel（复用引擎，步进脚本 3-6 步）。
- 首批主题：需求怎么说/候选怎么看/确认与撤销/物料清单/交付包/评审页落钉。

### 1.4 触发时机

- 首访（无本地活动记录）自动播第 1-3 步，其余收进「？";
- 每个新功能上线时配一条 mini-reel（替代更新日志里没人看的文字）。

## 2. 不做什么

- 不做录屏视频（重量大、改版即过期、不能「动手试试」）；
- 不做全屏遮罩式强引导（PetitMaker 的回放是嵌在真实界面里的轻浮层）；
- 不阻塞既有操作（回放可随时关，倒计时可被用户手动抢先）。

## 3. 工作量与顺序

| 步 | 内容 | 量 |
|---|---|---|
| 1 | tour-reel 引擎 + 高亮/旁白/倒计时 | ~1 天 |
| 2 | 首访 8 步脚本 + 触发时机 | ~半天 |
| 3 | 帮助中心壳 + 首批 3 主题 mini-reel | ~1 天 |
| 4 | 移动端适配（触屏版旁白卡） | ~半天 |

## 4. 验收

- 新用户不看任何文档，跟着 8 步卡组完成「需求→候选→确认→物料」一次真实闭环；
- 每步可跳过、可重放、可「动手试试」；
- 回放产生的操作与真实操作完全同源（撤销栈一步可退）。
