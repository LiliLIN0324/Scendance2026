# 活动场景案例研究：可迁移的空间手法

**读法**：「可迁移点」按"格子地图 + 只放物件/改地形"判定——能落到格上的写"可"，需连续曲面、结构、真实高差或既有建筑的写"部分/不可"，并给原因。案例均取自公开报道或设计说明，链接在案例名内；未能核实规模的标"未核实"。

## 6. 反例：常见失败做法与后果

| 失败做法 | 后果 |
|---|---|
| 儿童区全铺塑胶、零遮荫 | 夏季地表可达 60 ℃以上，午后无人，器械烫伤投诉 |
| 适老座椅无靠背、无扶手、座高 30 cm | 起身困难，老人宁愿不坐，休憩区变成堆放点 |
| 市集摊位外扩侵占通道，净宽 <3 m | 双向人流对冲，遇突发无法疏散，摊位间无法错身 |
| 看护座椅背对活动区或视距 >15 m | 家长起身围观，边界站满人，反而挡住通道 |
| 儿童区紧邻车行道、无连续物理隔离 | 追逐时直接冲出边界，5 m 退距是底线 |
| 只做一条主路、大量尽端路 | 老人/儿童走到头必须折返，产生挫败并在端头堆积 |
| 打卡点等距密排（<20 m 一个） | 无节奏、视觉疲劳，停留时间反而下降 |
| 舞台/摊位正对住宅、无退距与隔声 | 噪声投诉导致活动被叫停，是户外活动最常见的死因 |
