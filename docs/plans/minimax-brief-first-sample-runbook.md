## 先核对

1. 使用独立测试环境和独立测试账户；确认网页、API、账号和密钥均不指向生产。测试结束关闭隔离环境。不要在聊天、仓库、截图、日志或命令历史中粘贴密钥。
2. 由账户管理者在供应商控制台核对**实际账户**的计费方式、币种、余额及可执行的账户级硬上限；记录非敏感的结论和核对时间。如果供应商没有可验证的硬上限，不能声称此次调用的费用有硬上限。也不能假设 `max_tokens` 覆盖所有计费的推理输出。
3. 由环境管理者在隔离服务的密钥管理界面配置 `AGENT_CHAT_BASE_URL`、`AGENT_CHAT_KEY`、`AGENT_CHAT_MODEL` 和 `AGENT_CHAT_PROFILE=minimax`；密钥由管理者直接输入密钥管理器，不经过聊天和仓库。前端公开配置只放隔离环境地址、公开客户端标识及 `NEXT_PUBLIC_AGENT_ENABLED=1`；不能把供应商密钥放入 `NEXT_PUBLIC_*`。本文件没有执行配置或发布。
4. 确认测试页有有效的隔离环境用户会话。关闭自动生成、其他可能调用同一供应商账户的任务及额外标签页。先记录当前账户侧调用计数或账单基线；此记录不是费用预留。
5. 在仓库根目录运行以下**纯离线检查**，核对待发送字段、单条样本和超时设置：

   ```powershell
   node scripts/run-ts.mjs scripts/minimax-brief-preflight-run.ts
   ```

   此命令不读取环境密钥、不联网、不写文件。它使用虚构模型和端点；显示的请求摘要仅对应离线夹具，**不是实际提供商请求的摘要**。如生产 prompt、profile 或参数改变，应重新检查，不能沿用旧记录。

## 唯一测试与核验

仅使用本工具固定的合成句：“为长者办一场讲座，预计 30 人，室内，签到和舞台尚未决定。”不输入真实人物、客户、场地、图片或附件。该接口向供应商发送系统提示词及这一句用户文本，不发送当前图纸、场景或历史对话；模型回复仍是未核验数据。

在隔离页面或隔离 API 客户端**只提交一次** `/brief/extract`。不要同时打开多个页面或重复点击；如果页面提示未决项，先停在提取结果，不继续发送下一句话。本次单样本不声称完成真实模型到落图的整条验收；用户确认与本地候选可先用已有本地模型桩验证。记录请求已发起与否、响应成功/失败/未知、耗时和非敏感错误类别；不保存授权头、密钥、完整供应商响应日志或截图中的隐私信息。

成功后仅检查：响应符合结构约定；签到/舞台不被编造为确定需求；长者不自动等于轮椅需求；任何引用必须存在于合成原句中。人工复核提问语义和安全表述。若需要复核原始模型输出，只在隔离本机受控位置临时查看，避免提交仓库或发送给第三方。

超时、浏览器关闭、连接断开或取消时，记为**结果未知**；停止等待不代表供应商停止处理或不计费。不要刷新后自动重试，也不要更换请求编号重发。先由账户管理者只读核对供应商请求记录及账单，仍无法确认则保留未知结果并停止本轮。
