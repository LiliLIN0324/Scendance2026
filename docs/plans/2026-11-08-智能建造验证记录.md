# 智能建造验证记录（2026-11-08）

本记录对应 `codex/chat-integration` 工作区，不等于原 main 已提交或上线。产品方向为一个活动 Agent；Bingo、空间、物料分别提供用户操作与可逐步调用的能力。

## 已取得的证据

- MiniMax 工具循环为显式配置的受限预览路径；默认真实模型和地点服务未自动启用。模拟模型经真实后端往返读取场景、寻找空位并提交候选。模型工具参数出错时，普通错误会整批不执行并反馈，危险或未授权输入保持拒绝。
- 提交前重新复核完整候选与原场景；新增或可证明加重的部分几何冲突会拦截，出口、疏散、门扇、消防、无障碍和核定人数不因此被判通过。
- 2026-11-08 隔离浏览器模拟：用户指定 12×10 米而场景为 10×8 米时不提交任务；尺寸一致时显示候选和待核验项，确认前数据库场景未改变。该固定样例只新增一把示意椅，并明确未完成 30 人布置；无真实模型及外网调用。之后代码又更新面积逻辑与工具错误恢复，最新版本仍需重新浏览器验收。
- 工具、协议与独立复核测试曾有 127 项通过；最新一轮主面板、深层工作台、物料库、交付与路线相关回归 692 项通过、45 项跳过。前后端类型检查和 Edge 检查通过；最新一轮隔离生产构建通过，构建副本与测试时工作区源码逐文件 SHA-256 一致。后续代码变动仍需要重新验证。
- 空间入口可在本机登记来源、核对状态和一扇门信息；独立浏览器验证过写入与回读。它与画布、交付和场地方确认尚未同步；跨活动切换只有组件级测试，浏览器验证尚未完成。
- 主卡已接入可选物料数量核对：用户需自己为明确身份及规格填写数量；模型与口述线索不自动成为实际库存。该核对并未覆盖所有独立应用入口，不能当作系统级库存保证。
- 活动 Agent 有可选、默认关闭的高德地点查询工具：固定服务、受限输入、带查询时间和来源。只做过模拟测试，地点结果不能证明场馆可租、面积、价格或库存；通用网页搜索尚未接入。
