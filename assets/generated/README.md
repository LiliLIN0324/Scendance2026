# 生成素材存档

Aholo 接口在本机生成过、并且确认要留下的 3D 场景与物件。工作台的「生成物件 / 环境预览」列表读的是浏览器本机记录，换浏览器或清站点数据就没了；这一份是仓库里的长期存档。

| 目录 | 内容 |
| --- | --- |
| `model/<slug>.glb` | 生成物件，尺寸为真实米数，可直接摆进布置场景 |
| `scene/<slug>.spz` | 3DGS 场景包，工作台「环境预览」用的就是这种格式 |
| `scene/<slug>.panorama.jpg` | 接口返回的全景预览图，4096 宽 |
| `thumb/<slug>.png` | 物件缩略图 |
| `manifest.json` | 中文名、尺寸、字节、校验值与来源；新增素材时同步补一条 |

不入库的部分：`.cache/aholo/`（同内容的重复副本，19 个文件其实只有 3 个不同）、场景的 `.ply` 原包（与 `.spz` 同一场景，单包 18–20 MB）、接口的 `result.zip`。

物件的生成任务号没有随文件保存，无法回查；场景保留了 `worldId`。
