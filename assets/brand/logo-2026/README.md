# logo-2026 · 「AI 的门」品牌留档

主标志是 **「AI 的门」（door 版）**：绿色圆角方块 + 白色拱形门洞，无绿点，主色 `#35624A`。
本目录存放它的矢量源与位图留档，**不是运行时资产**，代码零引用、不参与构建。

## 几何参数（反推自 128 位图，非手绘）

| 项 | 原图实测 | 母版取值 |

| 圆角 | 拟合 TL 30.83 · TR 31.03 · BR 31.80 · BL 31.91 | rtl 34.877 · rtr 34.359 · rbr 34.74 · rbl 36.381 |
| 门洞宽度 | 32.0（x 47.5..79.5，中心 63.5） | 半宽 16.273，中心 64.103 |
| 拱顶高度 | x=64 处 y≈72.5 | 72.875 |

| 白色像素簇 | **0**（门洞内 0） | 母版不含眼睛 |

原轮廓并非标准圆角矩形：四角拟合半径≈31，但顶边中部外凸约 2.5 px、左右边在 y=64 处最宽，
属"外凸软轮廓"。母版用 4 个独立圆角半径 + IoU 目标优化来妥协，结果为 **0.9779**。

## 校验数字（两轮）

| 轮次 | 做法 | 形状掩膜 IoU | 不匹配像素 |
| --- | --- | --- | --- |
| 起点 | numpy 超采样模型（等半径 r=35） | 0.9459 | —— |
| 第 1 轮 | 11 参数 Nelder-Mead 拟合 | 0.9738 | —— |
| 第 2 轮 | 以 resvg 真实渲染的 IoU 为目标做坐标下降（步长 0.5→0.03） | **0.9779** | 215 px / 1.31% |

残差分布：四角 143 px、外缘 67 px、拱头 1 px、门腿 4 px；平均边缘偏移
L −0.31 / R −0.27 / T −0.14 / BL −0.41 / BR +0.35（128 像素）。整体亚像素平移 ±0.4 无提升，
故采用上表取值。等半径干净版只有 0.9727，说明"四角半径不同"是原图真实特征，不是拟合噪声。

## 眼睛：PNG 没有，包装层有

- `door.png`：白色像素簇 0 个，拱洞内全透明 → **母版无眼**。
- `frontend/app/icon.svg`（`viewBox 48`，`<image x=4 y=4 width=40 height=40>` 贴 128 PNG）里的两只 rect：
  `x=16.5 y=17.1` 与 `x=25.4 y=16.3`，`4.2×9.4`，`rx=2.1`，`rotate(12° 左上角)`，`fill=white`。
  换算到 128：左上 (40.0, 41.92) 与 (68.48, 39.36)，尺寸 13.44×30.08、圆角 6.72。
- 两只眼睛落在绿色门脸上、拱洞正上方（拱顶 y≈72.9），**不在门洞内部**，是"脸"的五官，
  属人为品牌设计；`brand-mark.tsx` 用同一套几何，`rail-avatar.tsx` 另有一套更小的眼睛（42.8%/36.2%）。
- 运行时用户看到的是**带眼**的包装层；`door.png` 是"无眼"的裸标志。
- 结论：`door.svg` 保持纯净拱洞，`door-eyes.svg` 复刻包装层外观；两者并存，不擅自"补设计"。

## 动效（`motion/`）

12 个 SVG + `index.html`（双击即开，全内联、零依赖）+ `preview.png`。

- **主线：门洞变形**。绿色外框的轮廓、圆角、位置、尺寸全部固定，只有拱形白色负空间的
  宽 / 高 / 拱顶弧度在演化（`d` 关键帧插值）。三帧静帧：收窄（半宽 11.5）· 常态（16.273）· 张开（22）；
  三个循环：呼吸 1.6s、开合 1.8s、纵深 2s（洞高 34→62、宽 32.5→18.4）。
- **辅助**：静态无眼、眨眼（114ms / 3.8s）、悬停（白描边 + 1px）、入场（200ms 淡入，不缩放）、
  加载（门洞呼吸 1.2s）、四形体序列（4.8s，仅概念演示）。
- **两色铁律**：全部文件只出现 `#35624A` 与 `#FFFFFF`（白仅以不透明度叠加），无暖光、无第三色、门身不上色。
- 已内置 `prefers-reduced-motion: reduce` 静态退化；**favicon 只能取 `door-static.svg`，永不加动画**。

## 运行时真源与替换建议

运行时真源仍是 `frontend/public/assets/rail/door.png`（128×128），`app/icon.svg` 与
`components/brand-mark.tsx` 都指向它；**本轮不替换运行时**，只提供矢量源。

> 若要提升高分屏清晰度，可用 `door.svg` 替换 `app/icon.svg` 的引用方式，需另开任务验证
> （48 单位画布 + `preserveAspectRatio="none"` 贴图要先做坐标重映射，并检查 16/32 档 favicon 边缘）。
