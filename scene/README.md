# scene — 模型场景模板

把模型拖进无限网格场景，用固定日光和实时阴影查看效果。不依赖账号、后端或 API Key。

本目录是仓库里的**独立入口**，与根目录的首页和 `frontend/` 工作台互不影响：它不修改任何既有文件，只共享仓库已有的 `../vendor/three/`。

## 运行

从**仓库根目录**启动（模板要读取 `../vendor/` 与 `../assets/library/`）：

```sh
python3 serve.py                 # 仓库自带的服务器，默认 http://127.0.0.1:8766/
# 打开 http://127.0.0.1:8766/scene/
```

或不用 `serve.py`：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
# 同样打开 http://127.0.0.1:8766/scene/
```

**必须通过 HTTP 服务打开。** 页面用 import map 解析裸模块名 `three`，并且要 `fetch` 本地 GLB；直接双击 `index.html` 会因 `file://` 协议被浏览器拦截而白屏。需要浏览器支持 WebGL 2 与 import maps。

## 操作

- **拖模型进网格** —— 从左侧工具栏把任意模型拖到画布上，落点即放置位置
- **点击模型** —— 选中，出现蓝色包围框与左上角信息卡
- **按住拖动模型** —— 在网格上滑走，阴影跟随
- **Delete / Backspace** —— 删除选中模型
- **拖动空白处** —— 旋转视角；滚轮缩放
- **适应视图 / 移除选中 / 清空** —— 画布右上角三个按钮
- **‹ 按钮** —— 收起 / 展开左侧工具栏（状态记在 localStorage）

## 网格

- **0.2 m 一格**，每 1 m 一条主线，原点轴线略深
- 程序化 shader，无贴图。用屏幕空间导数（`fwidth`）保持线宽恒定，并用 `smoothstep` 做解析抗锯齿 —— 边缘是渐变而不是二值判断，所以相机移动时不会闪
- 两个层级各有独立淡出区间：0.2 m 格约 150 m 处开始淡出、300 m 处完全消失，避免亚像素摩尔纹
- 网格体只有 600 × 600 m，但会**跟着相机按 1 m 周期吸附平移**。因为图案本身周期性，平移整数个周期渲染结果完全相同，所以线不滑动，却等效于无限地面；同时把世界坐标保持在小区间内，保证 `fwidth` 精度

## 光照

固定日光，不随昼夜变化：

- **定向主光**：强度 2.6，色温偏暖 `#fff4e2`，投射实时阴影（PCFSoft，2048² 阴影贴图，覆盖原点 30 m 半径）
- **半球补光**：天蓝 `#dce9f7` / 地面暖灰 `#b9b3a6`，强度 1.5，保证背光面不发黑
- **反向补光**：强度 0.42，避免阴影面过于平
- **色调映射**：ACES Filmic，曝光 1.05

不使用环境贴图（IBL），因此启动没有额外的 GPU 生成步骤。

## 模型库

| 页签 | 数量 | 文件位置 | 需联网 |
| --- | ---: | --- | --- |
| 本地模型 | 30 | `../assets/library/model/` + `thumb/` | 否 |
| 线上模型 | 234 | 仅清单 `../assets/library/online.json` | 是 |

两者均为 **CC0 1.0 Universal**（公有领域奉献，无需署名）。详细来源、每个模型的 sha256 与上游链接见 [`../ASSET-SOURCES.md`](../ASSET-SOURCES.md) 与 [`../assets/library/README.md`](../assets/library/README.md)。

本地 30 个模型覆盖活动布置的主要类别：桌子、椅子、吧台、讲台、展位、摊位、展架、签到台、背景板、音箱、麦克风、桁架、LED 屏、射灯、篮球架、足球门、记分牌、旗帜、盆栽、花盆、指示牌、隔离带、帐篷、遮阳伞、围栏、垃圾桶、推车、地毯、挂画、笔记本。每个带真实米制尺寸，放置时按该尺寸缩放。

线上 234 个模型的 GLB 与预览图运行时从 `cdn.3dassets.dev` 直接加载（该 CDN 返回 `Access-Control-Allow-Origin: *`）。这些文件**不随仓库分发**，只存引用。

重新生成素材清单的方法见 [`../tools/catalog/README.md`](../tools/catalog/README.md)。

## 边界

- 场景的「无限」是视觉呈现：网格体 600 × 600 m 跟随相机，可放置范围限制在原点 34.5 m 内，与阴影覆盖半径一致，避免模型被拖到阴影消失的位置
- 首次拖入某个线上模型需要等待数百 KB 下载；本地 30 个模型无此延迟
- 模型尺寸取自上游包围盒，用于布置预览，**不代表可生产制造的实物尺寸**，也未做承重、消防或人流仿真校验
- 侧栏收起状态不持久化到项目，刷新回到初始
